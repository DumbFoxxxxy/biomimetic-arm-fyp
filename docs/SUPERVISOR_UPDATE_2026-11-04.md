# FYP导师汇报：仿生机械手臂原型

汇报日期：2026-11-04。进度截止：2026-11-03。项目路线为真实人体骨骼外形、工程关节和钢丝＋异形TPU晶格肌肉。

## 可直接口述的说明

我目前已建立人体骨骼路线的数字结构候选，重点推进肩部。模型包含工程球铰、骨骼固定台架、肌肉端部连接、钢丝通道和短肌腱；冈下肌及肩胛下肌已经有随肌腹外形变化的三维晶格与表面网格。肘部也有独立保留的设计候选。

目前完成的是数字几何和局部装配检查，尚未证明实体已经能够驱动。裸骨能够完成部分规定动作，不能直接等同于装上肌肉后的运动范围。完整TPU体网格存在问题，相关数值结果已拒绝使用，没有把它当作变形或驱动预测。

下一阶段我会优先打印、穿线和装配，先做单肌肉手拉，再装到骨架上验证实际动作与恢复，随后加入拮抗驱动。运动范围由实物测量，不要求在试制前通过完整有限元确定。长期目标仍然是整条仿生机械手臂。

## 已完成与尚未完成

| 部分 | 已有成果 | 当前边界 |
|---|---|---|
| 解剖模型与工程骨架 | 真实骨形、工程GH关节、支承和骨干抱箍等数字候选 | 实际材料、配合、紧固及完整安装仍需试制核对 |
| 肌肉结构 | 四功能模块／六主动线布局；两块肩袖肌采用共形Y晶格、表面网格及连续通道 | 不是四模块或整臂实际驱动完成 |
| 肌肉与骨骼连接 | 近端支承、自由端盖、短钢丝肌腱、销轴及压接候选 | 端部保持、预紧、摩擦和恢复尚未实测 |
| 数字检查 | 当前191对象零位、有限裸骨运动与部分名义安装步骤有记录 | 不证明整肩已装好、可打印、可承载或可驱动 |
| 制造准备 | 参数化生成脚本、实际网格、方向／通道样件和空白观察表 | 设备／材料未确定；暂无实物驱动测量 |
| 数值分析 | 保存完整肌腹建网失败、孔道修改和独立审计 | 未得到可信变形解；本阶段不以此阻塞试制 |

当前研究起点为S1-Y2；未采用的孔道修复及其他试验均单独保存。191是包括钢丝、五金和台面的模型对象数，不是191个打印零件。

## 接下来先做什么

1. 确认打印资源和实际TPU，核对关节、五金和钢丝接口尺寸。
2. 检查实际零件切片，打印一块肌肉及其端部，验证可穿线、可拉动、可恢复程度与端部保持。
3. 装入肩部台架，演示钢丝输入经TPU肌肉带动骨段，再接入拮抗回拉。
4. 用视频与观察表记录实物动作，测量可达范围；按卡线、滑脱或干涉位置局部修订，再扩展方向和整臂。

首次演示的判据是实际肌肉传力带动关节并可重复观察。原K1–K7保留作后续比较，不以预先达到某个角度或假定25%收缩作为开始打印的门槛。

## 希望与导师确认

- 可用的TPU打印设备、材料和试印安排。
- 钢丝、压接件、标准紧固件与台架加工的可用资源。
- 先完成肩部台架手拉演示，再扩展拮抗控制及整臂集成的试验次序。
