# 仿生机械手臂项目概览

更新：2026-11-03。

## 项目目标

项目希望搭建一条以真实人体骨骼外形为基础、通过工程关节活动、由钢丝与异形TPU晶格肌肉驱动的仿生机械手臂。设计参考论文《Accelerating Musculoskeletal Robotics Through Parametric Design and 3D‐Printed Flexible Structures》中的参数化柔性结构方法。

当前重点是先做出能动的实体模型，再通过实物测量运动范围、恢复情况和驱动效果。首轮采用手拉钢丝，逐步完成单肌肉、关节驱动和整臂集成。

## 总体设计思路

| 部分 | 作用 |
|---|---|
| 解剖骨骼 | 提供骨段外形、比例和肌肉布局的几何基础 |
| 工程关节 | 明确骨段之间的运动关系，并提供连接和保持结构 |
| 异形TPU晶格肌肉 | 按肌腹外形布置内部晶格、表面网格、连续通道和端部过渡，参与形变与传力 |
| 钢丝与短肌腱 | 将外部拉线输入传入肌肉组件，再经端部接口连接骨骼 |
| 支承与固定件 | 固定骨架和肌肉近端，使拉线时有明确的反力路径 |

钢丝与TPU共同构成肌肉组件。TPU本身不主动供能，实际形变、传力和恢复效果需要通过穿线与拉动试验调整。

## 当前结构

目前主要推进肩部S1，采用S1-Y2作为研究起点。肩胛骨和锁骨固定在台架上，先研究GH（盂肱）关节；模型包含工程球铰、骨干抱箍、近端支承、肌肉自由端盖、短钢丝肌腱和端部五金。

肩部布局包含三角肌、冈下肌、肩胛下肌和大圆肌四个功能模块、六路主动钢丝。冈下肌和肩胛下肌已采用随肌腹截面变化的共形Y晶格、菱形表面网格和连续通道；三角肌及大圆肌保留原晶格候选。

肘部已有独立设计候选和试验准备，继续保留，后续与肩部逐步集成。当前完整肩部模型包含191个名义对象，其中包括骨骼、肌肉、钢丝、五金及台面，并不等于191个打印零件。

## 当前进展

| 部分 | 已有成果 | 当前边界 |
|---|---|---|
| 解剖模型与工程骨架 | 真实骨形、工程GH关节、支承和骨干抱箍等数字候选 | 实际材料、配合、紧固及完整安装仍需试制核对 |
| 肌肉结构 | 四功能模块／六主动线布局；两块肩袖肌采用共形Y晶格、表面网格及连续通道 | 不是四模块或整臂实际驱动完成 |
| 肌肉与骨骼连接 | 近端支承、自由端盖、短钢丝肌腱、销轴及压接候选 | 端部保持、预紧、摩擦和恢复尚未实测 |
| 数字检查 | 当前191对象零位、有限裸骨运动与部分名义安装步骤有记录 | 不证明整肩已装好、可打印、可承载或可驱动 |
| 制造准备 | 参数化生成脚本、实际网格、方向／通道样件和空白观察表 | 设备／材料未确定；暂无实物驱动测量 |
| 数值分析 | 保存完整肌腹建网失败、孔道修改和独立审计 | 未得到可信变形解；本阶段不以此阻塞试制 |

目前已有数字几何、局部配合和有限裸骨运动记录，实体驱动尚待验证。裸骨结果与装上肌肉后的活动范围分别记录；未采用的孔道修复及其他试验单独保存。

## 下一步

1. 确认打印资源和实际TPU，核对关节、五金和钢丝接口尺寸。
2. 检查实际零件切片，打印一块肌肉及其端部，验证可穿线、可拉动、可恢复程度与端部保持。
3. 装入肩部台架，演示钢丝输入经TPU肌肉带动骨段，再接入拮抗回拉。
4. 用视频与观察表记录实物动作，测量可达范围；按卡线、滑脱或干涉位置局部修订，再扩展方向和整臂。

首次演示的判据是实际肌肉传力带动关节并可重复观察。原K1–K7保留作后续比较，不以预先达到某个角度或假定25%收缩作为开始打印的门槛。

## 试制所需资源

- TPU打印设备、喷嘴、材料和切片参数。
- 钢丝、压接件、标准紧固件及台架加工条件。
- 用于记录拉线量、关节动作和恢复情况的拍摄与测量工具。
