# 当前工作基线：从 V2 收敛骨架，再设计钢丝与 TPU 肌肉接口

实施结果（2026-10-29）：骨架几何基线已收敛为 **V2-S1**，见 `design/V2_SKELETON_FREEZE.md` 及 `mujoco_arm/exports/skeleton_from_v2/V2-S1/`。按用户选择保留形态并记录验证范围，K6仍低于旧底线；原目标未降低。可编辑CAD为STEP，原生SolidWorks特征树未回写。下文保留为本轮工作范围记录。

用户于 2026-10-29 明确：先只考虑骨骼结构能否无干涉完成设定动作，不考虑受力；允许在 V2 基础上微调骨骼。骨架确定后，再优化钢丝锚点和 TPU 肌肉接口；若驱动不能覆盖骨架范围，保留目标并报告实际可实现范围。

## 基线与调整边界

- 起点为 `mujoco_arm/cable_design_v2/arm_cable_design_v2.xml`、其源骨骼网格及现有锚点数据；SolidWorks 零位装配为后续回写入口。
- V2 的骨长、关节中心、机构链优先保持。肩胛主体让位、局部轮廓/间隙/连接过渡等属于允许的修正方向，但必须逐项验证。
- 后续探索中的 GH 外移 80 mm、同心三轴及新增钢丝数量不继承为必选参数。
- 骨架阶段可规定关节姿态检查几何。此时既不要求张力平衡，也不以肌肉力、重力、材料强度或电机力限验收。
- 关节限位、骨段方向与实体干涉要分开报告。设置到了某个关节角不等于实体结构可达；现有球窝/销轴配合区的重叠也不能未经检查直接忽略。

## 动作口径

| 动作 | 完整设计目标 | 旧任务书验收底线 |
|---|---:|---:|
| 肘屈曲 |145°|116°|
| GH 前屈 |120°|96°|
| GH 外展 |120°|96°|
| GH 内旋 |70°|56°|
| GH 外旋 |90°|72°|
| 肩胛上回旋 |50°|36°|

同时保留 V2 的肩胛前后滑、内外旋与胸大肌抱合测试，先核实它们的物理测量定义。联合抬升必须测实际骨段姿态，不以 GH 角与肩胛分量的和替代。

V2 已有基础模型及锚点，但其 action 文件中的 K1–K5 是底线角度，K6 为30°、K7为150°，与任务书不同；旧评估还存在再乘80%的口径。不能直接把旧 PASS 当作本轮全范围通过。

## 交付顺序

1. 原始 V2 几何复核、统一指标与干涉清单。
2. 分项骨骼修正及修改前后对照，确定唯一骨架候选和可达范围。
3. 把选定修正回写可编辑 CAD，并复核导出的一致性。
4. 以原 V2 锚点为种子，设计钢丝与 TPU 肌肉接口，检查肌肉变形包络、行程及驱动范围；不能达到时给出具体差距与实际范围。

本轮未重写 V2。第一份只读几何复核输出为 `mujoco_arm/exports/skeleton_from_v2/v2_bone_geometry_baseline.json`；它只检查原始骨骼视觉网格，保留关节区域重叠供分类。仍不能据此宣布最终范围。
