# Goal · 肩胛钢丝主动控制

在现有桌面整臂的胸廓、胸锁和肩锁机构上，用 Seth 肩部模型补足前锯肌与斜方肌的局部传力路线。先验证从中立位主动上回旋一小段并可回位，再对照前伸、后缩的控制方向与限制。

1. 用 OpenSim 原配骨段、肩胛坐标和绕行面计算上回旋时前锯肌、斜方肌及菱形肌的路径、线长和力臂，记录约束、动作范围和源模型版本。
2. 在现有工程骨架上，按解剖附着区和已筛选的安装位置选择工程端点。对局部导向登记固定骨段、接触方向、反力和刚性件间隙。先选一个有连续可用区间的方案。
3. 在 MuJoCo 以正张力驱动肩胛，从中立位给定钢丝拉力，量化上回旋、前后位移及卸载回位。记录关节约束和弹簧阻尼等假设，并把一条受约束动作的结果和自由多轴控制分开报告。复核前伸、后缩探针，登记首个失败因素。
4. 交付锚点及支承坐标、对照数据、可复现脚本和回放。TPU 肌腹、通往驱动器的供线以及实物性能留到后续阶段。

最低演示目标为从中立位主动上回旋至少 2°，回位后偏离中立位不超过 0.5°，并复核所走区间的局部钢丝干涉。前伸和后缩各以一小段可主动运动为目标。若候选因实体相交、力矩方向或反力支撑失败，登记范围和原因，再按同一标准比较下一候选。
