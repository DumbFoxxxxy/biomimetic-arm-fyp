# TPU 晶格首轮打印：知识库依据与待测项

用户确认打印机、喷嘴和材料尚未选定，允许从知识库寻找参考。本轮将 **TPU 95A**
设为材料硬度的起始候选，实际品牌、批次、打印设备和切片配置仍未锁定。
这项选择不改变现有骨骼比例，也不把论文样件性能转移为当前肌肉的能力。

## 原文中能确认的内容

| 项目 | 知识库证据 | 对本项目的用法 |
|---|---|---|
| 柔性材料 | 2026 论文 §4.4 使用 TPU95A；文献 [60] 指向 Bambu Lab TPU 95A HF | 首轮候选硬度 95A；该品牌只是论文来源，不代表已选购或已验证 |
| 成形方式 | §4.4 为 FDM，实验使用 Prusa XL 工具切换设备 | 以 FDM 打印流程设计；具体打印机未选，不把论文设备列为必须购买项 |
| 支撑 | 内部晶格本身可免支撑，外表面和韧带需要支撑；多材料打印时使用 PLA 支撑便于拆除 | 当前异形肌腹还需各自检查悬垂；不能直接断言整个肌肉免支撑 |
| 刚性骨骼 | §4.4 使用 PLA，配合嵌件和螺钉连接 | 骨骼打印的首轮材料参考，尚无本项目承载、蠕变或关节磨损验证 |
| 具体切片参数 | 正文要求参见 Table S2 | 当前知识库全文及笔记中未包含该表；喷嘴、层高、温度、速度均不得冒充已从论文查得 |
| 晶格参考几何 | 早期 PSM 论文 Table I：单元参数 (15,10,30) mm，分支直径 2 mm，TPU95A | 作为样件起始几何；当前肌肉是异形体积映射，边界、方向和端部均不同，需要实测 |

2026 正文列出的两个方向弹性模量为 9.8±0.7 MPa 与 7.4±0.6 MPa，
断裂伸长率分别为 650% 与 480%。这些是该材料/工艺语境下的参考数据，
不等同于当前打印晶格的等效刚度、允许工作应变或疲劳寿命，暂不写入已标定仿真材料。

早期 PSM Table I 的一块样件由 250 mm 缩到 115 mm，且可拉长到 380 mm。
同表的 300 N 是电机—钢丝单元的最大张力，不能写成当前 TPU 肌肉已实现的输出。
上述几何、制造与约束不同，不能按比例保证本项目某块肌肉也能缩短 54%。

## 首轮试验的取舍

先保持 95A 与现有 2 mm 名义杆径，测试短晶格、带钢丝通道的段件以及实际端部连接，
再决定是否要降低硬度、改变杆径或调整单元方向。现阶段不为整块肌肉承诺收缩百分比。
现有肘部候选的横向单元为 15×20 mm、轴向间距为10 mm，并非论文的15×10×30 mm。
早期 PSM Table I 的样件压缩坐标为 x，不能混作 AIS2026 §2.3 的 y 向收缩坐标；肌腹中心线需要单独映射，数值接近不表示各向异性相同。

打印机确定后须记录喷嘴、层高、挤出宽度、温度、速度、冷却、摆放方向、支撑、
材料干燥和批次。先按实际材料与设备的可用配置打印校准件，检查杆件直径、孔道可通线、
支撑能否取出及层间完整性，再打印完整肌腹。

每种样件至少保留三份独立试样，记录循环前后的自然长度、拉线位移、轴向压缩量、
回弹残余、卡线、端部损伤与可获得的力值；没有力传感器时力值保持空白，
不能将电机指令、估计扭矩或手感登记成测得张力。用同一打印配置生成测试件和目标肌肉，
才能据试验修正参数；对照文献曲线不替代自己的标定。

## 2026-11-02：当前方向标定入口

[独立两端夹持的方向／通道样件](../02_人体骨骼晶格肌肉方案/输出/shoulder_design/s1_actuation_calibration/axis_coupons/README.md)已生成8类几何，均未实测。各对使用同一8单元核心、同一XYZ打印朝向，只在受测方向两端设置夹持板。旧z标定件的四面夹持可能产生旁路载荷，不能直接用来冻结未约束晶格各向异性；旧D7预测的刚度比窗口不作为新样件的通过条件，旧记录保留。

P0以名义应力／应变比较样件响应，P1另测钢丝位移与实际缩短；两者都不能直接当作完整异形肌腹的材料模型或驱动能力。生成器的Y中心线映射已实现，但原72对象肌腹未被自动替换。

## S1-Y1父级实际截面检查

当前191对象中冈下肌／肩胛下肌已替换为共形Y晶格，两块其他模块保留旧格；上述72对象描述为历史状态。新增[真实肌腹裁切检查件](../02_人体骨骼晶格肌肉方案/输出/shoulder_design/s1_y_muscle_pair/print_inspection/README.md)，用于观察实际变截面、通道及表面杆，未选定打印参数。

独立检查定位完整源肌腹闭腔：冈下肌1处约13.11811 mm³、肩胛下肌3处共约2.79258 mm³；均不与名义钢丝／完整通道包络相交。小样亦有裁切碎片。必须结合实际切片检查，不可用自动填腔、删片或网格闭合结论替代制造判断；源设计未修改。裁切件无整肌肉夹持边界，不用于直接转移材料／驱动能力。

当前研究起点已切换[S1-Y2](../02_人体骨骼晶格肌肉方案/输出/shoulder_design/s1_y2_transition_stock/README.md)，明确填实两肌腹4处非通道／端接口的封闭过渡空隙，外形／钢丝不移；旧裁切小样不冒充新版本实测。材料、设备与切片仍未选定，新增局部材料对刚度的影响待测。
