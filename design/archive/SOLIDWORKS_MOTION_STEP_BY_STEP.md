# SolidWorks Motion 详细设置步骤

当前工作文件：

```text
D:\XJTLU\PSP\final_model\assembly_cable_paths.SLDASM
```

该文件包含 6 个零件和 14 条静态 3D 路径草图。当前没有运动配合。

## 0 准备运动副本

1. 打开 `assembly_cable_paths.SLDASM`。
2. 选择 `文件 > 另存为`，保存为：

```text
assembly_motion.SLDASM
```

3. 打开 `工具 > 插件`，勾选 `SOLIDWORKS Motion`。
4. 确认单位是 mm、deg、s。
5. 在创建配合时隐藏 14 条 3D 草图，减少误选。

## 1 先完成 K1 肘关节

### 1.1 暂时固定无关零件

1. 在 FeatureManager 中右键 `humerus-1`，选择 `固定`。
2. 确认 `ulna-1` 没有固定。
3. 暂时不需要约束肩胛骨、锁骨和胸廓，因为本阶段只测试尺骨绕肘轴转动。

### 1.2 建立肘铰链

优先使用机械配合：

```text
配合 > 机械配合 > 铰链
```

选择：

- 肱骨远端两个耳孔；
- 尺骨近端铰链孔；
- 端面或中心基准面。

通过标准是：尺骨只能绕肘轴转动，不能沿轴向平移，不能径向脱离。

如果 Hinge 配合不易选择，改用三个普通配合：

1. `同心`：肱骨耳孔与尺骨孔，轴线都沿 B；
2. `重合`：尺骨中央连接舌的中面与肱骨两耳的中面；
3. `角度限制`：0 到 116°。

不要在球面、圆柱面或端面之间额外添加相切配合。

### 1.3 把 E01/E02 路径绑定到零件

当前 14 条路径是固定的装配体草图。不绑定端点时，Motion 中路径长度不会变化。

E01/E02 的点所属关系：

| 点 | 所属零件 |
| --- | --- |
| A | 肱骨 |
| G | 肱骨导眼支架 |
| B | 尺骨 |

操作：

1. 在肱骨零件中建立 A、G 的参考点或命名 3D 草图点。
2. 在尺骨零件中建立 B 的参考点。
3. 回到装配体，编辑 `CAB_E01_PATH`。
4. 对路径草图的三个端点分别添加 `重合`，连接到对应零件中的参考点。
5. 对 `CAB_E02_PATH` 重复相同步骤。
6. 不给路径线段添加固定长度或固定方向，否则零件运动时草图会被锁死。

如果暂时只验证关节运动，可以先不绑定路径，但不能用当前静态草图的长度判断钢丝行程。

### 1.4 新建 Motion Study

1. 在窗口左下角切换到 `Motion Study 1`。
2. 点击运动算例类型下拉框，选择 `Motion Analysis`。
3. 点击 `运动算例属性`。
4. 关闭重力。
5. 关闭 3D Contact 和阻尼。
6. 帧率设为 30 或 60 fps。
7. 将总时长设为 5 s。

### 1.5 添加肘部旋转马达

1. 点击 `马达`。
2. 马达类型选择 `旋转马达`。
3. 选择肘铰链的转动轴。若使用 Hinge 配合，可以直接选择该配合。
4. 运动函数选择 `等速`。
5. 单位改成 `deg/sec`。
6. K1 验收角度 116°，总时长 5 s：

```text
角速度 = 116 / 5 = 23.2 deg/s
```

7. 点击绿色箭头确认方向。正向应使前臂向屈曲方向运动。
8. 点击 `计算`。
9. 播放结果，确认尺骨连续转动，没有跳变、脱离或配合报错。

### 1.6 检查 K1

在 0 s、2.5 s、5 s 分别暂停并检查：

- 尺骨是否只绕肘轴旋转；
- 肘心 E 是否保持不动；
- 是否出现肱骨与尺骨干涉；
- E01 是否缩短；
- E02 是否在反向动作时缩短；
- 路径 B 点是否始终贴在尺骨上。

## 2 建立 GH 三自由度运动链

理想球铰不能直接在三个方向分别加马达，因此 Motion 中使用隐藏辅助件，把球铰拆成三个串联铰链：

```text
肩胛骨
 -> GH 屈伸铰链，轴约沿 B
 -> GH 外展铰链，轴约沿 C
 -> GH 内外旋铰链，轴沿肱骨长轴 A
 -> 肱骨
```

辅助件只需要小方块或圆柱，质量可设为 0.001 kg，建模后隐藏。

### 2.1 GF 组

1. 只激活 GH 屈伸铰链，其余两个铰链锁定。
2. 新建独立运动算例 `K2_GH_Flex`。
3. 在屈伸铰链上加旋转马达。
4. 目标 120°，时间 5 s：

```text
角速度 = 120 / 5 = 24.0 deg/s
```

5. 运行后检查 G01 缩短、G02 反向运动时缩短。
6. 通过后再锁定屈伸轴。

### 2.2 GA 组

1. 只激活 GH 外展铰链。
2. 新建 `K3_GH_Abduction`。
3. 目标 120°，角速度 24.0 deg/s。
4. 检查 G03 缩短、G04 反向。
5. 通过后锁定外展轴。

### 2.3 GR 组

1. 只激活肱骨长轴旋转铰链。
2. 新建 `K4_GH_InternalRotation`，目标 70°。
3. 运行结束后再新建 `K5_GH_ExternalRotation`，目标反向 90°。
4. 检查 G05 和 G06 的方向、路径是否绕肱骨轴线，不能只检查点对点距离。

## 3 建立肩胛骨三自由度

肩胛骨运动链为：

```text
胸廓
 -> 滑动副，沿 e_slide
 -> 上回旋铰链，绕 W 过 P
 -> 内/外旋铰链，绕 U 过 P
 -> 肩胛骨
```

可以使用隐藏辅助件串联三个运动副。不要同时保留完整 SC 两轴万向节和 AC 球铰链，
否则与 3 自由度简化模型发生冲突，造成过约束。

### 3.1 SS 组

1. 锁定肩胛两个旋转轴。
2. 新建 `K_Slide`。
3. 在滑动副上加线性马达。
4. 从 0 到 +15 mm，再反向到 -15 mm。
5. 检查 S03/S04 的长度变化和胸廓间隙。

### 3.2 SU 组

1. 锁定滑动副和肩胛内外旋。
2. 新建 `K6_ScapulaUp`。
3. 在 W 轴上加上回旋马达。
4. 目标 50°，时间 5 s，速度为 10.0 deg/s。
5. 检查 S01 缩短、S02 反向，路径不进入胸廓。

### 3.3 SR 组

1. 锁定滑动和上回旋。
2. 新建 `K_ScapulaRotation`。
3. 在 U 轴上从 -20° 运动到 +20°。
4. 检查 S05/S06 的方向和肩胛外侧间隙。

## 4 K7 组合动作

1. 新建 `K7_Combined`。
2. 同时添加两个旋转马达：

```text
GH 屈曲：120° / 5 s = 24.0 deg/s
肩胛上回旋：50° / 5 s = 10.0 deg/s
```

3. 两个马达必须同时从 0 s 启动。
4. 检查 G01 和 S01 同时缩短，肩胛骨和肱骨之间无碰撞。

## 5 路径长度和答辩输出

在每个 Motion Study 的以下位置保存姿态：

```text
0%
50%
100%
```

对每个姿态使用 `评估 > 测量`，选择同一条路径中的相连线段，记录总长度。

建议输出：

- K1-K7 角度曲线；
- 主动钢丝长度曲线；
- PSM 行程率表；
- Motion 截图；
- 实物与仿真的并排视频。

如果在某一阶段出现报错，停止继续加自由度，先解决当前配合或路径约束问题。
