# 原肘部端部接口接入新骨架

后续已接入两个实际被动转轴，完成三组自由响应及1200保存姿态的独立刚体审查，见[12自由度被动端盖模型](../elbow_passive_model/README.md)。实际弯曲通道与TPU端部反力仍需继续接入，不能据此认定实物传力已验证。

保留原FJ1486/FJ1477晶格肌腹、端盖位置及钢丝路径，恢复83个原有刚性接口零件：近端转接支架、骨侧连接件、安装五金、远端转轴架及保持件。本轮未采用肌腹移位或凸轮联动，也未重新生成原肌腹。两块TPU显示源的文件指纹保持。

## 安装座修订

初次恢复后，11537个涉及新增接口的刚性配对中，只发现四根原M3安装螺栓与新肱骨重叠；记录保留在父级elbow_interface_integration/assembly.json。原因是统一骨干保留新肩端时没有同时恢复这四处肘肌肉安装接口。

本候选按原设计的四根螺栓轴线恢复前后承压凸台（半径4.5 mm）和贯通孔（半径1.7 mm）。轴线与实际螺栓网格核对，未移动螺栓、端盖、骨段或关节中心。肱骨新增约1404.951 mm³、切除约795.763 mm³；GH与肘中心各45 mm保护球域的材料变化均为零。

修订肱骨导出为单个连通正体积实体，回读通过；与其余180个刚性对象求交，未发现超过0.001 mm³的重叠。新增接口间及其与其他对象的关系沿用前述父级配对，相关来源未改变。此项是零位名义几何配合，不证明螺纹、预紧、握持、孔壁强度或装配顺序。

## 传力关系和未决项

近端路径为肌腹／端盖→原转接支架→四轴M3骨侧接口→肱骨；远端路径经原旋转端盖／轴销保持包→骨侧转轴架→前臂。实际钢丝终端、导管反力和短肌腱仍需分别核对，不能把端垫中心当作骨孔。

两套远端端盖在原清单中分别属于FJ1486_distal_pivot、FJ1477_distal_pivot，不能简单刚接到前臂并宣称运动通过。下一步建立这两个被动转轴的坐标、转动限位及恢复／摩擦模型，由钢丝和TPU受力计算端盖姿态，再检查连同肩肘运动的整段通道。旧10自由度端点代理动态结果不自动包含这些端部自由度。

TPU原件仅作为原形显示保留，未据此宣称其网格合格或柔性变形已验证。当前末端夹线／压接仍需实际保持验证，已计算的约56 N峰值张力并非这些终端的已验证承载能力。
