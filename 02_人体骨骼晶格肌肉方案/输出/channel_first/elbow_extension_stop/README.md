# 肘伸展实体止挡候选

后续[2s周期与安装检查](CYCLE_REVIEW.md)：三组零缓冲软接触返回止挡时出现超阈值数值压入，不能继承下述0.2s局部通过为完整周期通过；另有单独保守接触缓冲候选，状态以其独立审查为准。

2026-11-08。最终装配仍为胸廓通过底座立于桌面，无工程背板。本目录是局部肘接口候选，不替换主骨架指针，也未改变原肘肌腹、原钢丝通道或 K1–K7 指标。

## 为什么增加止挡

上一阶段的实际弯曲通道梁模型在肘 −0.393° 时，伸肌端盖转子进入肱骨。该端盖相对前臂只转动约 −0.00124°，不能以强迫端盖联动、增加肌腹刚度或挖去连接部位解决。原软件 −5° 下限也不是实体止挡。

本候选在前臂关节毂增加一体连接的止挡凸耳，在肱骨叉耳外侧增加可拆卸固定臂，由两套 M3 通孔螺栓、垫片及背侧螺母连接。先装入前臂、销轴及原保持件，再安装止挡臂。实际插入路径、工具空间、预紧及强度尚未验证；不能据此制造定版。

## 几何及接触

`assembly.json` 给出源坐标、关节局部坐标框架、192 件刚体、两原肌腹显示源及文件指纹。接触面为局部 x=26..30、y=−18..−10、z=10 mm 的32 mm²平面；名义伸展止位0°，力臂中心约14 mm。固定臂及所有新增凸台必须单体连通，不移除孤岛来制造通过。失败几何保存在 `trial_history_*.json`。

- 零位：对所有涉及新增／修改部件的配对检查，无 >0.001 mm³ 重叠；导出后精确回读、拓扑及体积核对通过。
- `motion_screen.json`：肘0–30°去程和回程、1°采样，所有相对移动配对无超阈值重叠；两个端盖相对前臂保持零转角。只允许零体积的面接触，不排除整个部件对。
- −0.1°几何探针首先压入预期止挡，体积0.7802 mm³；−0.4°还会碰旧端盖，属于越过止挡的禁止姿态。探针用于确定止挡位置，不能作为可达姿态。
- 30°只是局部筛查上限，未评估完整K目标，也不代表实际驱动范围。正向无失败边界可细化；负向探针间距0.1°。

## 实际受力短时模型

`model.xml` 延用294速度自由度的两条原弯曲通道弹性梁、被动端盖、肩胛支承及其余25条端点代理。新增两接触盒与实际止挡块一一对应；其余骨骼、端盖和五金没有接触响应，必须另做实体审查。肘软件角度限位关闭，由接触力限制伸展，没有指定关节角度。恢复刚度、阻尼、质量及接触参数都未实测。

止挡采用无摩擦单边接触，MuJoCo `solref=(-1e8,-20000)`、`solimp=(.9999,.9999,.0001)`。这是未标定的高刚度数值假设，不能据极小计算压入量推断实物刚度／精度。新增打印件密度1200、钢件7800 kg/m³；骨段质量及惯量仍为估计。

`short_response.json`：时间步20 µs，0.2 s自由受力响应，屈肌卷线0→2→0 mm；钢丝只拉、可松弛，60 N张力上限。接触后预测肘范围约 −0.00000046° 至1.779°。无数值警告、无张力饱和，最大通道轴向应变0.00403；端部平移等式最大残差0.0953 mm。最大计算接触压入约1.72e−7 mm，仅属该数值接触律。

`wire_solid_screen.json`：111保存姿态，最大旋转采样增量0.5203°；两条半径0.3 mm钢丝对192刚体，以及14156跨体刚体对均未发现 >0.001 mm³ 重叠。接触面没有整对豁免。此为离散筛查，不是连续全姿态证明。

TPU管壁／完整晶格、孔腔压扁、内部摩擦、终端尾线、供线导管及胸廓驱动器尚未包含；0.2 s曲线也不是完整恢复周期。原肌腹外形未更换，此模型中的线和梁不能冒充实际晶格变形。

## 复现

在项目根目录的 PowerShell 中使用已安装MuJoCo的Python：

```powershell
$env:PYTHONPATH='tools;.deps'
D:/MujocoEnv/Scripts/python.exe tools/build_channel_first_elbow_extension_stop.py
D:/MujocoEnv/Scripts/python.exe tools/audit_channel_first_elbow_extension_stop.py
D:/MujocoEnv/Scripts/python.exe tools/build_channel_first_elbow_stop_model.py
D:/MujocoEnv/Scripts/python.exe tools/simulate_channel_first_elbow_channel_beams.py --folder '02_人体骨骼晶格肌肉方案/输出/channel_first/elbow_extension_stop'
D:/MujocoEnv/Scripts/python.exe tools/audit_channel_first_elbow_channel_beams.py --folder '02_人体骨骼晶格肌肉方案/输出/channel_first/elbow_extension_stop'
```

需要上游已生成的 `elbow_mount_candidate`、`elbow_passive_model`、`elbow_channel_beams`。本目录文件记录上游指纹，不能将旧响应套到改后的几何。
