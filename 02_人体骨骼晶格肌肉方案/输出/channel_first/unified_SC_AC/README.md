## 几何构造与检查

锁骨采用既有AC工程增减材。肩胛骨的初次薄皮差集移植产生非流形导出，精确OBJ及STL尝试都曾拒绝，记录保留在generation_failure.json；该文件是被后续构造替代的历史失败，不是当前assembly.json的状态。

当前肩胛构造改为AC中心35/36 mm局部体积重建，并保护GH中心26 mm范围；27/26 mm保护过渡与AC边界共同形成重叠连接带。导出后单个正体积实体回读通过，网格清理相对构造的材料变化约0.000030 mm³；GH保护区材料变化约0.000117 mm³，均小于0.001 mm³筛查阈值。不得把此构造解释为删除GH连接来获得通过。

98个对象的2673配对检查包括全部跨刚体对和新增AC零件内部关系，零位未发现大于0.001 mm³的实体相交。球窝后座和骨骼、两端连接颈部均保持连通。两套SC/AC保持盖及螺栓是名义几何，螺纹、装入顺序、防脱载荷与制造公差未验证。

## 运动学探针

理想链为10速度自由度、98可视几何体，0.1 s重力积分保持有限。SC/AC/GH各轴正负10°、肘0–30°按1°探针，对2478跨刚体对逐姿态求交。

- AC三轴正方向至10°检查上限均未发现实体相交；负方向在−1°采样时肩胛骨接触肋骨。
- SC轴0/1正10°清、负1°碰肋；轴2负方向最后清楚采样−8°，正方向最后清楚采样1°。
- GH多数方向到±10°检查上限；负轴1在−10°时肱骨／肘部五金触及胸廓。
- 肘0–30°采样未发现重叠。

局部轴不等于解剖动作角，10°/30°是本轮检查上限，不是动作验收指标。尚未完成回程或0.1°边界细化，更不是钢丝驱动范围。SC或AC单独转动会把肩胛带入胸壁，因此下一步应研究SC—AC协调路径、肩胛胸壁支承及其受力，不能把肋骨删除，也不能将这些单轴探针直接当作联合动作极限。
