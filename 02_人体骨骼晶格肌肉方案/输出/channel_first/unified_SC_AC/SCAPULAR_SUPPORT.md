# 新骨形上的肩胛胸廓支承检查

在当前SC—AC骨骼上重新投影前锯肌邻近肩胛区域及右侧肋骨，选择12个分布候选，不直接继承旧骨骼的接触位置或反力结果。所有支承只允许朝向肩胛的压缩法向力，无拉力、无切向力。

## 中立位方向分配

27条端点肌群＋12个骨面反力候选，在每处反力上限20 N时，中立位力矩残差从0.573降为约0.00146 N·m。提高反力上限到60/120 N后残差基本不变；结果是近似静力分配，不是严格全自由度平衡或实体驱动通过。

在保持同一可实现反力向量的前提下最小化总力，可选三处候选：

| 候选编号 | 骨面间隙 mm | 中立位反力 N |
|---|---:|---:|
| 4 | 6.721 | 20.000 |
| 5 | 10.523 | 14.332 |
| 9 | 4.312 | 5.396 |

这些编号不是已制造的支承件。需要有真实厚度、骨侧固定和肩胛接触面，才能形成模型中的反力。胸廓仍由桌面底座固定，不采用工程背板。

## 支承必须按压缩和接触范围激活

进一步采用三块未标定的肋骨侧固定圆形支承垫候选：有效半径12 mm、刚度10 N/mm。原长按中立位间隙及预压力反推。肩胛接触点随骨段移动；分离或超出垫面时法向力为零，压缩时按实际压缩量计算，不再由优化器任意分配。

| 协调路径 | 首次少于三处接触的SC采样角 ° | 端点剩余接触数 | 端点力矩残差 N·m |
|---|---:|---:|---:|
| 轴0负 | −0.483 | 0 | 1.684 |
| 轴0正 | +1.000 | 0 | 1.928 |
| 轴1负 | −0.950 | 1 | 1.516 |
| 轴1正 | +1.000 | 0 | 1.786 |
| 轴2负 | −0.481 | 0 | 1.180 |
| 轴2正 | +1.000 | 0 | 2.183 |

不同路径采样间隔不同，表中是首次记录到接触改变的姿态，不是精确分离边界。所有样本未记录压到底，但轴1负方向单垫力达到约57.8 N，超过初始反力分配使用的20 N探索上限；这不是已验证的安全载荷。没有通过力截断掩盖此差异。

## 当前判断

新骨面的压缩反力方向有助于中立位平衡，但三块固定位置平面垫不能直接维持原协调路径。不能沿全程套用中立位反力，也不能让已经脱离的垫继续推骨骼。下一步应同时求解SC/AC协调、肩胛胸壁接触随动及支承压缩，再选实体导向／支承结构；随后重算钢丝路径、行程及动态驱动。

当前垫是有骨侧归属和有限作用范围的条件模型，未完成曲面足印、安装、强度、接触材料、摩擦或实体运动验证。27条肌群仍是端点作用方向代理，不能把本试算当作完整钢丝—TPU方案完成。

复现依次运行`tools/study_channel_first_scapular_support.py --unified-sc-ac`及`tools/study_channel_first_unified_pad_engagement.py`。位置、法向、力和来源记录在scapulothoracic_support_direction_screen.json及passive_pad_engagement_paths.json中。原K指标、原始模型和主指针保留。
