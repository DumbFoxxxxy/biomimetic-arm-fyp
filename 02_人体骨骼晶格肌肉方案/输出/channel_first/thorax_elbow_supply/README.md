# 胸廓到肘部入口的两条外供线候选

2026-11-08。胸骨局部座与原肘近端端头之间，已得到两条没有中间固定导向点的零位曲线，并导出真实中空参考壳体。当前仅是外供线几何候选，不是完成的全臂驱动设计；其余肩部／肩带路径尚未由此完成。

## 路径与支承

路径从胸骨座中导管实际承压台阶，经端头出孔，沿候选曲线进入肘近端金属端头，最终落在肱骨所属的导管承压台阶。仅两端有名义端头支承；Bezier控制点定义未受力形状，不作为空间固定导向。端头外的8mm直线尾段也是可变形节点，不新增刚性夹持。

| 路径 | 胸廓实际座中心 X/Y/Z，mm | 肱骨所属实际座中心，mm | 零位中心线长度 | 候选最小弯曲半径 |
|---|---|---|---:|---:|
| FJ1486屈肌 | −57 / −235 / 1236 | −185.71493 / −97.82312 / 1224.77969 | 214.905mm | 13.087mm |
| FJ1477伸肌 | −57 / −235 / 1272 | −179.07486 / −45.22341 / 1294.07952 | 308.969mm | 25.504mm |

长度是两承压座之间的导管中心线路径长，不是电机收线行程或TPU肌腹缩短量。胸廓端的电机及内侧卷线段未设计；肘端经原端盖通孔进入原肌肉通道，原远端钢丝终端本轮未重新验证。

胸廓端向外轴线为(−1,0,0)，肘端向外轴线为(0.172585,−0.014178,0.984893)。有限4mm插入段的夹持、扭转及防拔出均待验证；后续动力学必须在实际台阶处施加端部支承，不能把旧绿色短管尖端固定到世界或骨段上。

## 几何筛查

屈肌比较25组曲线，首组通过；伸肌有24组满足探索性8mm最小半径条件，检查到第14组通过。8mm只是未标定的几何探索阈值，不是钢丝／导管的实测能力或产品规格。

`route_screen.json`保留所有尝试。通过的曲线以801个Bezier采样点及两端座／出孔组成805点路径，曲线段最大弦长约0.312/0.524mm；包含平端面的外半径1.5mm包络及半径0.3mm钢丝，对235个实际刚体无>0.001mm³相交。两外包络的名义间隙至少达到本次0.5mm筛查上限；未宣称数学连续曲线证明。

`sheath_geometry.json`记录参数化扫掠壳体：外半径1.5mm、孔半径0.6mm、32边圆周、805圈截面，壁厚名义0.9mm，两端平口。导出后精确重载，正材料各连通，对235刚体仍无超阈值相交，两壳体也不相交；体积回读相对误差约0至1.25e−16。

这些是未选材料的参考通道壳体，未证明轴向抗压、弯曲恢复、孔腔稳定、摩擦或制造性能。肩部完整TPU肌腹及其变形接触也未纳入；原肘TPU只是保持原形的显示源。真实加载后曲线可能改变，不能用此静态结果冻结走线。

## 整臂查看：明确是零位场景

`neutral_geometry.xml`专门设置为0自由度，239个显示网格=235刚体＋原肘两块TPU＋两中空外导管参考。这里没有把805个空间点加入运动模型作为固定导向。它可360°查看布局，但不能播放外导管变形或驱动动作。

红色为未改动的原肘TPU晶格，绿色为未加载外导管参考，蓝色为胸骨局部反力座。肩部完整肌腹、电机和桌面底座未显示为已完成结构。

## 复现

先生成胸骨反力座及模型。项目根目录PowerShell中：

```powershell
$env:PYTHONPATH='tools;.deps'
D:/MujocoEnv/Scripts/python.exe tools/screen_channel_first_thorax_elbow_supply.py
D:/MujocoEnv/Scripts/python.exe tools/build_channel_first_external_sheaths.py
D:/MujocoEnv/Scripts/python.exe tools/render_channel_first_external_supply.py
D:/MujocoEnv/Scripts/python.exe tools/view_channel_first_supply_geometry.py
```

`--check`已验证静态模型加载及239个源文件指纹，GUI本轮未启动。下一步把两外导管接入自由弯曲／轴向压缩的模型，将钢丝路径接到胸廓端，核对真实外反力、通道变形、骨接触和收放线；随后补实际驱动器、其余功能肌群及完整晶格。主骨架指针未切换。
