# 胸锁球窝连接候选

在统一肩肘骨架上接入既有参数化SC球窝构造：球头半径10 mm、球窝半径10.35 mm、连接颈部半径4.5 mm、两块分体保持盖及两组M3螺栓包络。实际螺纹、预紧、公差、防脱载荷和安装尚未验证。

SC中心保持原位。锁骨与胸骨柄仅在距SC中心36 mm球域内修订，球域外相对父级的实体变化小于0.001 mm³。颈部和后座仍与对应骨骼连通，各导出件通过单实体正体积及回读检查；没有通过删除连接部位消除重叠。文件保留父级来源、局部增减体积和旧SC设计参数。

88对象候选的2323配对检查（所有跨刚体对，另加SC零件内部配对）未发现大于0.001 mm³重叠。原319.292 mm³锁骨—胸骨柄重叠已不再存在。本候选独立存放，尚未替换CHANNEL_FIRST_SKELETON或历史S1指针。

## 小角度运动探针

88几何体／10速度自由度理想链已生成，0.1 s重力积分保持有限。1748跨刚体对纳入实体求交，零位清楚。SC及GH的三个局部坐标轴分别尝试正负10°，肘尝试0–30°，均按1°采样，出现首次重叠即停止该方向。输入为运动学姿态探针，不是钢丝驱动验证；未完成回程、0.1°边界细化或K指标。

- SC局部轴0和1的正方向到10°检查上限未发现重叠；负方向在−1°采样时肩胛骨与肋骨相交。
- SC局部轴2负方向最后清楚采样为−8°、−9°锁骨与肋骨相交；正方向最后清楚采样为1°、2°肩胛骨与肋骨相交。
- GH多数方向到±10°检查上限；局部轴1负方向在−10°采样时肱骨／肘部五金与胸廓相交，最后清楚采样−9°。
- 肘0–30°采样未发现刚体重叠。

以上局部轴不是人体标准动作角，也不是实际可达范围。SC独立转动会带动全部下游骨段，AC保持零位；肩胛撞肋提示需要检查SC—AC联合运动和胸壁接触，而不是直接删除肋骨或将相邻碰撞整体排除。
