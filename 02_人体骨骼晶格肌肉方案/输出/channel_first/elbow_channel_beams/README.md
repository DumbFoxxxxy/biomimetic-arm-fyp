# 原肘部弯曲通道的弹性梁模型

将两块原肘部肌肉的钢丝路径（近端孔口至远端孔口）接入被动端盖模型。每条通道采用轴向与转动弹簧阻尼单元，近端依附现有肱骨侧框架，远端位置连接对应被动端盖孔口；中间节点由弹性单元支承并随受力运动，没有世界固定的悬空路径点。

模型共294速度自由度。原路径按不超过5 mm弧长间隔离散，端点源坐标及中立位连接约束核对通过。模拟参考管外／内半径1.6/0.8 mm、模量15 MPa，未标定；原制造几何和其孔径未改变。它不代表完整原晶格的轴向／弯曲刚度。两条原端点200 N/m恢复弹簧移除，避免直接重复计入；端盖0.02 N·m/rad的等效恢复作用暂保留，仍需核对其与真实TPU端部的分工。

## 短时自由响应

0.2 s内以可用线长输入使屈肌收线2 mm、保持并放回。积分步长20 μs，关节角和通道变形不预设。无数值警告、无60 N张力饱和；最大分段轴向应变幅值约0.00422，未触发±50%数值保护。端部连接约束最大误差约0.0958 mm，后续需随时间及空间离散进一步核对，不能称为精确刚接。

初次固定2 ms记录的最大局部转角增量约2.05°，不足以满足1°采样要求。当前采用最长2 ms加0.5°旋转触发的自适应保存，最终115个姿态，最大实际相邻关节转角约0.520°。广义位移数组包含转动rad和滑移m，按MuJoCo切空间坐标重建，不能全部理解为角度。

## 这次试算没有通过实体运动验收

两条钢丝的完整分段胶囊包络（半径0.3 mm）在115个保存姿态中对181刚体未发现超过0.001 mm³重叠；未排除端口或相邻骨骼。但刚体相互求交在第39个检查姿态、约0.05402 s发现：肱骨与FJ1477端盖转子相交0.00217 mm³。模型没有施加该处刚性接触反力，故之后的自由空间状态不能视作实际可达运动，即使钢丝本身没有碰撞。

接触时肘角约−0.393°，屈肌端盖约−2.320°，伸肌端盖自身转角仅−0.00124°。因此不能简单归因为伸肌端盖旋转过大，也不能盲目增大端盖恢复刚度或挖除肱骨。应优先核对肘部伸展方向的实际限位和接触结构。当前理想肘关节允许−5°，该软件范围尚无相应物理止挡验证。

局部相交范围约x[-217.549,-216.720]、y[-53.526,-53.415]、z[1085.349,1086.099] mm。定位保存在first_overlap_localization.json，首次失败及钢丝检查保存在wire_solid_screen.json。

## 后续工作

设计可装配的肘部伸展止挡／合法接触面，核对其反力和刚体捕获，再重算实际曲线响应。不能把这一干涉改成整对碰撞豁免，也不能只在仿真里收紧限位就声称实体完成。随后需加入通道与骨／五金接触、自接触、孔腔压扁、内部摩擦及完整晶格恢复作用，完善端部局部安装边界、终端尾线和胸廓供线。其余25条肌群仍为端点代理，三个颈段支承缺项尚未完成。
