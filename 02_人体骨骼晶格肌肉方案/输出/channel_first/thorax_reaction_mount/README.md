# 胸骨局部双路供线反力座候选

2026-11-08。本候选将两条肘部外导管的胸廓端安装在胸骨前侧，不使用工程背板。主体为20×62×4mm的局部安装条、两条向侧方伸出的开放支承臂和两个法兰端头座。电机、卷线器和桌面底座仍未设计完成，不能把该局部座当作完整驱动器。

`assembly.json`列出235个刚体，继承原208件肘／肩骨架及接口，只修改胸骨本体FJ3178、增加27个胸廓侧部件。原肌腹、肩关节中心、骨段比例及原肘部锚点保持。

## 胸骨连接

源坐标单位mm，沿前后方向的源网格射线交点用于确定安装面，不用最近点投影代替骨厚：

| 孔位 | X / Z | 原骨前表面Y | 后表面Y | 轴向骨厚 | 名义M3长度 |
|---|---|---:|---:|---:|---:|
| 下位 | 0 / 1230 | −199.83492 | −182.53413 | 17.30079 | 50mm |
| 上位 | 0 / 1260 | −191.54427 | −172.65393 | 18.89034 | 60mm |

局部增加半径5mm、向表面外伸2mm的前后承压台，贯穿孔半径1.7mm；前侧两个独立间隔套连接安装条与胸骨承压台。M3前垫片、后垫片及螺母均有几何包络，真实螺纹、预紧、承载、手部及工具空间未验证。胸骨新增约580.82mm³、移除约326.34mm³，原源文件保留。

原胸骨网格含0.002519mm³的独立小片，距主体约0.24565mm。保留该片，增加半径0.3mm的局部连接，新增材料约0.13943mm³，并对邻近右第五肋软骨FJ3341让位约0.01937mm³；没有删除碎片或改变关节点。此微小网格修补不是承载连接，其制造保真性未验证，详情在`fit_screen.json/source_fragment_repairs`。

## 实际反力端口

| 路径 | 导管实际承压台阶中心 X/Y/Z | 端头出孔中心 | 向外轴线 |
|---|---|---|---|
| FJ1486屈肌 | −57 / −235 / 1236 | −61 / −235 / 1236 | −1 / 0 / 0 |
| FJ1477伸肌 | −57 / −235 / 1272 | −61 / −235 / 1272 | 同上 |

两端头采用与肘近端接口对应的外径4mm主体、外径6mm法兰及双M2压板；导管插入4mm。法兰有名义保持结构，导管与金属端头的压接／粘接防拔出仍待确定。参考短管末端不是固定点。

反力传递链为端头内台阶→端头底部→一体供线座／支承臂→M3安装条与间隔套→胸骨承压台。胸骨经肋软骨／肋骨／胸椎到桌面底座的整体机械连接仍未验证；当前动力学中的thorax固定于世界只是研究假设。

## 验证范围

`fit_screen.json`与精确导出重载的`export_screen.json`均未发现新增／修改材料造成的>0.001mm³穿透。新增部件与修订胸骨各为单一正材料连通体，未通过删除孤岛获得通过，导出体积相对误差约0至1.34e−16。

原胸骨与剑突、胸骨柄及肋软骨共14处源解剖接合重叠保留。每对均记录原交叠体积、当前体积，并单独检查新增材料，而不是整对排除检查。这14处仍需确认融合／装配方式，不能据“新增零件配合清”宣布整个胸廓无实体穿透或可装配。

`installation_screen.json`完成两间隔套、预装双端头框架、两组M3前后件共7阶段687姿态的局部安装筛查，平移步长0.5mm，均无超阈值相交。框架从前方60mm处进入，M3前组从65mm、后组从45mm处进入。端头模块视为预装完成，间隔套及胸廓由人工保持；模块预装、实际拧紧／工具、完整胸廓装配及底座不在该结果内。

`model.xml`是294速度自由度、244显示几何的共同模型，新增支架属于固定thorax，只接入几何，没有加入外导管力或新的电机。不得将原208件局部驱动结果直接转移为235件外供线驱动通过。
