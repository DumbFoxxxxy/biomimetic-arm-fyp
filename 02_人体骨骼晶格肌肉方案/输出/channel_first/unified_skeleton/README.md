跨刚体1498对实体的零位检查发现：胸骨柄FJ3290与锁骨相交319.292 mm³。SC邻近重叠坐标已保存于`SC_overlap_localization.json`。这项更完整的检查覆盖了此前四骨六对检查之外的胸廓关系，因此后续角度探针尚未运行，也没有可达范围结论。下一步设计胸锁关节实体连接和间隙，不能把该骨对整体排除或将初始穿透当成合法关节接触。

复现：`tools/build_channel_first_body_chain.py --unified --geometry-mass`，随后`tools/audit_channel_first_unified_motion.py`。新输出在本目录，旧参照的动力学模型未覆盖。SC/AC仍是理想球关节假设，非已完成的实体连接。

本目录是通道优先路线的当前骨骼几何基准候选，入口为 `design/CHANNEL_FIRST_SKELETON.json`。状态为静态几何候选；尚未完成整臂运动、安装或驱动验收。历史S1-Y2及原共享肱骨均未覆盖。

## 结构选择

- 胸廓及前臂保留原参照。锁骨、肩胛骨取S1-Y2选择中的实际骨件。
- 肱骨上段取S1-Y2肩端，下段取原共享肱骨的肘端。骨段位置、关节中心及坐标变换没有调整。
- 在既有骨干坐标的110 mm站位重建单体，109–111 mm材料重叠。108–112 mm检查带内，两来源对称体积差约1.2×10⁻¹² mm³，共同材料约1465.16 mm³。
- 导出后为一个正体积连通实体。检查带上、下方相对各自来源的差异均小于0.001 mm³。这里的接合是数字几何重建；不要求实物打印后粘接两段骨。
- 工程背板和台架夹具不进入该参照。胸廓桌面底座、胸锁和肩锁实际连接仍待设计，不能把未安装连接当作已存在。

## 文件及复现

- `humerus.obj`：带明确平移的局部坐标精确OBJ，平移记录在assembly.json中；不要按世界坐标直接摆放。
- `assembly.json`：骨骼来源、变换、接合与接口复核；关节环境单列。
- `joint_context_scene.json`：骨骼及关节环境静态查看场景。
- `channel_screen.json`：85对象零位通道检查及四骨六对检查。

使用项目Python环境、将`tools`和`.deps`加入导入路径，运行 `tools/build_channel_first_unified_skeleton.py`，随后运行 `tools/audit_channel_first_unified_channels.py`。

交互查看入口：`mujoco_arm/tools/view_shoulder_manufactured.py --report 02_人体骨骼晶格肌肉方案/输出/channel_first/unified_skeleton/joint_context_scene.json`。已验证78个几何体、0自由度加载；这是可旋转的静态检查场景，不是可驱动装配。后续需接入统一关节链，完成刚体连续运动、端座和钢丝驱动，再讨论定版。
