# 支架到背板／局部台面的安装候选

2026-11-02。以92对象近端配合版为输入，保留骨骼、肌腹、钢丝及自由末端，替换两支架的基座孔座，并增加30个对象，合成122对象独立候选。**尚缺肩胛及锁骨夹爪，不能视为完整固定台架或驱动定版。**

## 结构与名义尺寸

内侧基座Z为1346.034–1352.034 mm，外侧1258.372–1264.372 mm。原两基座都为40×30×6 mm，不能假设两者放在同一水平桌面。公共背板沿XZ布置，主板225×148×6 mm，Y30–36 mm；两支脚30×75×8 mm向背侧延伸，各有两根错开M6轴线的R4斜撑。主板、支脚与斜撑联合为一个实际实体。

每基座增加两个R6一体孔座，沿Y开直径4.4 mm孔。内侧孔X相对基座左边12／30 mm；外侧22／36 mm，Z相对基座中面−2 mm，保留原骨侧端点位置。两对隔套长约13.236／16.553 mm，外径12、孔径4.4 mm，补足基座后面至背板的间隔。

## 连接路径与安装次序

支架加强孔座 → 近侧垫圈／M4螺钉 → 隔套 → 背板 → 远侧垫圈／螺母；背板与支脚同一实体，经两组M6及垫圈／螺母连接台面接口片。具体压紧力、摩擦、抗弯和防松未计算或测试。

建议先装支架、隔套与背板，再装背板支脚至实际台面，最后安装骨骼／肌肉。6根螺钉在仅含支架／背板／台面／五金的场景中，向螺钉头方向抽出至70／45 mm未超相交阈值；这只是几何插拔的逆路径，不是整套装配顺序已验证。

完整未变形场景中，外侧第二根M4沿−Y抽出7.7 mm首先碰肩胛，不能声称安装骨骼后可从原方向拆卸该螺钉。螺母／垫圈进入、工具包络及后续夹骨安装均未验证。若要求带骨原位维护，需要另行修改接口或安装策略。
