## 4. 安装顺序与维护条件

拟定顺序为：先连接两支架和背板，再放置骨骼／衬垫、安装浮动爪与M3，最后安装肌腹。**骨骼装入、夹具螺母／垫圈进入、工具及完整顺序尚未验证。** 松开五金后爪的抽出，不等于前面的拆螺钉动作已在全部肌肉存在时通过。

六枚M3的最短轴向清出行程按各自长度+0.1 mm登记，裸骨台架中均未超阈值：

- 内侧中段两螺钉在27.3／28.0 mm额外抽出时碰背板，已超过所需20.1 mm；不把这个额外空间首限误判为无法清出螺孔。清出后的侧向转移仍未验证。
- 上角两螺钉在受检轴向行程内未超阈值。
- 外侧两M3在完整场景抽出16.0／22.3 mm碰三角肌，均早于所需30.1 mm；需要先安装夹具再安装肌腹。完整装肌后原位拆卸未通过，不能假定TPU随意变形就可绕开。

此前六根背板／台面螺钉已对新支架重新检查：未装骨／肌肉时所测路径仍清；装骨后的原外侧第二M4受阻记录保持。当前方案不是所有维护步骤均可原位进行的结构。
