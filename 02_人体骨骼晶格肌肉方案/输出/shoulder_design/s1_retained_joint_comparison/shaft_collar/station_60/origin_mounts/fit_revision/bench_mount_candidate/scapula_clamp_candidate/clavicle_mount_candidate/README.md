# 锁骨可拆抱夹与背板支承候选

2026-11-02。以155对象肩胛夹持版为父级，新增20对象并替换穿两孔后的背板，得到175对象独立候选。**骨骼、GH、四块肌腹、钢丝及原肩胛夹区源文件保持不变；锁骨不钻孔。** 此处是S1固定锁骨的台架几何候选，不是可运动SC关节、六自由度固定证明或驱动定版。

## 1. 局部基准

沿既有SC→AC参考轴取15 mm站位，在±6 mm按1 mm截取锁骨实体截面，计算面积加权质心并线性拟合局部轨迹。局部原点约为源坐标[-29.0882,-137.5391,1326.1266] mm；骨干切线约[-0.97308,-0.01248,0.23011]，XY分量拟合RMS约0.133 mm。

这是夹具定位坐标，不是新的SC/AC/GH中心，也不是关节标定误差。SC参考轴站位不等于沿弯曲骨干测得的实际骨长。原始表面顶点较稀，直接局部PCA主轴不稳定，故采用截面质心轨迹。站位、截面及拟合数据完整记录在[生成报告](assembly_check.json)。

局部骨干±6 mm按0.5 mm采样截面，联合凸包后形成外包轮廓；TPU外包再偏置1 mm，刚性型腔额外留0.02 mm，刚性壳壁名义3 mm。衬垫内面按实际骨形与拆卸方向开敞，不宣称均匀法向厚度、打印精度或预压量。

## 3. 开敞腔与实际读回

仅按骨面配合会留下倒扣：初版零位合格后，前夹体移动0.1 mm就碰前衬垫，锁骨移动0.1 mm碰后衬垫。当前用20 mm连续棱柱Minkowski包络，分别按骨／衬垫的相对运动方向开敞两半的内面，并明确0.02 mm横向模型间隙。没有用假定TPU任意变形或把松衬垫刚性粘在夹体上获得通过。

[装配报告](assembly_check.json)和[独立回读／接触／路径检查](readback_contact_checks.json)分别保留输入哈希、变换和检查范围。

- 175对象全部单正材料实体、零边界／非流形边；15225对零位检查无超0.001 mm³刚性相交。
- 21个新增／替换对象对全体未出现超阈值新增相交；六路主动线对全部175对象相交为0。
- 两M3与两M4轴杆孔路均清，实际孔径包络也未侵入锁骨；不是以整对排除骨／夹体相交。
- 衬垫—骨、衬垫—夹体、法兰—背板及五金承靠面共21对，沿对应法向推进0.05 mm均遇到材料；名义间隙最大约0.01999 mm。接触不等于预紧、摩擦或强度合格。
- 原三角肌／肩胛约1.84044 mm³柔性重叠、通道壁残差和自由肌腹末端仍待验证，旧角度不转移到本结构。

## 4. 受检拆卸步骤与顺序限制

全部平移路径按1 mm采样，首个边界细化至0.1 mm；不是数学连续性证明，也不是完整装配／工具验收。

1. 两M3×20和两M4×20的轴向抽出已检查，所需清出近侧垫圈行程20.1 mm均未超阈值。仅验证清出，不涵盖螺纹旋转、扳手进入、螺母／垫圈放入和随后转移。
2. 取下抱夹两组M3五金后，前半夹体沿局部前向抽出20 mm，衬垫留在名义位置，未检出超阈值相交。
3. 再取下前衬垫，未装肌肉的骨骼／夹具场景中，锁骨沿同方向20 mm路径清。完整固定未变形肌腹场景中，锁骨移动0.6 mm接触三角肌；**当前需要先骨骼／夹具、后肌腹，不能宣称带肌肉原位取出锁骨通过。** 柔性真实变形未求解，这也不是物理上绝对无法拆出的证明。
4. 假设锁骨、两衬垫、前半夹体及M3/M4五金已移除，单独支承沿源−Y离开背板30 mm路径清。各前置步骤必须先成立，不能拼成未经检查的整套安装结论。

三处肩胛整骨装入、此前外侧M3被三角肌遮挡、背板外侧M4装骨后抽出受阻等记录仍保留。尚未完成完整肩部装配图谱或所有原位维护路径。
