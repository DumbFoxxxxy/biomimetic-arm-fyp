# 两块肩袖肌近端支承与背侧分压板候选

2026-11-02。已把原约6／15 mm的近端间隔落实为具体前支承、端垫夹持、背板及穿骨螺钉几何。当前入口为 [配合修正版](fit_revision/assembly_check.json)。原72对象、未配合的初版及骨骼输入均保留；本候选尚未制造定版或驱动验收。

## 1. 名义连接路径

近端盖板／钢丝入口的反力由两枚M3螺钉、TPU夹持端垫、前支承、薄肩胛片及背侧分压板传递。前支承补足现有盖板与骨面之间的实际间隔；背板分散薄骨片上的局部承压，而不是在约2 mm骨片内假设已有可靠盲孔螺纹。

这些是实际几何连接意图，不代表螺钉预紧、摩擦、防转、薄骨强度或台架反力已经验证。现有台架夹骨垫、夹爪与工作台固定仍未完整落实。

## 2. 骨骼与制造网格

独立工程肩胛新增四个半径1.7 mm的穿孔。相对上一版移除约86.626 mm³，导出新增约0.001829 mm³属于网格差值；原始骨形文件不变。未删掉关节连接或整块骨区来换取无干涉。

每块肌肉新增一件前支承、一件背板、两螺栓、两螺母和四片垫圈，共20个新增对象。对应TPU端垫和肩胛件替换后，与原72对象合为92个名义对象，仍含两份柔性钢丝路由网格。

前支承开实际通道让位，保护原钢丝路径；TPU端垫重新做平面夹持面和M3通孔。支承足终止于顶板内部，避免刚性柱伸入TPU；旧肌腹周边保留装配让位，新端垫则在名义位置与盖板／顶板接触，不把接触面一并裁成悬空间隙。

初版出现断连后，对局部旧端垫残料单独核对：只在半径11.2 mm、盖内面法向−8～0.01 mm的重做端部内，且避开R1.8通道，允许清除总量小于1 mm³、相对体积小于0.01%的孤立残留。本例两侧分别约0.6887／0.0176 mm³，记录在原始参数报告中。更大或涉及通道的断连不予放行。整段替换试验曾造成2.394／11.794 mm³的断连，已拒绝并保存，没有用这种方式删除工作晶格。

肩胛下肌前支承在较远的显示原点导出时出现4条非流形边；改用部件自身原点后通过实际回读。各部件的源坐标变换明确记录，不能将局部毫米文件直接当成已经放好的装配。

## 3. 实际硬件与冈下肌配合

原TPU网格并未为完整螺钉头、垫圈和另一肌肉的背板留足空间，未配合初版存在多处相交。配合修正版按实际硬件做局部让位，不把它们全部标成合法软接触。

冈下肌额外移除约88.897 mm³、增加约15.427 mm³。剪裁留下的1.311 mm³旧杆段无法用原位满径肋接回，遂在其原方向两侧的存活节点间重做一根R1绕行肋，节点结合体积约2.443／2.514 mm³。没有把杆径缩小来躲避硬件。另清除总量约0.00432 mm³、且远离两个端区与通道的孤立切屑；更大的杆段由真实新杆替代，操作及坐标完整登记。

导出还产生一个约1.0×10⁻⁷ mm³的新数值腔隙，与外表面共边。已核对其不属于原有设计空腔，且不触及钢丝孔或硬件，用有记录的微量补料处理后回读通过。原约49 mm³闭腔仍在，未整体填实空腔来获得通过。

相对更早的72对象，端垫改型本身会改变旧腔隙：冈下肌旧59.811 mm³腔中约7.381 mm³变为端部材料；肩胛下肌原3.359／5.056 mm³闭腔成为开口，原4.527 mm³腔保留。不能声称所有旧空腔完全不变。完整位置及体积对照见接触审查文件；内部主动线通路独立验证。

通道壁体积对照仍有小残差：基础支承改型约0.009927／0.004769 mm³，冈下肌硬件配合相对上一版另有约0.006874 mm³。它们不等于已测得壁厚，尚未进行完整壁厚、受压卡线或打印验收；不因钢丝能静态通过而将这项标成完成。

## 5. 装配顺序与未完成项

建议先确认四个实际穿孔与两背板位置，再按组安装前支承、TPU端垫、盖板和穿骨螺钉／垫圈／螺母；骨片两侧都需要工具进入。原有远端钢丝、止挡、卡扣和肌腱连接按上一阶段候选安装。

这是拟定的装配次序，尚未做工具包络、真实紧固和打印试验。需要测薄骨片受压、弯曲、局部压溃、端垫压缩及反复拉线后的松动，再决定材料、壁厚、预紧和是否调整背板。不能把名义M3包络直接当作已选定的商品规格或承载能力。

当前仍需：单肌肉方向标定、真实压接与卡扣试验、抱箍／台架固定，以及自由末端—肌腱—关节的耦合运动。当前交付是近端反力的几何候选，不是整臂驱动定版。
