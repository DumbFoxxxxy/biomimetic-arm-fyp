# 大圆肌远端穿骨夹持对照：未采用

2026-11-03。机械结构设计对照，接续[近端夹持候选](../s1_teres_origin_mount/README.md)。本目录不替换默认模型，也不代表大圆肌两端已完成定版。

本方案沿原端盖双孔轴，以两根长M3螺钉穿过肱骨，将原端盖、TPU贴骨端部与后侧共形背板夹紧。保留原钢丝、锚点、骨长及GH中心。实际生成209对象总装，其中9件新增，肱骨和大圆肌TPU两件修改，父候选其余198源记录不变。

## 几何修正与结果

第一版双M3×50的浅侧螺钉尾端与三角肌相交约5.558 mm³。保留在`iterations/initial_through_bone/`，未采用。当前对照版在该侧背板加工1.5 mm阶梯承压面，改用M3×45；另一侧保持M3×50。两只名义螺母均被完整穿过，浅侧伸出约0.908 mm。双孔间距14 mm、孔径3.4 mm，肱骨净去除约454.505 mm³。未验证这些孔和长紧固件的强度或刚度。

TPU仅在端部补承压接触面约12.117 mm³，保留工作晶格。实际端盖平面与名义基准存在约0.0017 mm偏差，直接补到名义平面会侵入端盖约0.110 mm³；现按实际端盖实体裁定补面边界，未用全对碰撞豁免掩盖。

[零位配对报告](assembly_check.json)显示，209对象中涉及修改件的2233配对未新增或增加超0.001 mm³的实体相交；六主动钢丝路径对修改件无超判据相交。继承的原有柔性接触仍保留，不能理解为全模型零穿透。MuJoCo实际加载209对象，0自由度，仅用于查看。

## 装配检查没有通过

[独立复核](verification_checks.json)检查全部修改件的精确拓扑、两个背板脚的骨面接触和端盖接触。11件修改件在所查索引拓扑判据下通过，两个支承脚分别通过0.02 mm接触探针。这些结果不证明预紧、强度或摩擦保持。

在其余200父对象已预放的上下文中，按0.5 mm步长检查以下往返路径，合计850姿态：

| 前侧浅侧螺钉／垫圈 | 222 | 0 | 未检出 |
| 前侧深侧螺钉／垫圈 | 222 | 0 | 未检出 |

记录数包含不同移动件、往返和采样位置，不是独立碰撞数量。两处前侧工具包络无超判据相交；两处后侧工具包络分别与三角肌相交约223.010和49.917 mm³。该检查不包含真实工具啮合或手部空间。

这些冲突说明当前刚体预放条件下的后侧直线装配不可用，不能据此断言柔性肌肉必然损坏，也不能未经变形验证就假定可以扒开。先装背板、后装三角肌可能改变装配条件，但三角肌后续完整安装尚未验证，因此没有以删除三角肌的检查结果登记为通过。`geometry_checks_pass=false`，`stage_pass=false`。

## 决策与后续结构方向

该对照方案保留，暂不采用。问题集中在长穿骨紧固件和三角肌背侧操作入口。下一步优先比较连接到既有肱骨抱箍的刚性转接座、朝可接近方向布置的短紧固件及端盖局部接口修订；需要同时核对真实连接连通性、肌腹／通道让位、防转、反力和工具空间。这里尚未生成或验证抱箍转接结构，不能将其视为已经解决。
