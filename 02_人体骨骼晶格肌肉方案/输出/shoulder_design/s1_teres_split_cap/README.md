# 大圆肌远端分体端盖工作候选

2026-11-03。为解决[完整模块对照](../s1_teres_module_fit/README.md)中整片端盖被肌腹出口挡住的问题，将原远端盖改为可从两侧合拢的A、B两半。沿用带双孔TPU连接翼、抱箍转接座和主动钢丝止挡，形成208对象机械工作候选；整块肌腹装入仍未解决。

## 结构与局部顺序

拆分方向依据肌腹出口在端盖平面内的投影确定，两半分别由原一根M3固定。分缝0.2 mm；A半具有两根Ø1.5 mm一体定位销，B半对应Ø1.7 mm孔，定位销布置在与弯曲钢丝出口相反的一侧，局部切向−4、−8 mm处。定位销用于两半对位，不能用它们代替螺钉、防松或强度验证。

原整盖从正面套入会刮碰出口。分体后从局部侧向15 mm入口分别合拢，先A后B；末3 mm按0.1 mm采样，其余0.5 mm。入口之外的通行空间没有无限延伸验证，不能把15 mm以外穿过肩胛的位置作为装入路径。

端盖出口边缘分别去除约0.278、0.409 mm³装入刮碰区，并记录微面数值清理变化，未切掉工作肌腹。原盖更换后总净去除约15.102 mm³，未有超0.001 mm³新增盖体材料。早期对称销和出口侧销曾堵住钢丝通道，失败几何与报告均保留在`iterations/`，最终改到出口反侧。

## 已通过的检查

[总装报告](assembly_check.json)包含208对象：原整盖一件退役，新增A、B两件，其余206项源记录保持。[独立复核](verification_checks.json)证明当前规定的局部范围：

- 两个盖件精确回读后，无边界边、非流形边、重复索引或零面积面，大于1e−8 mm³的正材料分量均为1。
- 413个涉及新件的配对没有超0.001 mm³实体相交；六条主动钢丝通道未被新盖件堵住。
- A、B共220个侧向往返采样姿态无超判据相交；A安装后保留在B的检查障碍物中。
- 六角止挡沿内向移动0.08 mm，在组合盖上仍有约0.4279 mm³承压接触探针，不证明实际承载。

本检查从191个对象已经预装、肌腹已在零位开始。15件列为随后安装：8件抱箍螺钉／螺母／垫圈、4件远端短紧固件、2件止挡及钢丝参考。这些件保留在最终208对象清单，之后能否装入尚需独立验证。不能据局部合拢通过宣称完整模块或整肩安装通过。

## 仍需处理

整块肌腹放入还会碰下半抱箍的连接桥；原顺序中提前装好的抱箍五金也会阻挡。下一步进一步修订连接翼的导入轮廓，并验证抱箍五金后装，而不是假定柔性件可以任意让开。定位销／孔真实配合、螺钉保持、TPU夹持强度及整体运动均未验证。`split_cap_geometry_pass=true`，`stage_pass=false`。
