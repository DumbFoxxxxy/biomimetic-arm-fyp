# 中束近端固定方式对照

输入为前束227对象工作候选；原模型、骨骼位置、肌肉中心和钢丝出口不变。本目录是几何筛选，不能替代实际连接模型或强度验收。

1. [对称盲孔嵌件](blind_insert_study.json)：14mm双孔线每5°转动，配合1／2／3mm埋深；名义Ø5×6mm嵌件，Ø7mm外包络检查侧壁及孔底空间。108组均未通过，主要是孔周实体不足，不能依据中心射线骨厚接受。
2. [独立孔位嵌件](offset_insert_study.json)：允许两孔在端部R10区域内按2mm格点分别移动，埋深1–4mm；仅3个独立轴位通过同样筛选，但不足以形成间距至少10mm的孔对。未缩小外包络或放松条件来制造通过。
3. [侧装六角螺母](side_nut_study.json)：改用AF5.5×2.4mm名义M3螺母、AF5.7槽，检查Ø8.6mm局部实体包络及槽顶1.5／槽底1mm；2mm格点筛选找到9个可用轴位。选取局部坐标`[0,-8]`和`[8,-2]`，间距10mm。判据为缺失体积小于0.001mm³，不代表实体尺寸精度。

侧装方案已进一步落实为[234对象实际夹持候选](../s1_middle_side_nut_mount/README.md)，包含真正的骨槽、螺母、螺钉、支承和端部形状。只有该目录的回读与路径证据能支持局部机械结论；本筛选不证明侧槽切完仍完整，也不证明实际预紧或承载。
