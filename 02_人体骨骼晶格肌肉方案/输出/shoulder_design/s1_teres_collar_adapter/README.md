# 大圆肌远端：抱箍转接座工作候选

2026-11-03。优先机械结构，不选择打印设备或工艺。此候选接续[近端夹持](../s1_teres_origin_mount/README.md)，取代[长穿骨螺钉对照](../s1_teres_distal_mount/README.md)作为大圆肌远端的后续设计方向；当前默认191对象指针仍保留，尚未宣称整肩定版。

## 具体结构

将转接座、短连接桥与肱骨抱箍下半件做成一个刚性件。端盖采用两根前侧M3×12螺钉及垫圈，旋入转接座的名义M3螺纹位置；孔距14 mm。背侧不再放置螺母、背板或长穿骨螺钉，本轮肱骨、肩胛及锁骨文件均与200对象父候选相同。近端候选已有的肩胛双孔仍保留。

转接座厚3 mm、半径10.8 mm，位于原远端盖局部法向−6.2～−3.2 mm，避开六条主动钢丝路径。转接座与下半抱箍按金属刚性件设想，不能将渲染中的孔直接当作聚合物自攻孔。旧肩胛下肌肌腱耳和原抱箍材料均保留，连接桥实际并入下半件，没有悬空或单独删除不连通区域。

传力路径为：肌腹／端部TPU → 端盖与转接座夹持界面 → 转接座及连接桥 → 下半抱箍 → 原抱箍紧固、内衬 → 肱骨。双螺钉限制端盖相对转接座转动，整体抱箍的摩擦保持、防滑和承载尚未验证。大圆肌主动钢丝止挡仍待设计，当前不是完整驱动模块。

### 螺纹模型边界

名义螺纹轴向材料长度3 mm；检查了两处螺孔周边的连续材料环。模型孔径3.2 mm仅作简化螺纹显示包络，与现有名义螺母类似，**不是实际M3底孔尺寸或可直接加工的螺纹**。未建真实牙型、未验证旋入／拉脱。螺钉到肱骨最小间隙约0.393、1.050 mm，均为零位名义值，未计公差或实物偏差。

## TPU端部与内衬修订

只在远端半径12 mm、法向−10～0.2 mm的声明区域内修订TPU接口；原端盖、钢丝端点和通道中心线坐标不变。旧端部下层垫片被转接座替代，净去除约1837.305 mm³，新增上下接触补面约12.125 mm³。区域之外未去除TPU，工作肌腹保留。端部握持、通道过渡和变形未验证。

仅切出转接座形状的缝会留下约727 mm³悬空的旧TPU垫片，因此早期版本失败。当前按明确的端部层区域重新设计接口，而非从网格中自动丢弃碎片。失败几何保存在`iterations/terminal_relief_disconnected/`。

原下半内衬完全贴骨，径向装入最后约1 mm存在轻微倒扣。将内衬手工嵌入下半抱箍一起放置仍会刮到骨面；已经按原骨实体0～2 mm相对行程、0.1 mm采样，减去内衬上的局部倒扣，仅去除约0.1760 mm³，未改骨面或增加虚构压缩。旧检查保存在`iterations/liner_prepositioned/`和`iterations/nested_liner_undercut/`。内衬需要人工嵌放，不声称已经粘接或固定。
