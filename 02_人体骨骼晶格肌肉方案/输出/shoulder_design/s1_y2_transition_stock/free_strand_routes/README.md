# 中央肌腱连续走线：规定端环角的几何候选

更新：2026-11-02。沿用S1-Y2，源骨骼、端盖、抱箍、TPU、锚点和默认候选指针均不变。本轮补上[上一轮局部端部检查](../free_terminal_kinematics/README.md)未包含的中央钢丝，输出完整肌腱及两端槽环／压接套的可复核场景。

## 几何模型与假设

两端出口、销轴和端环尾线均来自实际设计源。端盖、肱骨及未变形TPU保持零位，只规定两端眼环角；在保持局部端线长度的同时，重建中央段。中央材料长度明确假设为名义39.92927／36.64097 mm，实际安装长度、压接保持和预紧仍未测。

保留原中心线在压接套外的约1.6 mm直出段，再以匹配两端切向的单个三次曲线连接。调整共同控制柄长度，使曲线积分长度与名义中央段一致；数值积分误差和离散线段长度差分别记录。控制点只是搜索参数，不代表添加了导管或空间固定导向。

该曲线族用于寻找**一条长度匹配且通过指定配合检查的走线**。它不求全局最短路径，也不求钢丝形状或拉力平衡。无自重、接触、弯曲刚度等作用时，一条弯曲的自由钢丝不能直接解释为正张力的理想绳平衡解；候选曲线不作为张力证据，也不传入“已知最短路由长度”的接口。

## 新发现：斜向出线

| 零位指标 | 冈下肌FJ1500 | 肩胛下肌FJ1504 |
|---|---:|---:|
| 两出口沿肌肉侧销轴的偏移 | −0.25531 mm | +10.55503 mm |
| 出口连线偏出端环平面的角度 | 0.36638° | 16.97720° |

两个销轴在本设计零位平行。肩胛下肌的明显轴向错位要求钢丝斜向弯折，或依靠自由端盖随TPU改变位置／姿态；绕销轴转动本身不能消除固定端点的轴向错位。需要测试出口弯折、槽环侧向接触、磨损和疲劳，不能只核查端环的平面转角。约2.55 mm端眼半径及计算曲率均为几何值，尚非钢丝厂商认可的工作半径。

## 搜索与限制分类

对两块肌肉分别检查四条端环输入路径的正负方向：仅肌肉侧、仅骨侧、同号双端、反号双端，共16条。常规1°、首个无合格候选区间细化0.1°，从零位连续搜索，合格采样独立重建回程。

| 模块／端环输入 | 负向最后找到候选的α | 正向最后找到候选的α |
|---|---:|---:|
| 冈下肌：仅肌肉侧 `(α,0)` | −6.1° | +0.1° |
| 冈下肌：仅骨侧 `(0,α)` | −5.1° | +0.1° |
| 冈下肌：同号 `(α,α)` | −0.6° | 0.0° |
| 冈下肌：反号 `(α,−α)` | −0.8° | +0.8° |
| 肩胛下肌：仅肌肉侧 | −14.5° | +9.8° |
| 肩胛下肌：仅骨侧 | −15.8° | +9.8° |
| 肩胛下肌：同号 | −10.6° | +5.8° |
| 肩胛下肌：反号 | −10.2° | +10.2° |

α是规定端环输入，限定在名义材料长度、零位端盖／肱骨及本曲线族下；这些数值不转移为端环全局极限或肩关节范围。尤其冈下肌的名义路径仅比出口直线长约0.00333 mm，结果对未测安装长度很敏感，不能把0.1°当作可制造或可驱动能力。

每个首限分别标记为出口直线长于假设材料长度的必要条件不满足、当前曲线族无解、生成曲率不足以构造R0.3 mm钢丝管、线段自接触或真实刚性配合相交。当前曲线族无解不排除其他弯曲形状；不把搜索失败包装成机构不可行。0.3 mm曲率检查只是避免该扫掠几何局部奇异，不是钢丝允许弯曲半径。

全部受检端部硬件同时按给定角放置，整根原肌腱由新完整折返线替换；检查5个变化对象与其余上下文，不再省掉中央段。未变形TPU相交另行记录。体积判据仍为0.001 mm³，末端姿态可能没有正制造间隙；有限采样不宣称数学连续性或全姿态证明。

## 独立复核与实际网格

[主报告](route_audit.json)保存各条正／负路径、细化、回程和每条候选的曲线参数。[独立验证](verification_checks.json)以32768段密采样核对18个曲线案例的弧长与曲率，并核对夹持出口和切向；4个导出场景重新回读实际网格及变化配对，保持完整名义折返长度差不超过0.0001 mm。该长度误差是数值采样条件，不是安装或制造公差。

场景包含全部191对象的真实网格引用；示意细节只显示新整根肌腱与4个槽环／套筒，固定骨骼与TPU隐藏。图中为规定角度的几何候选，未求解力学平衡：

## 复现与查看

项目根目录，在配置numpy、scipy、manifold3d及项目`.deps`的几何环境执行：

```powershell
python mujoco_arm/tools/audit_shoulder_free_strand_routes.py
python mujoco_arm/tools/verify_shoulder_free_strand_routes.py
```

MuJoCo／Pillow环境中查看完整肌腱及4个眼环部件（静态、DOF=0）：

```powershell
python mujoco_arm/tools/view_shoulder_free_strand_route.py --head FJ1504
python mujoco_arm/tools/view_shoulder_free_strand_route.py --head FJ1504 --render
python mujoco_arm/tools/view_shoulder_free_strand_route.py --head FJ1500 --case neutral --check
```

生成诊断输出不会替换默认S1-Y2。下一步需要安装长度／压接与弯折数据，以及自由端盖—TPU平衡；随后才能让肱骨和端盖共同运动并求解实际中央路由。当前`stage_pass=false`，实际驱动范围未知。
