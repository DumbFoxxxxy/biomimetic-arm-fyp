# 大圆肌端部保持修订与模块顺序对照

2026-11-03。接续[钢丝止挡候选](../s1_teres_wire_stop/README.md)。本目录修改TPU端部并检查完整模块的规定安装顺序。局部保持结构改进成立，但顺序检查失败；后续端盖修订见[分体端盖工作候选](../s1_teres_split_cap/README.md)。不更换骨形、GH中心或原钢丝端点，不继续打印工作。

## 端部修改

- 远端增加半径10.5 mm、局部法向−3.17～−1 mm的TPU连接翼，带14 mm孔距、Ø3.4 mm双孔。原两根M3穿过连接翼，提供几何侧向限位；连接翼避让现有转接桥，不能靠夹紧摩擦作为唯一定位方式。
- 肩胛侧原贴骨端垫有倒扣。按一个零位相连的候选装入方向，将原肩胛实体沿相对行程采样，只在半径12 mm、法向−20～0.2 mm的近端接口区修整导入轮廓；使用全局六轴±0.03 mm位移构造名义让位包络，未改骨面。包络在区外仍有小量接近，未扩大到工作肌腹切除；实际骨面在区外无超判据穿透。
- 原远端中央承压小台上端留0.03 mm名义间隙，避免近乎重合的接触面形成零宽网格接缝。该修改只在半径5.1 mm的端面区，不是缩短工作晶格。

相对父候选，TPU去除约10.7669 mm³、增加约505.6212 mm³。声明修改区外去除量约1.42e−6 mm³，除指定端面口外的钢丝外半径2 mm保护区材料损失约7.40e−7 mm³。布尔结果曾出现精确回读非流形边，失败网格保留；最终在明确0.03 mm几何让位后，以1e−6 mm数值公差清理极小面，另记录约0.000139／0.00000610 mm³数值增／减量。数值公差不是制造精度，未按连通分量删掉模型。

[生成报告](assembly_check.json)仍为207对象，仅更换TPU一项，其余206源记录与变换不变。206涉及修改件的配对没有超0.001 mm³的新增或增加相交；原TPU—肩胛相交约0.002336 mm³降至约0.000112 mm³，并不宣称数学零穿透。

## 保持探针与安装失败

[模块检查](installation_checks.json)对两端接口分别作几何探针：沿局部两个切向轴正反各移动0.3 mm，与M3螺杆均出现明确相交；沿轴向正反移动0.1 mm，分别遇到端盖和骨面／转接座。说明名义模型有侧向及轴向阻挡，不能据此给出真实TPU的防脱能力、允许载荷或间隙上限。

在188个其他对象预装条件下，对肌腹、端盖和紧固件等12阶段往返共1310姿态作检查，所有最终207对象均列入顺序账目，没有整对排除相邻部件。结果：

| 阶段 | 主要问题 |
|---|---|
| 整块肌腹放入 | 肩胛导入问题已缓解，但撞到下半抱箍连接桥及一组抱箍螺钉／螺母／垫圈 |
| 近端盖、近端固定包 | 规定路径无新增超判据相交 |
| 整片远端盖沿法向放入 | 被肌腹出口挡住，局部最大相交约65.137 mm³；远处入口也接近支架螺钉 |
| 远端短紧固、止挡及径向初接触 | 规定路径无新增超判据相交 |

该顺序检查明确失败。刚体平移失败不证明柔性TPU绝对不能安装，但当前没有形变验证，不能假定可以扒开。线的数字路径配合另有记录，不是物理穿线证明。`nominal_sequence_and_capture_geometry_pass=false`，`stage_pass=false`。

下一步采用分体远端盖；抱箍五金需考虑后装，并对连接翼与连接桥的导入进一步修订。后装只是待检查的真实工序，不是从最终总装删除这些件。
