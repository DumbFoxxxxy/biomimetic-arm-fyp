# 三角肌共享远端紧固件布局对照

输入为234对象中束工作候选；三条钢丝出口、附着中心和骨骼定位固定。此目录不修改源几何，不是完整连接。

[对称孔对筛选](fastener_study.json)比较半径7／8／9mm、孔对每5°旋转，共108组。检查实际M3螺钉／垫圈／螺母、有限骨周实体、六主动线及三角肌三线R2保护区，均无合格孔对。主要限制为自身出口结构、通道壁以及部分孔位骨周余量；未通过删除钢丝、缩小保护区或忽略TPU来接受。

[独立孔位筛选](offset_fastener_study.json)允许螺钉位置按2mm格点在R14区域调整，新增端部工作区扩大至R18、法向−18至0.2mm，未改附着中心。孔缘保护和R2通道保护条件不变，最终选局部`[4,-4]`及`[12,0]`，间距约8.944mm，均偏向肘侧。此变更需要实际增加端盖／TPU承压耳，不能继续沿用原14mm对称孔说明。

下一层[244对象实际夹持候选](../s1_deltoid_distal_mount/README.md)落实了骨孔、贴骨支承、背板和端部重构，并进行回读及条件装配检查。这里只是紧固件包络筛选，不能推强度、压接握持、全肩安装或驱动能力。
