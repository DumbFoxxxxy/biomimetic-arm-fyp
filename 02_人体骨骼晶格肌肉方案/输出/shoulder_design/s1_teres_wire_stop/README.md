## 连接方法与传力

钢丝沿原TPU内部路径和端盖通道穿出远端。外侧增加六角金属止挡：短定位段进入原钢丝孔，六角头抵住端盖外表面；径向M2平端紧定螺钉用于夹住钢丝，六角外形供另一工具反夹持，拧紧时不依靠TPU肌腹承受反扭矩。

名义传力链为钢丝 → 夹线接触 → 金属止挡头部 → 远端盖 → 短紧固件／转接座 → 肱骨抱箍。当前仅建模螺钉与钢丝的初接触状态；钢丝摩擦、压紧、拉脱、疲劳和防松均未验证，不能把接触探针当成握持能力。

| 项目 | 候选值 |
|---|---|
| 钢丝／止挡通孔 | Ø0.6／Ø0.8 mm |
| 定位段 | Ø1.4 mm、长1 mm，局部法向3.05～4.05 mm |
| 六角头 | 对边5 mm、长4 mm，局部法向4.05～8.05 mm |
| 入口倒角 | 定位端径向／轴向0.1／0.1 mm，外端0.2／0.2 mm |
| 径向紧定螺钉 | 名义M2×3、平端Ø0.9 mm、0.9 mm内六角显示槽 |
| 螺纹显示 | Ø2.1 mm径向孔，表示简化包络；不是M2加工底孔或真实牙型 |
| 钢丝尾段 | 原路径末端之外延长5.05 mm；原路径完整保留为精确前缀 |
| 止挡朝向 | 相对端盖局部Y方向绕法向185°，源坐标矩阵见报告 |

原端盖没有被假定为已经具有匹配沉孔；采用短定位段与外侧大头承压，原204源文件及变换全部不变。初始模型保留约0.05 mm轴向就位间隙，尚未预紧。止挡沿内向移动0.08 mm后与端盖发生明确承压接触，探针相交约0.4404 mm³。螺钉沿径向内移0.05 mm后与钢丝相交约0.00953 mm³，仅用于确认接触位置。

## 工具方向与局部装配

初版朝向下，反夹持工具会碰到大圆肌及钢丝。未裁去肌腹或删掉走线，而是对止挡朝向进行[对照筛选](orientation_study.json)：常规15°，175～195°细化1°，粗筛中181～189°的采样朝向无超判据冲突。最终185°对实际导出件独立重放更细装配路径；不据此声明一个连续、已验证的实物角度区间。

[独立检查](verification_checks.json)按全部当前207源作障碍物，保留完整钢丝：

- 止挡连同外退0.3 mm的螺钉，沿法向装入／退出12 mm，0.5 mm步长、50姿态，无超0.001 mm³相交。
- 止挡已就位后，螺钉从外退0.3 mm到初接触，0.1 mm步长往返8姿态，无超判据相交。
- 螺丝刀与反夹持叉形工具包络可同时放置，二者之间无超判据相交；叉形工具从侧面进入／退出20 mm，0.5 mm步长往返82姿态无超判据相交。
- 叉形工具的两侧夹持面分别有独立接触探针；螺丝刀包络止于螺钉尾面前，尚未证明真实工具啮合或手部操作。
- 六条主动钢丝通道对新增件均重放检查，未发现超判据冲突；原路径没有改写。

工具是明确尺寸的名义包络，尚未对应采购型号。模型中的径向直线位移不是螺纹旋入仿真，初接触也不是拧紧完成。实物扭矩与握持值仍为空，不提供猜测值。

装配顺序候选为：原通道穿线 → 将螺钉外退 → 钢丝穿过止挡导孔 → 定位段进入端盖孔并使大头就位 → 反夹持六角头、从另一侧接近紧定螺钉。此处只验证最后的局部规定路径；肌腹、端盖及抱箍的完整安装顺序仍需验证。
