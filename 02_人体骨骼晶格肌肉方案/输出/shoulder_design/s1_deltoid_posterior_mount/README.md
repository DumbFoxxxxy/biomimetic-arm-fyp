# 三角肌后束骨侧夹持候选：装入路径未通过

2026-11-03。以[大圆肌规定装配顺序候选](../s1_teres_assembly_order/README.md)的208对象为起点，本目录增加后束实际夹持结构，形成218对象对照。零位配合和接触链成立，局部装入路径未通过，尚未采用；打印工作暂缓。

## 为什么改变孔位

原后束端盖的一根孔轴错过肩胛，不能直接复制双穿骨背板。[孔轴研究](../s1_deltoid_origin_holes/hole_axis_study.json)在不移动端盖中心、钢丝出口和骨骼的条件下，以5°步长旋转14 mm孔距的孔对。前束、后束存在双轴都穿过目标骨的候选；中束没有满足同样单次穿骨条件的采样孔对，不适合直接照搬。

骨轴命中不代表五金适配。后束60°方案的螺钉和垫圈穿过肌腹，螺钉也堵住主动钢丝路径，已保存在`iterations/rotation_60_hits_muscle/`。[进一步筛选](../s1_deltoid_origin_holes/posterior_fastener_study.json)检查实际名义螺钉、垫圈、螺母与其余部件及六主动线，最终在预筛无冲突者中选最小射线骨厚较大的145°孔对；对称孔对等效原线转−35°，只是改变孔位，没有转动骨或肌肉锚点。

新两轴沿法向的骨内跨度约3.31、4.71 mm。这是中心射线厚度，不是孔边距、强度或承载保证，完整孔周与骨缘安全余量尚未验收。

## 实际结构与反力路径

组件由修订端盖、带双孔TPU连接翼、前支承、肩胛双孔、后背板及两套M3构成。旧金属盖孔填实，再沿新轴开Ø3.4 mm孔；原盖中心、钢丝通道、骨长和关节中心保持。

| 项目 | 当前几何 |
|---|---|
| 螺钉 | 两根名义M3×30，配前后垫圈及螺母；未建真实牙型 |
| TPU连接翼 | 半径10.3 mm，局部法向−7.2～−4 mm，双孔随新轴布置 |
| 端部承压补面 | 保留约0.03 mm名义盖面间隙；钢丝路径保持 |
| 前支承 | 名义法向−9.2～−7.2 mm，骨侧和TPU侧按实际面扣合，含双支脚及Ø6 mm中央让位通口 |
| 后背板 | 双脚贴骨，连接桥厚2 mm，按两个真实后骨面形成支承脚 |

原TPU小台背面与骨面有空隙，新孔轴周围也没有足够的TPU连接翼；仅给骨钻孔和加螺钉不能闭合接口。因此新增前支承和TPU翼，名义传力链为端盖 → TPU端部 → 前支承 → 肩胛 → 后背板 → 紧固件 → 端盖。实际预紧、摩擦、防滑、TPU孔边保持、骨孔边距和强度均未验证。

前支承第一次扣合后产生一个约1.319 mm³悬空中心小柱。没有按连通分量丢掉它，而是明确设计Ø6 mm中央让位通口；旧失败几何在`iterations/front_plate_central_island/`。最终每件新材料均为一个大于1e−8 mm³的正材料分量。

相对208父候选，仅修改肩胛、三角肌TPU和后束盖3项，其余205源记录不变，新增前支承／背板及8件五金，共218对象。骨净去除约67.078 mm³，TPU增加约769.145 mm³，旧TPU去除仅数值级约1.62e−6 mm³；工作晶格没有有意切除。原始文件保留。

## 静态与接触检查

[生成报告](assembly_check.json)对2743个涉及新／修改件的配对未发现超0.001 mm³的新增或增加相交，六主动线对修改件复核无超判据冲突。继承的旧接触仍列在报告中，不是全肩零穿透证明。

[独立复核](verification_checks.json)回读全部13件新增／修改件，精确索引边界、非流形、重复索引及零面积面均为0。名义接触探针分别为：

| 接口 | 位移探针 | 相交体积约mm³ |
|---|---:|---:|
| 前支承—骨面 | 0.02 mm | 3.425 |
| 前支承—TPU | 0.02 mm | 5.700 |
| 后背板—骨面 | 0.02 mm | 0.700 |
| 盖面—TPU | 0.10 mm | 4.720 |

这些量只说明接触位置存在，不代表力、压力或夹持能力。盖与TPU初始最小间隙约0.03105 mm，实际预紧后状态未模拟。

## 规定装入路径仍失败

以其余构件预装为上下文，前支承先于三角肌安装；肌肉随后只按零位预放，实际肌肉放入另待验证。按0.5 mm步长分别往返检查，发现：

- 前支承沿法向装入时撞到已装冈下肌，位移6.5～14 mm，最大相交约6.533 mm³。需改变先后顺序或局部入口，不能直接删掉冈下肌判通过。
- 整片后束盖沿法向装入时撞到三角肌出口，位移0.5～20 mm，最大约43.966 mm³。需研究分体盖或其他实际装入方式。
- 0号前侧螺钉／垫圈沿规定长轴入口撞到肌腹，位移3.5～35 mm，最大约17.933 mm³。可能需要随分体盖预装或改变入口，尚未验证。
- 后背板、1号前侧组和两组后侧紧固件的规定路径未见超判据相交。

因此`static_fit_and_contact_pass=true`、`local_approaches_geometry_pass=false`，`stage_pass=false`。最终218对象全部列入账目，但不等于其安装过渡都成立。没有假定柔性肌肉可以任意扒开，也没有接受完整三角肌或全肩安装。
