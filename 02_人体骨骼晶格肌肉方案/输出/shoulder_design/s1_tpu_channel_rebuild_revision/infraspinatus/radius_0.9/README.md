2026-11-03。默认模型仍为S1-Y2，名义孔径仍1.72 mm；本目录是单肌肉完整几何研究分支，不是制造定版或驱动验证。

## 结构变化

沿原完整钢丝路径重新切孔：圆柱直径1.80 mm、节点球直径1.818 mm，32段离散；节点半径比圆柱大1%，避免原始等半径交接处仅相切。中心线、锚点、0.6 mm钢丝和其余190个源／装配变换不变。端盖孔径未随此修改，接口处阶差及实际穿线／摩擦仍需确认。

相对所选冈下肌完整网格，显式切除约26.57415 mm³，约0.3154%；这是有记录的孔径设计变化，不能称为无材料变化的导出清理。名义壁厚与局部刚度的实物表现仍未知。

## 验证与拒绝原因

独立孔道重放与最终OBJ一致；未发现超0.001 mm³判据的刚体／六主动线冲突或新刀具范围外材料损失。排除端接口后的名义0.75 mm壁厚包络缺失约4.3×10⁻¹³ mm³。另以外接圆柱和按最小面距放大的球构造保守包络，避免内接多边形低估包络，缺失量同样仅为数值残差。这不验证打印后或变形后的壁厚。

Delaunay实际生成199103个四面体；用原始节点标签字典独立重算，确认8个非正体积、73357个平均比质量低于0.05，最小有符号体积约−291.89684 mm³。网格总体积8432.81669 mm³，与源材料8399.09955 mm³相差约33.71714 mm³，超过原体积门，**拒绝用于连续体求解**。没有通过取绝对体积、翻转单元或删除坏单元制造通过。

HXT发生原生堆损坏，初始`mesh_attempt.json`没有正常最终化；表面参数化出现重复递归后中断，没有最终报告。两者只按失败／中断留档。后续原生调用使用[有时间与日志上限的监督器](../../../../../../mujoco_arm/tools/run_shoulder_mesh_worker.py)。

本目录的`volume_mesh.npz`是被拒绝的数值结果，不能用来展示TPU应力、变形或驱动。预测及实测驱动范围未知，`stage_pass=false`。全过程、复现与下一步见[本轮审查](../../../../../../reviews/S1_2026-11-03/indexed_boundary_meshing/README.md)。
