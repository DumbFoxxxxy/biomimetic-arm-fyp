# 大圆肌近端骨侧夹持候选

2026-11-03。当前优先机械结构；本目录不涉及打印参数选择。

在S1-Y2基础上，具体补齐大圆肌FJ1507近端的名义紧固结构：保留原端盖、双孔轴、钢丝路径、肌肉附着位置和GH中心，增加贴合肩胛骨背面的双脚背板及两套M3紧固件。骨长不变。

## 连接与反力路径

端盖 → TPU端部承压面 → 原有共形贴骨端部 → 肩胛骨 → 背板 → 垫圈、螺母和螺钉 → 端盖，形成夹持回路。双孔间距14 mm，并以双支承脚限制背板绕单螺钉转动；实际预紧、防滑和承载尚未验证。TPU工作肌腹仍按柔性结构处理，不固定成骨骼刚体。

| 项目 | 候选几何 |
|---|---|
| 骨侧通孔 | 沿原两孔轴，Ø3.4 mm |
| 五金 | 2根名义M3×30螺钉、2螺母、4垫圈；未建真实螺纹 |
| 背板 | 2 mm厚连接桥、双共形支承脚，避让原有包绕TPU |
| TPU端部 | 仅在半径5 mm、法向−0.3～0 mm范围补接触面，净增约13.0414 mm³ |
| 肩胛修改 | 两孔净去除约97.4238 mm³，原始骨形文件保留 |

背板支承脚生成时向原骨面延伸0.2 mm，再扣除骨实体形成贴合面；该数值是建模构造量，不是过盈或制造公差。曾用1 mm构造延伸导致背板碰到绕过骨缘的TPU，已保存失败版本后缩短支承脚，没有切掉肌腹让位。

## 验证结果与边界

[总装报告](assembly_check.json)含200个名义对象：新增9件、替换肩胛和大圆肌TPU两件，189项源记录未变。当前默认191对象选择指针未变，本候选没有自动成为整肩定版。

[独立复核](verification_checks.json)记录：

- 11件新增或修改网格精确索引后均无边界边、非流形边和退化面，正材料连通分量均为1。
- 2134个涉及修改件的配对未发现超过0.001 mm³判据的新增或增加相交。原有三角肌—肩胛约1.84044 mm³、大圆肌—肩胛约0.002335 mm³的相交仍明列，不是全总装零穿透结论。
- 两只背板支承脚分别通过0.02 mm接触探针；端盖接触探针通过。探针相交不证明接触压力或承载。
- 背板先从后侧装入，再装两组前侧螺钉／垫圈，最后装后侧垫圈／螺母。五阶段按0.5 mm采样往返共690姿态，无超判据相交。起始状态已预放骨、肌腹和端盖，不代表完整肩部装配已验证。
- 两处前侧工具实心包络、后侧环形工具包络直线接近无超判据相交；工具止于头部／螺母前，尚未验证真实工具啮合、手部空间和紧固操作。
- 六条主动钢丝Ø0.6 mm路径对修改件复核无超判据相交。未验证动作中的走线或肌腹变形。

背板与TPU零位最小间隙约0.719 mm；端盖与补面后的TPU间隙约0.000957 mm，属于名义贴合数值，不能作为实物精度。尚未重放带肌肉动作；无预紧、强度、防松或驱动范围结论，`stage_pass=false`。
