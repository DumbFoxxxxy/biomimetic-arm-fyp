# 大圆肌模块：导入修订与规定装配顺序

2026-11-03。接续[分体端盖](../s1_teres_split_cap/README.md)，当前208对象机械工作候选。名义几何的15阶段装配／退出顺序通过；实物安装、穿线、拧紧和驱动未验证，`stage_pass=false`。打印工作仍暂缓。

## 本轮结构修改

只修整大圆肌远端连接翼经过下半抱箍桥时的刮碰区，净去除约2.08211 mm³ TPU。修改限定在远端半径12 mm、局部法向−4～0.2 mm区域；区域外材料变化约2.62e−7 mm³，钢丝路径外半径2 mm保护区内损失约1.53e−7 mm³，均低于0.001 mm³数值判据。工作肌腹不作有意轮廓修改。新OBJ精确回读无边界边、非流形边、重复索引或零面积面，正材料分量按1e−8 mm³阈值为1。

第一次用统一0.03 mm间隙包络削减会损失钢丝保护区约0.2253 mm³，未采用。核对后发现该包络也覆盖了合法承压面，实际金属并未挡住这部分保护壁。最终按真实刮碰区修整，保留承压和钢丝壁，不需要改金属件。原始失败对照保存在`iterations/TPU_wire_wall_loss/`。

[模型清单](assembly_check.json)保持208对象，仅替换TPU一项，其余207源记录和变换完全保留，骨形、关节中心、金属抱箍、分体盖、钢丝路径和端点均未改。207个涉及新TPU的配对无新增或增加超0.001 mm³相交。1e−6 mm微面清理单独记录约0.0001340／0.00000054 mm³增／减量；这是数值处理公差，不是实物制造精度。

## 安装顺序如何改变

实际挡住肌腹的只有0号抱箍紧固组。1号组保持预装，0号组的螺钉、前后垫圈和螺母在肌肉模块就位后安装。尝试把两组都后装时，1号组反而被其他已装结构遮挡，该失败顺序保存在`iterations/all_collar_screws_late/`。

[独立顺序复核](installation_checks.json)以184个其他对象预装为起点，完成下列规定步骤，去程与回程合计1740姿态：

每一步保留所有此前已装对象。所有208对象在最终账目中都已归位，无相邻件整对碰撞豁免。常规位移采样0.5 mm；肌腹最后10 mm、分体盖最后3 mm细化0.1 mm，径向初接触0.1 mm。全部规定采样无超0.001 mm³的新增／增加相交；不宣称连续路径的数学证明。

钢丝按完整数字路径作配合检查后加入账目，不是物理穿线仿真。骨骼和抱箍在装配时按临时定位状态处理，未验证工装、操作者手部空间或预紧。当前顺序只从184对象已在位开始，不证明这些对象自身的全肩安装顺序。

## 保持、工具与结论边界

两端的局部TPU接口沿两个切向轴正反移动0.3 mm，均遇到M3螺杆；正反轴向0.1 mm分别遇到端盖和骨／转接座。双孔连接翼因此有明确名义几何阻挡，但柔性TPU可变形，不能将探针量当成实际防脱力。

六条主动钢丝通道、完整主动线数字配合、止挡两侧工具最终包络均复核无超判据冲突。后装0号组另有[工具检查](collar_tool_checks.json)：

- 原长粗后侧套筒会撞抱箍和B盖，未采用。
- 改为外径7.2 mm、长5 mm的短套筒头＋Ø3 mm细杆，名义内六角对边5.7 mm，为自定义工具包络，尚未对应采购型号或强度验证。
- 前侧工具与后侧工具可同时放置；后侧局部4 mm进入／退出路径、0.5 mm步长共18姿态无超判据相交。更远处如何将手／工具送到局部入口尚未验证。
- 套筒腔留有突出螺钉尾端空间，但目前仍止于螺母前；真实啮合、手部操作、拧紧扭矩及握持均未验证。

`nominal_sequence_and_capture_geometry_pass=true`，`nominal_straight_tool_approach_pass=true`；全肩安装、真实钢丝握持、预紧／摩擦、TPU受载变形、实物性能及驱动范围仍未知。此结果允许继续推进其他机械接口，不等于实体可动模型已经验收。
