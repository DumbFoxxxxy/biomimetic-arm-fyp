# 后束修订：分体盖、前置螺母和背侧进螺钉

2026-11-03。接续[218对象夹持对照](../s1_deltoid_posterior_mount/README.md)。为解决前侧长螺钉和整片盖被肌腹挡住的问题，改为分体空盖先合拢、短入口放入螺母、背侧穿入螺钉。当前217对象，局部刚性件路径通过，肌肉实际放入和整肩安装未验证，`stage_pass=false`。

## 实际修改

- 原整盖改成A、B两半，分缝0.2 mm；补出真实螺母耳座，半径3.7 mm、高4.8 mm。原中央实体比名义孔距范围小，不能仅在空位置声明螺母孔。
- 前侧采用名义M3螺母，放入对边5.7 mm的开口六角槽；槽底距原内盖面2 mm。名义螺母高2.4 mm、对边5.5 mm。槽承担限转和承压，螺母暂需人工保持，尚无永久防脱盖。
- 两根M3×25从背侧穿入，复用背侧垫圈；取消两片前侧垫圈。螺钉头设名义内六角显示槽，真实牙型、工具啮合、预紧和承载未验证。
- B空盖先从尚未封闭的一侧进入；A盖随后沿斜向路径进入。两根Ø1.3 mm定位销与Ø1.5 mm孔按A的实际合拢方向布置，轴线不再是假定纯侧向。
- B盖入口轮廓再去约8.8210 mm³金属。不是削减工作肌肉；两处螺母承压底面的指定材料环均完整保留。另有小量静态贴合轮廓修订，见生成报告的逐件材料量。

相对218父候选，退役原整盖及两片前垫圈，增加两半盖，并改变两根螺钉及两只螺母的几何／位置；其余211项源记录不变。217是数量变化，不是降低零件验收范围。骨、TPU肌腹、前支承和后背板均沿用父候选。

名义传力链为背侧螺钉头 → 垫圈 → 背板 → 骨 → 前支承 → TPU端部 → 分体盖／螺母槽底 → 前置螺母 → 螺钉。力值、刚度和实际夹持仍未知。

## 局部顺序及证据

[生成报告](assembly_check.json)包含1281个涉及六件新／替换件的配对，未见超0.001 mm³新增／增加相交；六主动钢丝通道对修改件无超判据相交。

[独立复核](verification_checks.json)包含以下8阶段，共728个往返采样姿态：

| 阶段 | 往返姿态 |
|---|---:|
| 前支承先于三角肌、冈下肌安装 | 82 |
| 空B盖先进入 | 98 |
| 空A盖斜向进入，保留B盖作障碍物 | 98 |
| 两只螺母分别从正面3 mm局部入口放入 | 124 |
| 后背板 | 122 |
| 两组背侧螺钉／垫圈 | 204 |

常规位移0.5 mm，盖件末3 mm细化0.1 mm，螺母放入全程0.1 mm。全部规定采样无超判据干涉；所有最终217对象列入账目。两块肌肉仅在前支承就位后预放到最终位置，**三角肌和冈下肌的放入过渡没有经过验证**，不能据此宣称后束完整模块或全肩可安装。

六件新网格精确回读后，无边界、非流形、重复索引或零面积面，大于1e−8 mm³的正材料分量均为1。两处螺母指定承压底面无缺失；0.05 mm承压探针约0.858 mm³，正反5°旋转探针均遇限转槽。定位销横向阻挡及背侧头／垫圈／背板接触探针也成立。这些结果不是强度、扭矩或防松能力。

两处背侧螺丝刀的半径1.5 mm接近包络无超判据冲突，止于头面前，未证明真实工具啮合或手部操作。

## 失败对照仍保留

最初照搬较大端盖的定位销距离，会将销放在本盖实体之外，已保留失败网格后重新定位。完整螺母耳座曾与肌肉小量重叠，按实物几何修订耳座表面，承压底面和限转探针仍必须通过。

两半盖直接从各自外侧带螺母滑入时，B组被冈下肌挡住；多组直线／斜线预筛均未解决，未接受为通过。后续[短入口研究](pocket_loading_study.json)表明，螺母与盖分步安装可行，且B入口让位不损失指定底面。历史几何在`iterations/`，研究脚本从保存的旧网格读取，避免当前重生成破坏对照。
