# S1 台架试验记录模板与测量规程

对应 §10.2 的"待实测"项：z 标定（S1-P0）、单肌肉台架（S1-G3）、一对拮抗（S1-G4）、
三轴（S1-G5），以及两条必须先做的前置试验（压接滑脱 R2、通道通丝 R15）。

**原则：先记录条件，再记录结果。**
所有行程/拉力数据必须注明**当时的夹具柔度 k_fixture**（§5.9.8、R12），
否则不同批次的数据无法比较。

## 2. `p0_z_calibration.csv` — z 标定（S1-P0）

4 个 z（20 / 25 / 30 / 40）× 3 件 = 12 行。判据见 §6.6.1。

| 列 | 含义 | 单位 |
|---|---|---|
| `z_mm` | 该件的 z 值 | mm |
| `coupon_id` | 样件编号（z20-1 … z40-3） | — |
| `E_x_mpa` | 横向弹性模量（压缩方向） | MPa |
| `E_y_mpa` | 收缩方向弹性模量 | MPa |
| `k_measured` | 实测刚度 | N/mm |
| **`contraction_max_pct`** | **y 向压到载荷急剧上升（杆件互触）时的相对缩短量** | % |
| **`stroke_at_2N_mm`** | **2 N 载荷下的缩短量**（换算可用行程） | mm |
| **`set_pct`** | **卸载 60 s 后未回复的相对量** | % |
| `repeat_1/2/3` | 三次重复的位移读数 | mm |
| `residual_pct` | 与拟合曲线的偏差 | % |

**通过条件**：
1. z=25→40 的刚度比落在论文 1/2–1/5 量级内；外推区间必须书面声明；
2. **`contraction_max_pct` ≥ 25%**（§5.4.36 的验收线）——
   **达不到就改设计（多肌协同或换格子），不是把 25% 改小**；
3. `set_pct` ≤ 5%，否则该件判废并复测。

**为什么必须单独测收缩**：`E_y` 只给刚度、**不给行程**。低模量不等于能收缩 25%——
收缩上限由**杆件互相接触**决定，与模量是两个量。

## 3. `g3_single_muscle.csv` — 单肌肉台架（S1-G3）

每个模块一段，至少 3 次往返。

| 列 | 含义 | 单位 |
|---|---|---|
| `module` | deltoid / teres_major / subscapularis / infraspinatus | — |
| `end_pulled` | 从哪一端的手拉口拉（origin / distal） | — |
| `trial` | 第几次 | — |
| `delta_L_mm` | 缩短量（实测） | mm |
| `pull_N` | 手拉力（或用弹簧秤读数） | N |
| `return_L_mm` | 松手后回复长度 | mm |
| `hysteresis_mm` | 往返差 | mm |
| `wire_slip` | 钢丝是否在压接处滑移（Y/N，滑移量） | — |
| `kink` | 通道是否卡线/打折（Y/N，位置） | — |

**通过条件**：能产生**可重复**缩短；`hysteresis_mm` 每次都要记；
`wire_slip` 与 `kink` 只要出现就单独复测，不能"忽略一次"。

## 8. 记录纪律

1. **失败也要记**——本项目肘部阶段的教训是"失败记录比成功记录更有用"；
2. **不要事后补记**：`fixture_k`、环境、批次都必须在**试验当时**写；
3. **手拉数据不要写成"达到 150°"**：写**实测多少度、限制来自哪里**；
4. 每个 CSV 都有 `notes` 列，**异常必须写进去**，不要只写在纸上。
