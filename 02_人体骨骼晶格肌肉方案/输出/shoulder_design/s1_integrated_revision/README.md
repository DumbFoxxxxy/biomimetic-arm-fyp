# S1 实际零件与穿线路径联合检查

日期：2026-11-02。状态：**修订候选，不可作为整套装配放行**。

## 已完成的实质修复

旧build_shoulder_tendon_segments.py仅建立内存实体和计算记录，没有写STL。现在已导出9件腱段候选，并记录每段中心线、孔径、坐标系和装配变换。
旧圆头结构的内孔停在较小内球面，形成封闭空腔。现将孔沿两个端部切线延伸至外球面之外，单件名义0.6mm钢丝可贯穿。
3项回归测试通过：直管、弯管两端通丝，以及无壁厚参数拒绝。

## 坐标与制造检查

腱段STL使用局部毫米坐标以减少浮点精度损失，`translation_source_mm`明确给出回到原人体坐标的平移，不能在装配时忽略它。
9件均通过水密、单一材料、STL回读体积误差<=1e-5。FJ1513/distal弯道存在薄片夹点，固定清理容差反复处理未解决；将该段孔半径由0.850改为0.852mm后消除。名义孔径1.704mm已逐件记录，没有放宽连通/非流形验收阈值。
一次清理移除绝对体积约0.000001164mm3的浮点微壳，记录在`tendons_export.json`。其他材料未按“最大件”任意裁去。
局部坐标改善精度并不能单独解决弯道夹点，二者的处理原因应区分。

## 41个实际可用件的联合检查

对象：3骨、4个实际TPU制造网格、20个端垫/端盖、9个腱段、5个已导出夹具件。
报告`actual_assembly_check.json`保存逐件文件哈希和装配变换；这次不再用实心肌腹包络代替TPU制造件。
检出54处超过0.05mm3的交叠，全部保留，未以整对排除或宽泛白名单将其隐藏。包括设计连接处、柔性接触和待核对的刚性交叠，不能将54处一概视为54个故障，也不能一概判为合法。
仍缺3个夹具接触垫的制造文件、夹爪/螺钉/导轨、压接件、GH软衬以及完整手拉线入口，因此不称为完整装配。

## 穿线结果：单件管孔通，不等于装配后连通

对9段分别建立直径0.6mm的中心线钢丝几何，并区分已设计中心线与端口外直线试探：

- 每段与自己的管壁相交均为0，单件孔已打通；
- 9/9段的**已设计中心线部分**仍与其他装配材料相交，不仅是试探延长线的问题；
- 相交对象包括同模块TPU、端垫、端盖，以及三角肌共享止端处的其他腱段；
- 例如FJ1507/distal已知钢丝段与端盖相交约1.813mm3；三角肌后/中束止端钢丝与相邻腱段相交超过1mm3。

这证明各零件分别打孔没有建立统一的装配孔路。不能通过只检查单管、排除自己的端垫或假定肌肉压扁来宣告通丝。
必须统一设计从端盖止挡/拉线口、端垫、连接段到实际TPU通道的接口，三角肌共享座应明确三条线的端口与终端关系，再对同一完整路径求行程/Jacobian。
