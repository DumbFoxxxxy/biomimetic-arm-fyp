# GH螺母键槽与横向保持件候选

更新：2026-11-02。195名义对象，独立研究分支；尚未替代187对象集成起点。`stage_pass=false`，真实驱动范围未知。

## 设计与变化

在[187对象入口修订版](../assembly_entries/README.md)上，只改工程肩胛并增加两套M2横向保持五金，共8对象；其余186父级源／变换不变。骨长、GH中心、肱骨、肌腹和钢丝路径均未移动。

- 每个M3螺母有宽5.7 mm的平行键槽，对应原名义5.5 mm对边螺母。上层7.2 mm宽通道容纳下垫圈；槽壁与工程肩胛连成一体。
- M2横向螺钉穿过两侧闭合孔，安装后横跨侧向出口，挡住M3螺母及下垫圈。横向孔径2.2 mm，螺钉名义杆径2 mm、长14 mm，两垫圈与外侧螺母固定。
- 螺钉头采用高1.5 mm、R1.9 mm的候选包络，避免初版2 mm头部在肱骨回零时相交。它是设计包络，未选定现成产品，尚无真实驱动孔与工具啮合验证。
- 横向五金须先于肱骨安装；不沿用旧的“肱骨已在场时插横销”步骤。

[源清单与全体零位报告](assembly_check.json)记录肩胛相对父级新增约483.94427 mm³，移除约200.31061 mm³，主要用于横销孔及两侧工具／五金入口。另记录原材料布尔／读回差值约0.01768 mm³，不称逐面不变。实际变化均在GH中心55 mm邻域内。肩胛仍为单一正材料实体，零边界／非流形边。

完整195对象18915对零位检查无超0.001 mm³刚性相交，六主动线无超阈值相交。历史柔性相交保留。材料连通及名义净空不能代替剩余壁厚、强度或制造配合验收。

## 13步前置关系

1. 在肱骨、GH盖及肌肉尚未装入时，放入M3螺母0／下垫圈0。
2. 装入保持螺钉0／近垫圈0，再装远垫圈0、外侧M2螺母0，共三步。
3. 对另一侧重复上述四步，完成两套保持件。
4. 裸肱骨保持GH屈曲10°，沿受检路径装入。
5. 依次放置盖0／上垫圈0、盖1／上垫圈1、M3螺钉0、M3螺钉1。

共4＋4＋1＋4＝13步；报告逐步列出固定对象和未装对象。拆卸按相反顺序。移动子组件不预设相互粘接，装配暂持与实际操作仍待设计／试验。M2外侧螺母按真实螺纹连接意图工作，但数字网格无螺纹，不能用几何止退探针代替紧固验收。

## 查看与复现

在项目根目录，使用已配置numpy／scipy／manifold3d及`.deps`的几何环境：

```powershell
python mujoco_arm/tools/build_shoulder_GH_nut_keepers.py
python mujoco_arm/tools/check_shoulder_GH_nut_keepers.py
```

两条会覆盖本分支输出；如需保留当前版先存档。使用MuJoCo环境查看已有网格：

```powershell
python mujoco_arm/tools/view_shoulder_manufactured.py --report '02_人体骨骼晶格肌肉方案/输出/shoulder_design/s1_GH_assembly_review/nut_keeper_candidate/assembly_check.json'
```
