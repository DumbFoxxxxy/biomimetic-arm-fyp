# S1-Y1真实截面试制检查件

更新：2026-11-02。四件均由当前两块肌腹的实际网格裁切，**不增加夹持结构、不修补空腔、不删碎片**。用途是检查切片、杆件／通道细节；没有等效于整肌肉的载荷边界，不能据此标定整肌肉力学或驱动能力。

## 实际输出与发现

## 完整肌腹新增检查项

[独立检查](readback_checks.json)同时对完整源网格的负体积封闭壳进行计数：

- 冈下肌：1个封闭空腔，约13.11811 mm³。
- 肩胛下肌：3个封闭空腔，约0.08114、0.17525、2.53619 mm³。

这些是空腔边界，不是额外TPU零件。将边界反向构造的正体积探针仅用于定位和相交计算，未填回设计。它们与名义0.6 mm钢丝及1.72 mm完整通道包络均无体积相交，因此目前没有证据把它们判为主通道堵塞；这也不证明打印后通道可用。位置包围盒均记录在报告中，需结合切片检查闭腔桥接、局部挤出与是否需要开敞修订。未因单材料连通或STL闭合而忽略内部空腔。

候选Y朝上时，排除底面后、法向向下超过45°的表面积占总面积约7.2%–19.8%。这里只是三角面法向统计；45°是诊断分组，不是设备能力阈值，也没有做支撑可移除性、桥接或真实切片分析。不能据此直接选定打印摆向。

## 复现与下一步

项目根目录，在有numpy、manifold3d及项目`.deps`的几何环境执行：

```powershell
python mujoco_arm/tools/build_shoulder_Y_print_inspection.py
python mujoco_arm/tools/check_shoulder_Y_print_inspection.py
```

脚本只写本检查目录，不替换S1-Y1源肌腹或候选指针。重新生成后须复核源哈希和裁切，实测记录继续保持空白。先确定设备、材料、喷嘴和实际切片配置，解决碎片与闭腔处理，再试制并记录穿线／损伤。需要力学标定时使用有明确夹持边界的方向样件和完整肌肉；裁切段不替代它们。
