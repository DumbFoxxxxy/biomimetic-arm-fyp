# 封闭空腔的局部开口比较

更新：2026-11-02。这是独立几何实验，**没有替换当前S1-Y1，也没有验证打印、强度或驱动能力**。原肌腹、钢丝、锚点与候选指针保持不变。

## 来源与限制

[独立检查](independent_checks.json)将当前四个闭腔与紧凑GH骨架父级的肌腹空腔比较，体积重合约99.956%–99.996%。四处均位于内部路径R3.3 mm的保留过渡区域，端部保护区重合为0；与既有闭腔高度一致，不能归咎于新外表面网格，也不能据此推断其功能意图。

保留R1.8 mm内部路径范围内的现有材料，以及两端R12 mm、内面法向−8至+3 mm内的现有材料。开口只在其余区域搜索，每个闭腔／孔径最多80个不同面种子方向。沿空腔正向法线穿过局部壁，用0.8／1.2／1.6 mm直径有限圆柱作显式切除；未填负壳、未静默删片或改变钢丝孔径。

孔径是比较参数，不是已确定喷嘴、工艺公差或可靠排气孔尺寸。即使几何开敞，也不能保证切片器生成开口或材料打印后不融合。

## 结果

| 模块 | 开口候选直径 | 实际移除材料 | 空腔结果 | 独立几何检查 |
|---|---:|---:|---|---|
| 冈下肌 | 0.8 mm | 0.09879 mm³ | 原约13.11811 mm³闭腔已开敞 | 通过下述限定检查 |
| 冈下肌 | 1.2 mm | 0.27865 mm³ | 同上 | 同上 |
| 冈下肌 | 1.6 mm | 0.57885 mm³ | 同上 | 同上 |
| 肩胛下肌 | 0.8／1.2／1.6 mm | 无设计切除 | 三闭腔保留 | 全部受检方向侵入保护材料，拒绝采用 |

冈下肌三件均为单正材料连通，零边界／非流形边、无负体积闭腔壳。对177个名义刚性对象、六条完整主动线分别复核，无超0.001 mm³相交；保护材料损失仅约−0.00000001 mm³的有符号数值残差，开口圆柱中回读残留材料小于0.00000027 mm³。该判据不是制造公差、承载证明或带肌肉全姿态检查。三件的细孔与局部削弱均待切片及试验判断，尚未选定孔径。

肩胛下肌的三种导出仍接近原模型，不作“优化成功”交付。报告中约−0.000027 mm³的有符号差分为布尔数值残差，不是实际负材料移除；其三闭腔总量仍约2.79258 mm³。有限搜索失败不证明任何开口都不可行，但不应为清掉闭腔而切断通道保护壁。

最初使用通用清理导出时，冈下肌保护区产生约0.00360 mm³额外差分，因此未采用；该运行及原脚本保存在[初次导出快照](../../../../../reviews/S1_2026-11-02/Y_vent_experiment/first_cleaned_export)。当前直接写出／回读，不再对候选简化。没有通过放宽原相交阈值获得通过。

## 文件与复现

[生成清单](vent_trials.json)保存六次试改、每个被拒绝方向、实际切口、网格与来源哈希。[独立检查](independent_checks.json)另外回读网格，核对闭腔、保护材料、实体冲突和钢丝。STL路径见各记录的`mesh.file`。

项目根目录，几何环境含numpy、manifold3d与项目`.deps`时：

```powershell
python mujoco_arm/tools/build_shoulder_Y_vent_candidates.py
python mujoco_arm/tools/check_shoulder_Y_vent_candidates.py
python mujoco_arm/tools/section_shoulder_Y_vent_candidates.py
```

渲染记录切面仅需Pillow：

```powershell
python mujoco_arm/tools/render_shoulder_Y_vent_sections.py
```

当前不自动更新候选指针。下一步结合实际切片选择是否采用冈下肌开口，并检查肩胛下肌保留过渡区的构造方式；任何修订都需重新导出、复核接口／通道与实际打印。封闭空腔本身不等于驱动失败，开掉空腔也不等于肌肉性能改善。
