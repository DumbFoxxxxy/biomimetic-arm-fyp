# 肩胛下肌开口搜索：限制刀具后伸

原试改的平底圆柱刀具在闭腔面后伸一个孔半径，可能跨越薄空腔的对侧壁。新搜索从实际空腔正体的反向射线获得局部厚度，后伸改为厚度20%与0.02 mm中的较小值；端口、R1.8内部通道保护材料和接受阈值不变。

[生成记录](outward_trials.json)保留原／新同面刀具的保护区损失对照。例如0.8 mm两条选定切口，后伸约0.01556／0.02000 mm，原刀具会分别移除约0.15543／0.11878 mm³保护材料，新刀具不超过既定判据。

0.8／1.2 mm孔径可开敞2.53619与0.17525 mm³两闭腔，仍保留0.08114 mm³闭腔；1.6 mm还保留0.17525 mm³闭腔。新方向仍是有限搜索，不证明其他开口不可行。[独立复核](../../transition_stock_comparison/independent_checks.json)重新检查材料、接触、覆盖、刚体与钢丝，区分“指定切口无冲突”和“全部闭腔已处理”。

这修正了搜索实现，未证明实际可打印。原失败清单不覆盖、不改写。新试改不直接替换默认装配；最终当前选择见[S1-Y2](../../../s1_y2_transition_stock/README.md)。
