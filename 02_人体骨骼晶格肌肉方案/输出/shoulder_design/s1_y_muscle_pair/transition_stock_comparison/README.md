# 已分类过渡空隙：填实与开口比较

本目录存放显式设计变更，不是自动修网格。仅对闭合空腔、R3.3内部路径保留过渡区内、名义完整孔腔和端部保护区外的空隙进行TPU填实；每处体积、位置及排除检查在[生成记录](transition_trials.json)。空腔分类失败即拒绝生成，没有一律填所有负壳。

| 冈下肌封闭过渡空隙填实 | 13.11811 mm³ | 仅数值残差 | 0 | S1-Y2采用 |
| 肩胛下肌三空隙填实 | 2.79255 mm³ | 仅数值残差 | 0 | S1-Y2采用 |
| 肩胛下肌0.8 mm开口＋最小空隙填实 | 0.08111 mm³ | 0.74706 mm³ | 0 | 保留比较，未采用 |

选择前两项以保留现有外部轮廓，避免依赖未选打印工艺还原细孔。新增材料约占各原肌腹0.156%／0.036%；这不证明刚度、折叠或驱动能力不变。两种路线的机械优劣尚未验证。

[独立检查](independent_checks.json)包括三种限后伸开口、两种纯填实和一种混合方案；检查源网格回读、预期布尔设计重放、原保护材料、177刚体、六主动线、内部／表面分层覆盖及有限接口探针。三种纯开口仍有闭腔，不能因零位配合清而写成处理完成。相交报告阈值0.001 mm³不是打印公差，有符号数值残差均保留。

仅采用两件纯填实TPU并重新构建整肩装配，详见[S1-Y2](../../s1_y2_transition_stock/README.md)；本目录各生成比较记录保持创建时状态，不将历史`adopted_as_current=false`改成整批采用。唯一当前选择以[候选指针](../../../../../design/S1_CURRENT_CANDIDATE.json)为准。

生成与独立检查脚本为`build_shoulder_Y_transition_stock.py`及`check_shoulder_Y_transition_stock.py`。来源、依赖、候选网格和脚本哈希均在报告中。未打印、未测力、未得到实际驱动范围。
