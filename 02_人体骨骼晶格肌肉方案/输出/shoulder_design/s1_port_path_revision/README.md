# S1 统一孔路与三角肌共享止端候选

日期：2026-11-02。属于接口重构候选，不替换已发布端部，不构成完整S1制造放行。

## 为什么重构

原零件分别开孔，但钢丝、端垫、腱段和肌腹没有共用同一条主路径，整装后9段已知中心线均碰到相邻材料。
现在先定义6条从手拉入口、端盖、端部连接段、肌腹到远端终端的几何主路径，再由该定义生成局部零件。
骨骼中心、骨侧座中心及原R11共享座不移动。中段仍为名义静态通道，不假定运动时固定在世界坐标。

## 当前路由结果

`routes.json`是首轮候选，`routes_separated.json`是经过共享止端分配搜索的候选。
保留原肌腹中段路径，短连接段按骨障碍重新规划，记录全部端口、入口/出口面和截取长度。
这些截取长度只是当前接口重构边界，**不是已经测得的有效肌腹长或收缩行程**。

共享止端设置三个独立端口，位于原座法平面上半径4.5mm的圆，角位置30/150/270度。
保持原2×M3@14mm的固定模式。检查两个端口分配后选出不交叉的分配，试验记录见shared_port_search.json。

- 三条完整名义路径最小中心距约3.2552mm；
- 以1.7mm孔径计算，三条通道之间可保留至少约1.555mm间隔；接口局部采用1.72mm清孔后仍大于0.75mm；
- 端口压接座半径1.4mm，与M3半径1.7mm孔之间的最小几何壁厚约0.7328mm；这是几何值，未证明承载；
- 三个共享止端连接段按外半径3.2mm的名义过渡包络检查，对三骨相交均为0；
- **其他位置尚非全部解决**：三角肌中束起点的3.2mm外包络仍与肱骨相交约3.904mm3，不作为通过，也没有删骨掩盖。

当前还未按新路径重生成全部肌腹和连接段，不能用新路径去宣称旧制造件已打通。

## 已生成的三端口局部原型

目录`triplex_terminal/`：

- `TPU_pad.stl`：基于原共享端垫，增加三个局部密实TPU加强台并按主路径开孔；
- `rigid_cap.stl`：R11×4mm盖，两个M3孔，三个独立线孔及压接止挡座；
- `FJ1468_stop_blank.stl`、`FJ1513_stop_blank.stl`、`FJ1467_stop_blank.stl`：三枚独立止挡坯的选型/加工参考。

前两件为打印候选；止挡坯不是已经验证能夹住钢丝的打印件，应落实实际金属压接件与工艺后再测。
止挡坯外径2.5mm、长度2.5mm、内孔0.9mm；压接座半径1.4mm、深2.6mm。未压接时不提供夹持能力。

接口通过孔采用1.72mm清孔（半径0.86mm），用于消除新弯曲孔与原孔交接处的薄片夹点；原主肌腹孔径仍以1.70mm为候选。
孔径变化明确记录于check.json，未放宽水密和单连通验收标准。
5件均在局部毫米坐标导出，共用`translation_source_mm`恢复源坐标；不可忽略变换。

## 已核对和未核对

5件实际STL均单连通、水密、无边界边/非流形边，回读体积误差<=1e-5。
三个钢丝几何与这5件全部相交为0；端垫和盖互相交叠为0。
对骨最大相交为端垫/肱骨约0.000573mm3，在当前0.001mm3数值阈值以下，不能宣称数学零。

止挡坯向肌肉侧平移：0及0.04mm时与盖不相交，0.06mm时被座底台阶挡住，体积约0.02569mm3。
这仅证明名义几何止挡，**不证明压接力、防脱强度或外向捕获**。

尚未检查：与其他肌肉/夹具完整配合、真实肌腹与连接段连续成型、穿线/装配顺序、M3五金及工具空间、运动变形、接触稳定、摩擦、打印工艺和力学性能。
全局6条钢丝驱动能力仍未知；不把这一局部原型通过提升为完整孔路或三轴通过。

## 复现

环境需要numpy、scipy（与相关已有脚本一致）及manifold3d；本机可使用D:/MujocoEnv/Scripts/python.exe并加载仓库.deps。

```powershell
python mujoco_arm/tools/design_shoulder_port_paths.py
python mujoco_arm/tools/search_shoulder_shared_ports.py
python mujoco_arm/tools/build_shoulder_triplex_terminal.py
python -m unittest discover -s tests -p test_shoulder_port_geometry.py -v
```

check.json及各路由JSON保存实际几何、输入来源及数值，不包含物理性能通过结论。
