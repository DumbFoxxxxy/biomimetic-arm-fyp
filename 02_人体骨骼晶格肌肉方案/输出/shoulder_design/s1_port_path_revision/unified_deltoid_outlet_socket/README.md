## 设计变化

- 输入为 `../routes_outlet_candidate.json`。保持骨骼、骨座及共享三端口，重生成真实三角肌 TPU 网格和4个端盖。
- 中束端盖与R3弯曲导向管一体，外半径1.8mm。TPU按外形生成半径1.9mm的配合孔，名义径向间隙0.10mm；不是只按钢丝孔减料。
- 端盖沿名义厚度两面及径向各预留0.15mm配合避让。上面0.15mm用于容纳原盖坐标取整与实际配合；不再多切6mm。
- 骨侧端盖局部修整保持前轮候选的做法；没有移动骨骼或关节中心。
- STL回读产生1.082907×10⁻⁶mm³独立正材料碎屑，已记录位置并删除。保留全部负向封闭壳，TPU仍有12个超过记录阈值的封闭空腔，制造支持尚未评估。真实第二个材料部件不会按此规则被删除。

## 尚未闭合

1. 自由TPU的0.75mm名义壁厚守护区仍有前/后/中束0.007982/0.003037/0.003678mm³缺失残差；未改变验收阈值。需要定位其来源、评估实际壁厚，不能仅凭体积小就通过。
2. TPU骨侧接触及导出后数值残差尚未分类成合法接触区与真实干涉。
3. 其他模块按统一路径重生成；完整五金、夹具垫、衬垫、导管反力固定与钢丝压接仍缺。
4. 小端盖的实际紧固方式、弯管装配和拆卸路径未证明。R3不代表钢丝/导管已满足疲劳或摩擦要求。
5. 本候选全部为零位静态几何；没有验证柔性变形、连续可达范围或实际驱动力。

## 复现入口

仓库根目录中运行 `mujoco_arm/tools/build_shoulder_unified_muscle.py --routes <routes_outlet_candidate.json绝对路径>`；当前环境需将 `.deps` 与 `mujoco_arm/tools` 加入Python搜索路径。

随后运行 `mujoco_arm/tools/check_shoulder_manufactured_assembly.py --unified-report <本目录check.json绝对路径>`，脚本核对新件和主路径哈希，不混用旧三角肌端垫及腱段。三枚止挡只有在共享远端口与原参考路线逐项一致时才允许复用。

MuJoCo查看命令（仓库根目录，环境已安装MuJoCo/Pillow）：

```powershell
& 'C:/Python314/python.exe' 'mujoco_arm/tools/view_shoulder_manufactured.py' --report '02_人体骨骼晶格肌肉方案/输出/shoulder_design/s1_port_path_revision/unified_deltoid_outlet_socket/actual_assembly_check.json'
```

加 `--render` 生成 `available_parts.png`；再加 `--detail` 只显示独立弯曲端盖并明确隐藏周边。交互和渲染均为静态查看，模型DOF为0，碰撞由实体布尔报告检查，不能据图中接触表现推断运动通过。
