# 三角肌整体 TPU 与中束出口候选

2026-11-02。静态修订证据；不替代当前制造基线，不代表整装或运动验收。

后续状态：弯曲盖与真实TPU配合孔已联合生成并检查，见 `unified_deltoid_outlet_socket/README.md`。本页保留前一轮问题定位和物理盖厚候选的对照数值，不代表最新集成状态。

## 本轮定位与修改

1. 按统一路径重生成三角肌实际晶格、连续通道壁、端垫和过渡袖。输出为真实制造网格，保留原始骨骼、附着座和其他肌肉。
2. 首版 `unified_deltoid/check.json` 中后束自由 TPU 壁厚守护区缺失约3.1664 mm³。根因是端盖避让柱在实际盖厚之外延长6 mm，误删自由 TPU。
3. `unified_deltoid_physical_cap` 只按实际盖厚及内侧0.15 mm间隙避让。后束缺失降为0.003074 mm³；前/中束仍有0.007987/0.004100 mm³残差。未放宽判据或将其登记为壁厚通过。
4. 新增完整钢丝对骨骼检查，发现原 FJ1467 中束端盖外5 mm拉线段与肱骨相交0.953383 mm³。通道内钢丝不碰自己的 TPU，不能证明外部走线可行。
5. 保持骨骼和附着座，有限搜索中束弯曲端盖出口。选得倾角60°、座平面方位90°、弯曲半径3 mm、导向管外半径1.8 mm、通道半径0.86 mm。曲线角度采样不大于1°，与原入线方向相切；这些参数是几何候选，未取得钢丝弯曲/疲劳/摩擦资格。
6. 导向管是与刚性端盖一体的真实实体。导管体末端之后钢丝继续延伸3 mm，使孔道穿出圆头，避免再次形成封闭腔。原端盖对肱骨0.101656 mm³的局部相交通过修整端盖外形消除，没有修改骨骼。

## 可复现入口

在仓库根目录，以安装了 numpy、scipy、manifold3d 的环境运行；本机 manifold3d 位于 `.deps`，需加入 Python 搜索路径，工具目录为 `mujoco_arm/tools`。

- `build_shoulder_unified_muscle.py`：当前默认生成带明确0.15mm配合间隙的 `unified_deltoid_fit_gap`；`unified_deltoid_physical_cap` 保留为前轮无上侧配合间隙的对照。传入 `--routes <routes_outlet_candidate.json绝对路径>` 生成 `unified_deltoid_outlet_socket`。
- `check_shoulder_master_paths.py`：默认复查旧统一路线，保留其失败；`--routes <routes_outlet_candidate.json绝对路径>` 复查新候选。
- `design_shoulder_origin_outlet.py`：生成新路线候选和 `origin_outlet_candidate/FJ1467_origin_cap_with_guide.stl`。

相应 `check.json` 含局部 STL 的源坐标平移、哈希和回读证据。不可将局部 STL 以零平移直接放回源坐标装配。
