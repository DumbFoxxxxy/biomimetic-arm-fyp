## 合体前发现的实际问题

[整合审查](integration_audit.json)确认两版本肱骨并非同一几何：肘部特有材料约9559.16 mm³，S1特有材料约8355.37 mm³，差异分布于肘关节区域及骨干安装孔／连接区。不能简单叠两根骨，也不能直接做并集填掉另一套所需孔腔。

将肘部93对象放到同一坐标后，其中9件相对S1肱骨出现超过原肘部基准的实体相交，包括4根骨侧螺钉、前臂刚体、肘轴承、间隔件和销轴。这是需要统一共用肱骨特征的接口证据，不是完整整臂碰撞审查结果。

两块肘部TPU网格没有被丢掉，仍在预览中。[精确回读复核](elbow_exact_mesh_review.json)分别发现9和5条非流形边；当前布尔检查库虽返回NoError，也不能据此替代拓扑检查。因此这两件的共用骨配合检查尚不完整，源网格需要后续复核。未改肘部原件，未声称打印或实物性能通过。

## GitHub发布的实际前提

1. 完成S1剩余前束、中束、共享远端固定与整肩机械几何复核，明确局部已证据化与尚未验证事项。
2. 将肩部和肘部的共同肱骨特征落实在同一个可编辑骨模型中，复核骨段与接口；消除或明确处理新增实体干涉，不能隐藏重复骨或连接件来制造通过。
3. 生成最终选定版本的网页资产，在本地检查拖动旋转、缩放、图层及模型清单，再更新现有GitHub Pages和仓库首页入口。

发布页面应展示肩—肘—前臂整体、骨骼、TPU肌肉和连接件，标明版本及验证边界。静态几何展示不宣称TPU变形或钢丝驱动已经验证。**不新增打印、完整有限元或实测全部动作范围作为网页发布前置条件。**

现有站点实施方式见[交互模型查看与部署](../../../../docs/GITHUB_MODEL_VIEWER.md)。本次没有修改`docs/viewer/scene.json`、`scene.bin`或线上网页，也没有执行Git提交／推送。
