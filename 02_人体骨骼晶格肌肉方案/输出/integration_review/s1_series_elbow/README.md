# S1 与串联滑块肘部组合检查

使用当前 S1-Y2 的盂肱结构、可归属的肩部刚性接口及现有胸廓和肩带基准，接入 FJ1477 串联滑块、弹簧包络及最新肘部端盖。共登记 246 个刚体，原屈肌、短导向伸肌及 S1 肌腹另存几何引用。两套模型的盂肱中心吻合。在从中心向下 40 mm 起的局部比较区，换用肘部肱骨时的增减量均小于 0.001 mm³。肩胛、锁骨沿用现有胸廓链的 SC/AC 修订版本。

旧台架、尚未分配到骨段的接口和自由肌腱端不进入这轮刚体检查。冈下肌、肩胛下肌及大圆肌的近端盖按肩胛所有者处理。它们和相应支承的装配有效性仍待复核。详见[组合装配与所有者](assembly.json)。

## 肩肘组合自由受力

将现有串联滑块肘部接到自由转动的 GH 球铰，共七个速度自由度。锁骨和肩胛固定，三角肌三束及大圆肌用端点间的等效拉力和弹簧阻尼表示，两条 Y 肌肉尚未接入。三角肌前束和中束各以 10 N 峰值命令为肩部工况，肘屈肌以 25 N 峰值命令为肘部工况。对照重力、单独拉肩、单独拉肘和同时加载，各保存 201 个状态，间隔 0.01 s。

四组都在 **0.28 s** 的采样点首次发现肘关节销与右第十肋 FJ3330 相交，此时肱骨相对零位方向变化约 9.2°。包括只施加重力的工况。模型仅求解原有肘伸展止挡接触，其他刚性干涉由独立网格求交发现。原始轨迹中同时加载的肘屈曲峰值约 100.38°，出现在首次干涉之后，只用于诊断。

起始姿态的 GH 重力矩为 0.477 N·m。四路肩部拉力各限 0–25 N 时，最小残余力矩为 0.207 N·m。该结果来自估算质量、端点力和固定肩带，下一轮应核对起始姿态和肩部支承的重力平衡，再重算无干涉的组合路径。完整布线仍留在集成阶段。
