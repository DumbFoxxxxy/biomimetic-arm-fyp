# 肘部 TPU 参数对比样件

这里是试验设计与制造网格，**没有实测性能，也没有通过切片验证**。
每个 STL 只是一件样件；每类需独立打印三件，而不是把一次打印的数据复制三份。
设备、喷嘴和材料品牌未定，TPU95A仅为文献支持的候选。

| 样件 | 本地加载X／宽Y／高Z单元尺寸 mm | 构成 | 目的 |
|---|---|---|---|
| C0 | 10／15／20，轴向6格 | 八条中心—角点杆、端板 | 稀疏晶格基线 |
| C1 | 同C0 | 加表面菱形杆网、分段短导管 | 当前肌肉结构的简化对照 |
| C2 | 同C1 | 再加连续钢丝通道壁 | 单独观察连续管壁带来的变化 |
| C3 | 15／10／30，轴向4格 | 稀疏晶格、端板 | 原参考尺寸的独立对照 |

所有杆名义直径2mm，单列横截面，轴向单元跨度60mm，两端各3mm夹持板。
杆的圆截面超出节点中心平面，因此60mm不是外包络长度；以实测夹持面间距记录标距。
C1/C2有直径1.7mm通孔及直径0.6mm钢丝候选；C2连续壁外径3.2mm、壁厚0.75mm。
这些通道尺寸是本项目试验值，不是从论文附表核实的制造参数。
C3不是2026论文样件的复刻：打印方向、端板、圆角、表面结构均可能不同。
不要把C3与C0的差异只归因于某一个参数。

生成器为 `D:/XJTLU/PSP/mujoco_arm/anatomical_concept/build_elbow_test_coupons.py`。
`manifest.json` 记录体积、坐标与网格回读结果。四类均为单一连通实体，OBJ/STL回读通过；
C1/C2名义钢丝与通道实体无相交。这些检查不证明打印后通孔可用。

## 打印前

1. 先选材料和设备，在切片预览中检查2mm杆、0.75mm通道壁、悬垂和孔道连续性。
   当前摆放使加载X水平、非加载Z竖直，属于候选方向。不得在无法清除的孔内生成支撑。
2. 用小段通道确认实际孔径和穿线，再打印三件／类；保持同一批材料、方向及切片条件。
3. 记录实际尺寸、质量、材料批次、喷嘴、层高和温度；不套用未经核对的固定切片参数。

## 测量与选型

先进行外部夹具轴向压缩／拉伸比较，再单独对C1/C2进行内部拉线试验，不能混作一种试验。
夹持两端板，逐步增加位移；出现孔道闭塞、杆相互锁死、端板损伤或不能恢复时记录并停止该次加载。
每个试验点记录加载／卸载、位移、可用时的力，以及卸载60秒后的残余位移。
先用小幅往返筛查，再在可恢复区间做至少10次重复作为初步重复性观察，不能据此宣称寿命。
记录有无卡线、钢丝磨损、管壁破损及端部撕裂。没有力传感器时，力栏留空，不能推算模量。

`measurements_BLANK.csv` 提供12件独立试样的空记录行，自行增加循环／位移记录。
生成器不会覆盖该CSV。C1对C2可比较连续壁影响，但不能把短直样件行程直接移植到异形肌腹。
选出候选参数后，仍需测试两块完整肌肉及安装后的肘部；本轮没有这些实测结果。
