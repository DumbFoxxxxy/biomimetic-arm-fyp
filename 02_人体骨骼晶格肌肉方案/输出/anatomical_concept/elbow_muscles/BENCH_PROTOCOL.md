# 单肌肉样件检查准备

本步骤用于取得真实数据，不是打印或驱动已经通过的记录。整臂骨侧安装和肌腱走线尚未确定，先在独立夹具上检查模块。材料、打印机和切片参数应随样件记录。

每个模块的打印候选位于`print_candidates/`：TPU_muscle是柔性肌腹，两个rigid_cap为刚性端板。父目录的螺栓、螺母、垫圈和压接止挡STL仅作金属硬件尺寸包络。名义清单为4个M3×12螺栓、4个M3螺母、8片垫圈及1个与候选0.6mm钢丝匹配的实际压接止挡；硬件和夹持能力须实测。

打印前先在切片器逐层查看内部枝条、导向管、端部螺母侧向槽和外网格。单连通实体不证明无悬空或可免支撑打印；候选摆放的收缩方向水平、20mm横向晶格方向竖直，仍需核对外网格/端板的支撑与孔质量。不要把打印坐标文件叠回解剖装配，父目录保留公共装配坐标。

名义装配顺序：

1. 从侧向开口装入螺母及内侧垫圈。
2. 放置两端板，放外侧垫圈并安装M3螺栓。数字检查不包含实际螺纹旋拧或工具可达性。
3. 将主动钢丝从近端导管孔穿过各短导向单元，再穿过远端端板。
4. 用实际压接工艺固定止挡，拉回钢丝使止挡落入远端座。未压接的名义孔径不会夹住钢丝；松弛时的止挡留置及重新入座也要检查。
5. 检查远端横孔穿被动短肌腱的可操作性。此时不裁定最终关节肌腱长度，也不按未建模的滑轮约束手动测试。

把近端刚性端板固定到独立夹具，远端端板保持能够按真实受力移动。逐步增加较小的拉线行程，分别记录拉线量、两端板间距变化、输入拉力和可测的远端输出力；这些量不能互相代替。每次卸载后记录恢复情况、止挡滑移、卡线以及导向管/TPU端部损伤。出现不可重复的滑移或损伤时先查明原因，再扩大行程。

重复加载/卸载后记录可重复行程，而不是以首次极限变形作为可用行程。不把论文的材料数据、理想卷绕计算或旧25%假设填成实测值。`bench_measurements_template.json`中的实测字段初始为null，复制一份记录实际样件数据；保留未修改的模板。

这些结果用于修正孔径、晶格参数、端部、反力夹具和后续实际肌腱/卷绕设计。完成打印与测试前，不宣称肌肉能够覆盖肘0–150°或驱动整臂。
