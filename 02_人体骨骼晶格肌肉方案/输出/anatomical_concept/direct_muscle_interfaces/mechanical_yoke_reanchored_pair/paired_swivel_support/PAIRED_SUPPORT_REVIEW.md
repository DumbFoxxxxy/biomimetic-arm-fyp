# M10 肘部：两端盖可转动的实体骨侧连接候选

两块异形TPU晶格肌肉仍通过内部钢丝工作。远端盖增加短耳轴和叉架，让端盖能够转动；
叉架由一体连通支架接到原尺骨两处安装座。没有使用外部被动钢丝环路，没有改变关节中心、
肘轴或骨长。原文件与前一固定端盖方案保留，本候选未定版。

## 结构与力的传递

钢丝在TPU肌腹短导管内穿行，终端压接件向远端盖传力；端盖／TPU端垫的合力经短耳轴、
销轴和叉架传到一体支架，再经原两组尺骨螺栓座进入前臂。
近端盖、肱骨适配件和导管反力接口继续保留。钢丝压接、销轴止退、轴承间隙、螺纹与预紧
尚未完成实物或工序验证，不能将上述名义传力关系当成承载验收。

新增／修订实体共11件：一体骨侧支架、两件可转动端盖、四枚名义M2短肩销和四枚垫圈。
每个端盖两侧耳轴外半径1.8mm、盲孔半径1.1mm；叉耳厚3mm，端面名义间隙0.2mm。
销轴固定及轴向防脱仍需落实并检查，当前CAD使用未建螺纹的包络，不代表已经验证可靠锁紧。

屈肌普通叉架的后桥碰前臂，前桥20mm时约141°碰肱骨。有限候选筛选后改为前移16mm、
沿原肌腹轴向下移16mm的斜连接段。伸肌采用后方20mm桥。支架保留原两处骨座，
共同绕行段采用10mm侧向伸出、18mm后方偏移；三个前方连接候选碰前臂后被排除。

## 当前证据

| 检查范围 | 结果 |
|---|---|
| 117件真实制造网格的名义零位 | 刚性相交0、TPU相交标记0 |
| 两个端盖和新支架共同运动 | 肘0–150°，266个条件姿态未检出新增刚性干涉 |
| 采样步长 | 肘和两枚端盖的规定转角步长均≤1° |
| 回程 | 独立重算全部改变的刚性配对及额外骨性参考，未检出干涉 |
| 113件确定刚体 | 保留关节层级：肘＋两枚远端端盖铰链，无肌腹滑轨 |
| 11件新增／修订OBJ/STL与STEP | 回读通过 |
| 115个名义刚性实体整体STEP | 有效，双向顶点误差＜0.001mm |
| MuJoCo配准 | 零位117件；刚体113件在名义零位及规定0/90/150°姿态逐件通过 |

普通相邻零件没有整对关闭实体干涉检查。父版本未改动刚性配对的肘部证据按文件哈希核验复用；
全部改变的配对重新检查。这个结果只覆盖规定的肘部路径，不是重新完成整臂各自由度联合验收。

名义CAD与117件静态场景中，两枚端盖相对转角均为0。条件运动演示按“尽量朝向肌肉近端”
另行规定端盖角度；条件零位也可能带有小转角。**没有求解被动平衡**，不宣称实际端盖一定
按该规律转动。TPU未参与运动验收，刚性演示不显示TPU，不能看成肌肉收缩动画。

## 文件入口

- `cad/paired_swivel_arm_review.step`：115个名义刚性实体；包含两枚未压接的名义止挡坯。
- `cad/paired_bone_frame.step`、两件`FJ…_cap_rotor.step`与销轴／垫圈：可分别导入。
- `assembly.json`：117件的网格来源、坐标和所属骨段。
- `neutral_view.xml`、`paired_cap_detail.png`：实际TPU与骨架的名义零位。
- `rigid_hinges.xml`、`rigid_motion.gif`：113件刚体的规定运动，TPU和两枚未压接止挡不计入。
- `conditional_motion.json`、`geometry_checks.json`、`review_status.json`：运动、范围与证据。

STEP为可导入的分面BRep，不含SolidWorks原生参数特征树、螺纹或装配配合。

在项目根目录手动运行查看器：

```powershell

& 'C:/Python314/python.exe' 'mujoco_arm/anatomical_concept/view_paired_swivel.py' --motion
```
