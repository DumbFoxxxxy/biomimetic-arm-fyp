屈肌 FJ1486 和伸肌 FJ1477 沿用原版肘部肌腹及端盖几何。模型读取两块肌肉在中立位的既有端盖孔位。近端孔位固定，远端孔位在虚拟台架上沿两孔连线平移。等效拉力在两端等大反向，使肌腹轴向缩短。台架平移约束仅用于测量轴向响应。

| 肌肉 | 中立位孔距 | 两孔轴线与远端孔内名义钢丝切向的夹角 |
| --- | ---: | ---: |
| FJ1486 屈肌 | 180.74 mm | 3.06° |
| FJ1477 伸肌 | 172.18 mm | 6.31° |

| 假设轴向刚度 | 保持末端预测缩短量 |

| 100 N/m | 10.0 mm |

## 原伸肌的长行程与短导向

从原附着点、25 N 屈肌和 50 N/m 伸肌工况读取 1,601 个肘轴与端盖姿态。FJ1477 中立位的孔距为 172.18 mm，内通道中心线长 172.53 mm。峰值屈肘 98.58° 时，两孔间距增至 246.80 mm。即使此时通道完全拉直，相对于原通道仍需增加 **74.28 mm**。按两端孔面带动中间截面的插值，通道约需增加 79.96 mm，变形最大的导向段长度增至原来的 1.63 倍。该倍数描述插值模型，实际管壁与晶格的变形需要材料模型或实测。
