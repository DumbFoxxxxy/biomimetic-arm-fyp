# 当前整臂动作验证与回放

[双视角动作视频](current_actions.mp4) · [峰值姿态总览](current_actions_overview.png) · [逐帧数据和首碰记录](current_actions.json)

回放采用当前胸廓、肩胛、肩部 S1 和肘部共用装配，使用 K1 伸肌端盖让位候选和最新前锯肌胸廓导向。各动作从中立位分别开始。图中青绿色是前锯肌线，黄绿色是新增导向，蓝色和紫色分别标示上斜方肌和大菱形肌。白色虚线是中立位手臂，内外旋中的橙色标记显示肱骨绕长轴的转动。

## 动作范围

| 动作 | 本次展示范围 | 证据与边界 |
|---|---:|---|
| K1 肘屈曲 | 0–31.31° | 规定姿态。端盖让位候选的原审查在 31.41° 首次记录 FJ1467 钢丝干涉。 |
| K2 肩前屈 | 0–41.70° | 规定姿态。原审查在 41.8° 记录钢丝与肘屈肌转接座干涉。 |
| K3 肩外展 | 0–13.60° | 规定姿态。原审查在 13.7° 记录钢丝与肩胛骨干涉。 |
| K4 肩内旋 | 0–90.00° | 规定姿态，达到原几何探针上限。肩胛下肌另有每 10° 一次的局部受载试验。 |
| K5 肩外旋 | 0–10.00° | 规定姿态。原独立肩袖试验在 20° 样点记录冈下肌短肌腱与共用支座干涉。 |
| K6 肩胛上回旋 | 0–11.79° | 前锯肌中束与上斜方肌主动牵引。4 秒末距中立位 0.004°。 |
| K7 肩肘联合抬升 | 0–17.33° | 规定姿态，保留到既有组合检查的最后样点。量的是肱骨方向变化。 |
| 肩胛前伸 | 0–15.49 mm | 规定 SC/AC 协调姿态。 |
| 肩胛后缩 | 0–2.86 mm | 上斜方肌和大菱形肌主动牵引，在 4 秒末回到中立位。 |

另行测试了肩胛前伸主动牵引。前锯肌驱动 GH 中心向前 3.55 mm，卸载回程越过中立位约 0.22 mm 时，前锯肌钢丝碰右第六肋，新增导向包络同时与肩胛骨相交。这条试验轨迹没有纳入成功回放。

历史首碰和肩袖试验细节见[整臂审查](../README.md)。K6 的导向、几何边界与回位条件见[前锯肌走线修整](../scapular_control/ROUTING_REFINEMENT.md)。

## 在 MuJoCo 中查看

在项目根目录运行。回放需要 MuJoCo、NumPy、Pillow 和 imageio-ffmpeg。这里使用现有的本地依赖目录。

```powershell
$env:PYTHONPATH = (Resolve-Path .deps).Path
python -X utf8 tools/render_current_arm_actions.py --view
```

鼠标可旋转和缩放，数字键切换动作，P 暂停。启动时可用 `--action K6` 直接查看肩胛上回旋。去掉 `--view` 可重新录制视频和生成总览图。

## 验证方法

- 规定姿态动作复用原审查的去程姿态，在同一共用整臂中复查新走线与支承，按相同姿态逆序复算回程。有新增接触时，从中立位到首碰之间保留通过的区段，边界细化至 0.1° 或 0.1 mm。
- 钢丝牵引动作由约束后的 MuJoCo 子模型计算，使用仅施加拉力的钢丝和等效回位弹簧、阻尼以及理想重力预平衡。将该动力学轨迹放回整臂检查，按 0.04 秒间隔、轨迹极值和末帧筛查。回放用到对应模拟轨迹的全量记录。
- 检查对象为新钢丝和支承包络与整臂刚件、既有局部钢丝的相交，超过 0.001 mm³ 记为干涉。配合区域采用已有审查定义。原零件之间的结果沿用各动作的既有报告，规定姿态末帧是本次展示的证据边界。
- 肩胛前伸、后缩以 GH 中心相对胸廓的前后位移计量，联合抬升使用肱骨方向相对中立位的实际转角。

全臂 TPU 实际形变、随载荷移动的肩袖组件、同时牵引多个关节和实物行程仍待验证。
