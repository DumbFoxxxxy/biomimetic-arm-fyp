# 肘部肌肉打印与手动拉线记录

本步骤测试单肌肉，不要求先打印整臂；暂不进行电机驱动验收。

1. 使用 `assets/elbow_flexor_print_mm.stl` 或伸肌对应文件。单位毫米，
   已将长轴摆正并将最低点放到 Z=0；约190毫米的全长须先确认打印空间。
2. 材料以 TPU95A 起步。杆径2毫米、钢丝通孔2.4毫米、端部安装孔3.4毫米。
   这些是本版候选尺寸，不是材料性能保证。
3. 先在切片预览中确认杆件连续、孔道畅通、端板首层及外网格悬垂。
   实际层高、温度、速度、流量、支撑和耗材干燥按使用的打印机/耗材标定；
   不把未经切片检查的模型称为免支撑可打印件。
4. 固定 A 端的密实端板。使用平垫片分散夹持压力，不夹持中间晶格杆。
   PTFE 导管外壳必须固定到同一个台架，不能让导管悬浮吸收拉线行程。
5. 从 A 穿入候选直径1毫米钢丝，经中心孔道到 C；在 C 用可拆卸压线端头固定。
   不让裸绳结直接切割 TPU 孔壁。C 的另一接口连接短肌腱，再连接远端固定点 B。
6. 首先只做自由端手动拉线，记录 A-C 的实际长度、线端行程、弯曲方向、拉力和恢复。
   不强制 C 沿轴线移动，也不把电机收线长度当作肌肉长度变化。
7. 逐级增加位移，遇到卡线、杆件锁死、明显磨损或端部损伤即停止该次测试，记录首次限制。
8. 依据实测可重复行程，回填肌肉模型，再设计 A 支架、B 锚点和整臂夹具。

记录字段：样件编号、材料批次、打印方向、切片参数、自然端距、受载端距、
线端位移、拉力、松线后端距、重复次数、损伤位置、通道磨损、限制原因。
没有设备测出的字段留空，不填预测值冒充实测。

本版不预设25%或其他压缩/伸长率为合格能力。骨骼145度的肘运动结果不能
直接作为这对肌肉能够驱动145度的证据。
