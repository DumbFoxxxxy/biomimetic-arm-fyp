## 写作约定

1. **只写三类内容**：这周做了什么（有产出）、验证到了什么（有判据）、卡在哪（有依据）。
2. **每个"完成"都要能指向仓库里的文件或数字**，不能只有形容词。
3. **未验证项单独列**，不许并进"完成"。这是本项目最容易出错的地方。
4. 长度控制在一屏内；细节放链接，不贴大段日志。
