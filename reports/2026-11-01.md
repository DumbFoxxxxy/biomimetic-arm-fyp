## 3. 未验证 / 不能当成结论的

| 项 | 为什么还不能说 |
|---|---|
| TPU 实际驱动范围 | 0–150° 是刚性路径检查，不是肌肉能拉到的角度 |
| 打印可行性 | 0.75 mm 通道壁、1.7 mm 孔从未打印验证 |
| 摩擦与卡线 | 连续管壁可能增加收缩阻力，需实测比较 |
| 压接夹持力 | 压接坯至今是名义几何 |
| 夹具柔度 | 唯一必须实物标定的项，未做 |
| 完整装配 | 只验证到"刚性接头 + 裸前臂"子装配 |
| 肩部 | 只有文档，没有任何几何 |

## 4. 卡点

1. **通道路径目前是几何解**：端点是按力矩符号筛的，中段是按断面极点最短步进，
   不是肌纤维方向（源模型没有纤维数据）。按作用线重构的方案已评估，暂不实施。
2. **6 个止点在肱骨近端的排布**：每个座直径约 22 mm，而大结节/小结节/三角肌粗隆彼此只隔十几毫米，
   可能放不下，需要先做排布可行性。
3. **肩胛约束方案**（L2 才用，但 L1 要先预留安装面）：锁死 / 胸廓接触面 / 韧带。
4. **z 标定需要打印 12 件样件**，打印机与材料尚未确定。
