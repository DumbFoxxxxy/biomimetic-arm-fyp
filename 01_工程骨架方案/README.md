# 方案一：工程骨架与钢丝／PSM驱动探索

以人工设计的胸廓、锁骨、肩胛和臂骨建立工程骨架，围绕预设关节与锚点优化运动和钢丝布置。包含V2–V8、V2-S1、钢丝＋TPU接口等历史工作；不能将这里的运动通过结论转移到人体骨骼方案。

| 目录 | 内容 |

| `SolidWorks/` | 原final_model原生零件、装配及其归档 |
| `早期模型/` | 原model及早期模型资料 |
| `输出/` | skeleton_from_v2、wire_psm_from_v2s1、cable_design_v2–v8等真实输出 |
| `脚本/` | 按旧路线分类的原脚本目录入口 |
| `历史归档/` | 原archive，保留旧版本和参考重复项 |

| `旧演示代码入口/` | 原mujoco_arm运行目录入口；其中人体骨骼子目录只为兼容保留，不属于本路线 |
