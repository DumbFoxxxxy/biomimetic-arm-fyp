## 几何变化

- SC、AC、GH、肘心不移动，锁骨和肱骨的关节中心距离保留。肩胛主体沿法向渐进让位8mm，AC/GH附近保留连接过渡。SUP、INF及原P所在主体区域随轮廓调整；P不能继续当成已满足的贴胸接触点。
- AC球头增至名义R10。肩关节颈部、肘部及肩胛局部轮廓按实际运动包络避让；保留骨骼空腔。没有删除整对关节碰撞检查。
- 胸锁支座开局部让位槽，保护轴承座区域。五个骨骼均保持单一材料实体；内腔不算断开的骨骼。
- 肩胛材料净变化约−11.2%，肱骨约−7.0%，其余变化见 geometry_delta.json。主体让位不是整块肩胛带着关节中心平移。

## 验证和交付

- 12条动作路径，常规相邻姿态各关节变化不大于1°，碰撞边界细化至0.1°；前后滑边界采用0.02°细化，对应标记点变化小于0.1mm。验证了已接收路径的去程和回程，关节限位无越界。
- 五骨之间逐对实体布尔检查，重叠体积数值阈值0.001mm³；零位及接收路径不保留实体穿透。各对最小采样间隙见 rom_audit.json，超过2mm的结果按2mm封顶。没有作连续全姿态证明。
- cad/ 包含五个零位零件STEP及整体STEP。它们是可直接编辑的分面BRep实体，不包含原SolidWorks参数特征历史。STEP回读合法性、实体数量、体积、包围盒、顶点对应及重新网格化后的差集体积检查均通过。
- skeleton.xml 与经检查的网格一致；motion.gif 是规定姿态的骨骼运动演示，不是肌肉驱动仿真。原V2与原始SLDPRT/SLDASM保留。

## 本次定版的边界

仅定骨架几何基线。关节采用V2的理想运动学约束；未验证SC交叉销等辅助硬件的完整实体装配、防脱、受力、强度、制造公差或实物性能。胸廓沿用原实心几何包络，任务书的3mm壳体尚未落实。GH凹面经包络避让，不宣称已按原R10.2/深3mm解析球窝完成制造设计。
钢丝锚点与TPU肌肉未定版，旧V2 sites只保留为后续设计种子，部分点位可能已不落在修正骨面上。原生SolidWorks特征树未回写，本版可编辑CAD交付为STEP。
