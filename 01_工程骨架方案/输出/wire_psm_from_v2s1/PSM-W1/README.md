# PSM-W1 钢丝与 TPU 肌肉接口候选（2026-10-29）

本版确定接口拓扑并给出可对照CAD的名义坐标，尚未冻结加工孔位。沿用V2-S1骨架，骨骼网格和关节中心未修改。用户允许短钢丝肌腱段，并明确肌腹不能延长时保留实际长度。

## 接口和走线

- A：固定在近端骨/胸廓上的TPU肌腹端块，同时固定主动线护套出口。
- C：TPU肌腹移动端块，主动钢丝在这里终止；另接一根固定长度的被动肌腱钢丝。C不是骨骼钻孔点。
- G：导向滑轮的固定进线切点/偏转支点。实际轮心O随出线方向偏转，不能把G当成轮心。
- B：被动肌腱在另一骨骼上的固定止点。
- 主动线：桌面电机 → 柔性护套 → A → TPU晶格内部 → C。被动线：C → G处R8偏转滑轮 → B。外部护套布置和C端轴向导向硬件仍需实现和检查。
- 目前16个通道是候选功能通道，并不要求制造16块互相独立的TPU肌肉：E01–02在肱骨旁，G01–04在上臂，G05–06在肩胛背侧，S01–06在胸廓背侧，P01–02在胸廓前侧。共享肌肉形体的变形相容性尚未验证。

## 坐标和文件

`anchors_design_mm.csv`含128行参考点，单位mm，X向右、Y向上、Z向后，与V2-S1 STEP零位坐标一致。A_root/G_root/B_root是骨面建议连接区域中心；A_fixed、G_ENTRY_PIVOT、B_insertion是带安装偏置的接口点。C0和O0都是零位参考位置，不是固定孔。
`wire_paths_zero_design_mm.csv`区分内部主动线与被动肌腱。`muscle_installation.csv`记录实际可用AG长度、肌腹零位长度、参考单元数和被动肌腱长度。

## 已验证与未验证

- 已检查冻结骨架的807个姿态。零位7维几何映射满秩，14个正反方向的理想拉动组合均存在；这不是张力、承载或全姿态控制验证。
- 钢丝直径按1mm，骨面净间隙按2mm、不同钢丝表面净间隙按1mm筛选。滑轮采用R8圆弧和有限外包络，未把无限圆柱包绕当成完整实体。
- TPU空间采用14×34mm矩形外包络情景；不是实际晶格形变模型。压缩25%/伸长25%仅是布局比较用假设，不是已测TPU能力，尤其伸长尚无本项目试验。
- 连接支架、肌肉之间的完整空间/形变相容性、外部电机护套线束及实物防脱均未完成。因此不能直接按参考点在骨上开最终孔。

## 当前结论

接口形式已选定，名义坐标可用于CAD核对和可调夹具试装；运动过程中仍有部分钢丝/导向干涉和肌腹行程限制，整臂走线尚未定版。后续应针对首次失败的通道局部调整，不改变骨架、不强行拉长肌腹。
