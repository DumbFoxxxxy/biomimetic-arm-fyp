# S1-Y1：紧凑GH骨架与两块共形Y晶格肌腹

更新：2026-11-02。当前研究候选，**未制造定版，未验证实际驱动范围**。唯一选择及报告哈希见[候选指针](../../../../design/S1_CURRENT_CANDIDATE.json)。技术总说明为[SHOULDER_DESIGN v0.9.12](../SHOULDER_DESIGN.md)。

## 结构与设计方法

以[紧凑GH骨架父级](../s1_GH_assembly_review/compact_recessed_keepers/README.md)为固定输入，保留真实骨骼工程修订、GH机械保持、骨干抱箍、固定肩胛／锁骨夹具。仅替换冈下肌FJ1500、肩胛下肌FJ1504两件TPU；其余189个源及装配变换不变，骨骼、锚点与钢丝路径未移动。三角肌与大圆肌仍采用旧晶格，不能称全肩已完成论文方法改造。

沿内部钢丝通道中心线定义局部Y切向；截面薄向为X，Z构成右手坐标系。把共享晶胞节点映射到实际肌腹截面，生成中心至八角的三维杆、开放菱形表面网格，并保留连续通道、端垫与连接钩过渡。内部杆名义直径2 mm、表面杆1.5 mm；外表面是杆网，不是封闭薄皮。

该方法参考论文的体积映射、三维晶格、表面网格与通道集成思路，是本项目重建，未取得作者原始CAD。文献定位及源哈希见[paper_method_reference.json](paper_method_reference.json)，本项目实际构造以[生成记录](candidate_generation.json)为准。

| 参数 | 冈下肌 | 肩胛下肌 |
|---|---:|---:|
| 名义X/Y/Z尺寸输入 | 15/10/30 mm | 6/8/10 mm |
| 内部单元数 | 10 | 28 |
| 轴向分层／表面面片数 | 10／40 | 7／70 |
| 实际轴向站距 | 9.20577 mm | 7.73130 mm |
| 实际X投影间距范围 | 6.56500–18.23850 mm | 2.64230–11.67730 mm |
| 实际Z投影间距范围 | 13.02568–51.15164 mm | 1.13960–14.23512 mm |
| 材料体积 | 8412.55559 mm³ | 7726.39466 mm³ |

名义尺寸控制生成密度，实际横向尺寸随截面变化。端部及窄截面可能融合；不能把名义晶胞的收缩率、刚度或论文结果视作本肌肉性能。固定间距Y格早期试改虽闭合，却仅覆盖4/10、5/7轴向分层，已拒绝为完整肌腹；失败保存在[稀疏覆盖审查](../../../../reviews/S1_2026-11-02/Y_axis_sparse_coverage)。

## 钢丝、锚点与坐标

[wire_and_anchor_plan.json](wire_and_anchor_plan.json)记录两模块的近／远端接口、手拉入口、完整主动线、内部中心线、近端反力对象、远端止挡与肌腱连接。主路线仍来自[既有钢丝清单](../s1_port_path_revision/routes_compact_distal_candidate.json)。

名义力链为：手拉主动线→远端止挡／自由端盖→销与回折肌腱→骨干抱箍→肱骨。反力经近端盖、TPU端垫、前支承、穿骨螺钉／背板传向肩胛夹具。TPU变形与恢复参与工作；两自由端不能直接固定到空间或肱骨。内部TPU通道与外部Bowden导管不同，外部手拉引线不属于肌腹内通道；未凭空添加导管反力固定点。

清单坐标为源解剖坐标，单位mm。单件STL局部坐标加其`translation_source_mm`得到源坐标；MuJoCo显示坐标为源坐标减`[-140,-70,1100] mm`。切片摆放是独立选择，不能按解剖坐标直接认定打印方向。孔径、钢丝和肌腱弯曲半径都是设计候选，压接与穿线尚未实测。

## 单肌肉实物试验准备

新增[真实截面试制检查件](print_inspection/README.md)：四个窄／宽段均来自当前网格，独立裁切重放已复核；其中冈下肌宽段有裁切碎片，肩胛下肌窄段含封闭空腔。完整冈下肌另有约13.11811 mm³封闭空腔，肩胛下肌有三处共约2.79258 mm³；与名义钢丝及完整通道包络均无体积相交，但仍需切片核查。零边界／单材料连通不代表没有内部闭腔，也不构成可打印结论。检查件无力学夹持边界，不能代替完整肌腹标定。

当前是供切片与试制评估的网格候选；打印机、喷嘴、材料品牌／硬度、摆向及工艺未确定。应先完成以下步骤，再报告实测能力：

1. 复制[空白记录](single_muscle_observation_template.json)，保留源网格哈希。确定设备、材料和切片参数，检查1.5 mm表面杆、窄截面融合、支撑可清除性及通道连通；不能让切片器静默修补后继续引用原几何检查。
2. 优先试制单肌肉及必要的孔路／端部小样。打印后核对实际孔路、端垫与钩，检查缺料、粘连和支撑残留；记录实测尺寸及偏差。
3. 按清单从近端入口穿入名义主动钢丝，确认远端止挡及肌腱固定方式，手动检查顺畅与端部保持。终端尚未确认时先独立试验，不安装成整肩驱动。
4. 近端使用实际盖／支承，远端允许沿真实约束运动。逐级手动拉线并记录输入位移、肌腹缩短、张力、回零残余、卡线和端部损伤；出现异常即卸载并记录。当前不预填安全拉力、最大行程或25%能力。
5. 在多次加载／卸载后判断重复性。再将单肌肉数据用于拮抗肌与自由端／肌腱／接触模型；只有完成耦合与实测，才报告肩部驱动范围。

## 查看与重新生成

项目根目录、已配置依赖的Python环境中：

```powershell
python mujoco_arm/tools/view_shoulder_manufactured.py
python mujoco_arm/tools/view_shoulder_bare_GH_motion.py
```

第一条显示当前191对象实际零位网格，第二条仅显示受检裸骨规定运动。均不模拟TPU变形或钢丝驱动。`--check`检查加载；`--render`生成图。不要同时给两参数期待渲染，检查模式会先返回。

以下命令会重写本目录生成物，执行前保存需要保留的候选；依赖包括numpy、scipy、manifold3d及项目`.deps`，环境说明见[RUNNING](../../../../RUNNING.md)：

```powershell
python mujoco_arm/tools/build_shoulder_y_muscle_pair.py
python mujoco_arm/tools/check_shoulder_y_muscle_pair.py
python mujoco_arm/tools/check_shoulder_bare_GH_motion.py --assembly '02_人体骨骼晶格肌肉方案/输出/shoulder_design/s1_y_muscle_pair/assembly_check.json' --out '02_人体骨骼晶格肌肉方案/输出/shoulder_design/s1_y_muscle_pair/bare_motion_review'
python mujoco_arm/tools/check_shoulder_GH_nut_keepers.py --assembly '02_人体骨骼晶格肌肉方案/输出/shoulder_design/s1_y_muscle_pair/assembly_check.json'
```

生成器固定读取旧紧凑GH父级，避免Y版重复叠加。重新生成后须复核来源／依赖、更新钢丝引用与未测记录的网格引用、重新检查并审阅候选，再同步候选指针哈希和渲染；不通过仅更新哈希跳过检查。已测记录不可改写成新网格的测量。

当前`stage_pass=false`，预测与实测驱动范围均未知。原K1–K7指标和肘部历史候选不变；当前几何、原理与下一步验证并列记录，不把网格通过当作制造或性能通过。
