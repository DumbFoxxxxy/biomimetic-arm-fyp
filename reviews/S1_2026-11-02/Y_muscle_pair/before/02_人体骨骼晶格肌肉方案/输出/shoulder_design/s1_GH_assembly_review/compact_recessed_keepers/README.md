# 当前S1研究起点：191对象紧凑埋入式保持件

更新：2026-11-02。已选为后续几何与肌肉集成的研究起点，**不是制造定版**。唯一选择记录见[候选指针](../../../../../design/S1_CURRENT_CANDIDATE.json)，`stage_pass=false`，实际TPU驱动范围未知。

## 为什么修订195对象版

同一裸骨检查中，195对象外置保持螺钉头将正向屈曲限制为96.2°；187对象入口版能到120°检查上限。仅埋入五金的首次191对象试改达到99.1°，随后碰新增凸台。两个对照及失败首限都保留，不降低原120°目标。

本版从187对象入口模型重建：M2螺钉头与螺母埋入凸台，不再使用四片外置M2垫圈；第0侧横销沿入口方向向内收0.3 mm，轴站位由4.7改为4.4 mm，第1侧仍4.7 mm。骨长、GH中心、肱骨、肌腹和钢丝路径均未移动。

以裸肱骨80–120°、每0.5°的局部几何包络，加源XYZ各侧0.2 mm设计让位，修整约4.68953 mm³新增凸台材料；不以这一步削除187入口父级的原有骨形。设计包络不是连续运动证明，实际范围由重新导出后的独立路径检查给出。

[完整源清单](assembly_check.json)：187父级中仅改工程肩胛并新增4件M2五金，其余186源及变换不变。肩胛相对父级新增约427.85096 mm³、移除约186.29907 mm³，含横销／埋入孔及导出差值；单正材料连通，零边界／非流形边。191对象18145对零位检查无超0.001 mm³刚性相交，六主动线净空；旧柔性相交保留。

M2头下长度9 mm、头高2 mm、R1.9 mm；头内有对边1.55 mm、深1.1 mm的候选六角孔，螺母座对边4.2 mm。这些是可编辑设计尺寸，尚未选定现成紧固件或证明可用工具／强度。

K1–K7原目标和底线保留。上述裸骨结果不作为K2／K3驱动通过，长轴正负不直接填入K4／K5，S1固定肩胛也不验收K6／K7。

## 安装与保持证据

[独立保持／放置检查](readback_keeper_checks.json)：两M3螺母正负转动约±4.1°遇槽壁；横销按名义位置固定时，第0／1侧螺母侧退约0.3／0.6 mm遇阻，下垫圈约0.2／0.5 mm遇阻。只证明这些有限方向的几何相遇，不证明扭矩、预紧、任意逃逸或强度。

顺序为每侧先放M3螺母／下垫圈，再放埋入M2螺母和横销螺钉；两侧完成后装10°裸肱骨，再装两盖／上垫圈和两枚M3。11步、0.1 mm独立往返共4322个子组件姿态清。闭盖裸肱骨0↔10°按1°／22姿态清，52方向R16球头探针均遇保持材料。

M2紧固是名义螺纹连接意图，数字网格无实际螺纹。装配暂持、批头进入与转动、M2螺母座反力、预紧和薄壁承压仍待验证；没有把裸骨放置当整肩装配通过。

## 查看与复现

在根目录使用MuJoCo／Pillow环境，默认读取候选指针并核对报告哈希：

```powershell
python mujoco_arm/tools/view_shoulder_manufactured.py
python mujoco_arm/tools/view_shoulder_bare_GH_motion.py
python mujoco_arm/tools/view_shoulder_bare_GH_motion.py --render
```

第一条看191对象零位实网格；第二条仅看102对象裸骨步骤的规定往返旋转，空格暂停／继续，0回零，1到受检末端。MuJoCo采用一个mocap骨、DOF=0，不做动力学步进，不显示TPU驱动。

[裸骨三姿态图](bare_motion_review/bare_GH_motion.png)、[完整零位图](available_parts.png)。脚本检查肱骨几何绕既定GH中心的旋转、固定对象位置、源哈希和排除对象，不能仅凭图片判断无干涉。

在配置numpy／scipy／manifold3d与`.deps`的几何环境复算：

```powershell
python mujoco_arm/tools/build_shoulder_GH_compact_keepers.py
python mujoco_arm/tools/check_shoulder_GH_nut_keepers.py --assembly '02_人体骨骼晶格肌肉方案/输出/shoulder_design/s1_GH_assembly_review/compact_recessed_keepers/assembly_check.json'
python mujoco_arm/tools/check_shoulder_bare_GH_motion.py --assembly '02_人体骨骼晶格肌肉方案/输出/shoulder_design/s1_GH_assembly_review/compact_recessed_keepers/assembly_check.json' --out '02_人体骨骼晶格肌肉方案/输出/shoulder_design/s1_GH_assembly_review/compact_recessed_keepers/bare_motion_review'
```

生成／检查会覆盖本分支输出，应先保存版本。更改或重新导出后，须复核并同步候选指针中的哈希；查看器发现指针过期会拒绝默认加载。历史模型可显式传`--report`查看。
