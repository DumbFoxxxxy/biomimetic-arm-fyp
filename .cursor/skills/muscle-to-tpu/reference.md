# muscle-to-tpu 参考

## 1. 参数依据

来源：Yoshimura, Kawaharazuka, Okada (2026) §2.1 / §2.3，本项目肘部实测对照。

### 1.1 论文给出的定量关系

| 关系 | 公式 / 数值 |
|---|---|
| 单元杆与 x 轴夹角 | cos θ = x / √(x² + y² + z²) |
| 理想压扁应变极限 | ε_flat = 1 − 2p/x；x=15, p=2 → 0.73 |
| 实测拐点 | 约 ε ≈ 0.55（低于理想值，因杆柔性 + 局部接触） |
| p 的影响 | p 1.5→3 mm，杨氏模量约增 28 倍；p = 2 mm 为基线 |
| x, y ≈ 15 mm | 稳定柔性 0.005–0.01 MPa，接触应变 > 0.5 |
| z 25→40 mm | 刚度降至约 1/2–1/5 |
| (x, y, z, p) = (15, 10, 20, 2) | E_x ≈ 0.02 MPa，E_y ≈ 0.01 MPa |

论文的两档肌肉参数（按功能，不按部位）：

| 用途 | 参数 |
|---|---|
| 与骨摩擦的内部肌 | x, y, z ≈ 12, 12, 25 mm |
| 大幅变形 / 缓冲的外部肌 | x, y ≈ 12.5, 15 mm；z = 30 mm |

**这些是论文的实测值，不是本项目的实测值。** 本项目必须建立自己的 z 标定曲线（见 §1.2）。

### 1.2 z 标定（本项目做法）

- 样件：x=15、y=10、p=2，**z ∈ {20, 25, 30, 40}**，每个 z 打 3 件。
- 每件沿 x 和沿 y 各压一次，得到 E_x(z)、E_y(z)。
- 与标定样件**同一台机、同一喷嘴/层高/材料批次、同一摆放方向**。
- 加载速率固定 100 mm/min。
- 单调插值（PCHIP 或 E = A·z^(−k)），报告残差；**只在 20–40 mm 内插值**。
- 校准判据：z=25 与 z=40 的刚度比应落在论文的 1/2–1/5 量级；否则说明工艺差异，曲线不可用。

## 2. 几何管线

```
解剖肌肉体积
  → 沿长轴提取断面（肘部取 17 个）
  → 周期 / 三次 B 样条包络
  → 八杆中心—顶点晶格（按 x/y/z 间距，被曲面裁剪）
  → 外表面菱形杆网（每方向 8 条）
  → 连续钢丝通道（R0.85 / R1.6）
  → 端部过渡 + 刚性端盖
  → 单连通检查
```

**单元几何**：长方体单元的中心向 8 个顶点各伸一根杆，共 8 根；在任一正交中截面上读到 4 根、呈 X 形。
杆互相支撑，因此可无内部支撑打印。

**局部坐标**：断面在 (u, v) 平面，第三轴为沿肌腹的高度 h。
`y`（收缩方向）对应**沿 h 的间距**；`x`、`z` 是两条横向间距。

### 2.1 坐标变换链（本项目实测确认）

未写入本节前，这一步最容易搞错——直接拿剖面数据去对齐骨骼会差 1000 mm。

```python
SHIFT = np.array([-140.0, -70.0, 1100.0])       # 原始 BodyParts3D → display
E = elbow_centre_source - SHIFT                  # 局部系原点 = 肘关节中心
G = GH_centre_source - SHIFT
z = unit(E - G); x = unit(cross(z, [0, 1, 0])); y = cross(z, x)
F = np.stack([x, y, z], axis=1)                  # 正交，实测 |FᵀF − I| < 3e-16

local = (V_source - SHIFT - E) @ F               # 点云 → 局部系
```

| 常量 | 含义 | 存在哪 |
|---|---|---|
| `SHIFT` | 原始 BP3D → display 的平移 | 未落盘，必须写死 |
| `E` / `G` | 肘 / GH 中心（display） | `joint_candidates.json` 减 `SHIFT` |
| `F` | 正交基，第三列 = 肱骨长轴（GH→肘） | 已存进 profile 的 `basis_columns_display` |

**验证方法**（不依赖任何布尔库）：对源网格在 17 个记录高度做平面切，链成闭环求面积，
与 profile 的 `source_section_area_mm2` 逐条比对。实测 FJ1486 **17/17 完全一致（0.00%）**。
若面积对不上，先查 `SHIFT` 用没用对，而不是怀疑断面算法。

## 3. 生成依赖（本机可能缺失）

| 步骤 | 依赖 | 缺失时的表现 |
|---|---|---|
| 断面提取 / 包络 | numpy（可选 scipy 做样条） | 可用纯 numpy 线性插值替代，形状略钝 |
| 晶格 / 通道 / 布尔 | **manifold3d** | 无法生成实体，只能出线段与轴线 |
| `design.json` 里的体积 | manifold3d | 无 |

**manifold3d 缺失时不要伪造结果**：可以输出参数、断面、杆轴线与通道路径供核对，
但不得声称生成了制造网格。装好后重跑同一命令即可。

### 3.1 本机安装记录（沙箱环境）

常规 `pip install` 会失败，原因有两个，且都与网络无关：

1. `pip` 的临时目录落在被沙箱拒绝写入的位置 → `Permission denied: ...\pip-unpack-*\*.whl`；
2. 系统 Schannel 在本进程内无法取得 TLS 凭证 → `curl` / `Invoke-WebRequest` 全部失败。

**Python 自己的 OpenSSL 是好的**（`urllib` 能正常访问 HTTPS）。可行路径：

```python
# 1) 直接从镜像取 cp314 轮子
url = 'https://pypi.tuna.tsinghua.edu.cn/simple/manifold3d/'   # 解析出 *cp314-cp314-win_amd64.whl
# 2) 解压到 .deps/
# 3) 关键一步：wheel 把 msvcp140 放在 .data/platlib 下，需手工拷到 .deps/ 根目录
```

之后用 `PYTHONPATH=D:\XJTLU\PSP\.deps` 运行即可，`D:/MujocoEnv`（含 scipy）同样可用。
`.deps/` 已加入 `.gitignore`。

## 4. 回归检查（重跑必须能对上的基线）

改动用同一 profile 重跑后，用下列数字自检。**体积是唯一可靠的等价判据**。

| 项 | 实测 |
|---|---|
| FJ1486 重新生成体积 | **26467.562 mm³** |
| FJ1486 M1 父版（shifted_muscle）体积 | **26462.252 mm³** |
| 差值 | **+5.310 mm³（0.020%）** |
| 连续通道版 = 父版 + 墙 | +652.655 mm³ |
| `design.json` 记录（653.882 − 1.225 孔腔重切） | 652.657 mm³ → **差 0.002 mm³** |

**不要用逐层截面积做等价判据**：晶格切片对平面相位极其敏感，实测同一块肌肉的
截面积差异可达 48%，而总体积只差 0.02%。同理，点—面最近距离的尾部（实测 13.8% 的
采样点达 5–16 mm）来自采样点落在对方网格的孔里，不代表外形差异。

## 3. `design.json` 必填字段

```json
{
  "scope": "字符串：本件是什么、不是什么",
  "muscle": "FJ1486",
  "tube_outer_radius_mm": 1.6,
  "tube_inner_radius_mm": 0.85,
  "nominal_wall_mm": 0.75,
  "tube_material_components": 1,
  "full_material_components": 1,
  "new_TPU_volume_mm3": 0.0,
  "material_added_to_parent_mm3": 0.0,
  "nominal_steel_intersection_mm3": 0.0,
  "nominal_steel_clearance_mm": 0.0,
  "OBJ_STL_roundtrip": {"status": "", "relative_volume_error": 0.0, "pass": true},
  "basis_columns_display": [[1,0,0],[0,1,0],[0,0,1]],
  "coordinate_origin_display_mm": [0, 0, 0],
  "pad_centres_display_mm": [[0,0,0],[0,0,0]],
  "wire_polyline_display_mm": [[0,0,0]],
  "mechanical_performance_verified": false,
  "frozen": false
}
```

约定：

- 坐标用 **display mm**（原始 BodyParts3D 减 `[-140, -70, 1100]`），并在 `scope` 里写明。
- `mechanical_performance_verified` 与 `frozen` 默认 `false`，**不要因为几何通过就置 true**。
- `wire_polyline_display_mm` 可以包含穿线超出段（threading overrun）；实际工作端到压接座为止。

## 4. 失败目录（来自肘部实际发生）

| # | 失败 | 实际证据 | 本流程的拦截点 |
|---|---|---|---|
| 1 | 力矩符号反号 | 伸肌力矩在 85° 反号 | Step 0 力矩表 |
| 2 | 直线弦穿骨 | 伸肌弦在 132° 碰肱骨 | Step 0 穿骨检查 |
| 3 | 腱端需求超出材料能力 | 伸肌端部需增长 50.37% | Step 0 弦长变化 → 判是否可行 |
| 4 | 装配时 TPU 与骨/件接触 | 109 条 TPU 接触观察未消解 | Step 2 让位 + Step 4 检查 |
| 5 | 通道被打扁 / 卡线 | 分段短导管版假设失败 | 连续管壁 + 加大壁厚 |
| 6 | 压接滑脱 | 压接至今为名义几何 | 端盖前置：实际压接件尺寸核对 |
| 7 | 三块解剖体合并后不连通 | 三角肌三束是独立网格 | Y 形分叉重新构造，不做布尔并 |
| 8 | 打印方向不一致导致数据不可比 | 方向差 1.5 倍模量 | Step 5 方向一致性硬约束 |

## 6. 检查脚本

`scripts/check_tpu_muscle.py` — 纯 numpy（有 scipy 时自动加速），无需 manifold3d / trimesh。

另外，仓库侧还有一个通用的关节扫掠模块 `mujoco_arm/tools/interference.py`
（阈值 0.001 mm³ / 间隙封顶 3 mm / 首碰细化 0.1°，与项目既有口径一致），
用于"肌肉装上骨以后，关节转起来会不会撞"。它不属于本 skill 的可移植部分，
但同一个项目里做 L1–L7 时应当复用它，不要再写一份 `probe()`。

| 检查 | 方法 | 通过 |
|---|---|---|
| 连通分量 | 面—边邻接并查集（默认不焊接顶点） | 主分量唯一 |
| 碎屑 | 额外分量 ≤32 面且 \|体积\| < 1e-3 mm³ | 记为 debris，报告但不判失败 |
| 闭合性 | 主分量每条无向边恰好 2 次 | 边界边 0、非流形边 0 |
| 钢丝间隙 | 折线按 1 mm 重采样到三角面的最小距离 | > 钢丝半径 |
| 体积回读 | 有向体积，OBJ vs STL | 相对误差 < 1e-6 |

### 6.1 焊接开关（重要）

**默认 `--weld-tol 0`，即不焊接。** manifold3d 导出的 OBJ 已共享顶点索引（实测
FJ1477：153539 顶点 / 310566 面，V ≈ F/2 符合闭合三角网格）。

若强行按 1e-5 mm 焊接，会把相距极近但拓扑独立的顶点合并，**凭空造出非流形边**：

| 对象 | 不焊接 | 焊接 1e-5 mm |
|---|---|---|
| FJ1477 非流形边 | **0** ✅ | 29 ❌（假阳性） |

只有当外部来源的 OBJ 存在重复接缝顶点时，才开启 `--weld-tol 1e-5`。

### 6.2 已跑通的实测基线

对肘部当前连续通道候选 `captive_keepers/continuous_channel_candidate/`：

| 对象 | 主分量面数 | 体积 mm³ | 钢丝间隙 mm | 回读误差 | 结论 |
|---|---:|---:|---:|---:|---|
| FJ1486 | 313622 | 27114.907 | 0.8347 | 3.1e-9 | PASS（含一块 10 面 / −0.00046 mm³ 碎屑） |
| FJ1477 | 310566 | 30129.485 | 0.8344 | 1.7e-8 | PASS |

两个数字与项目记录一致：`design.json` 的 `new_TPU_volume_mm3 = 27114.90735160946`、
`nominal_steel_clearance_mm_capped2 = 0.5349`（本脚本按折线重采样测得 0.835，
差异来自采样点位置不同，两者都远大于 0.3 mm 的钢丝半径）。

**口径差异需注意**：项目 `design.json` 记 `full_material_components = 1`，
而按曲面连通性 FJ1486 有 2 个分量。差别在于后者包含一块 10 面、负体积的碎屑壳——
体积法把它算作零，曲面法能看见它。**报告里必须写明用的是哪一种口径。**
