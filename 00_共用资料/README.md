# 共用资料

这里的目录是原工作区资料的分类入口，保留原执行位置，不额外复制大文件：

| 入口 | 用途 |
|---|---|
| `knowledge_base/` | 文献全文、笔记、索引和检索工具 |
| `literature_inbox/` | 待补充文献和文献清单 |
| `design/` | 跨阶段设计历史总账；DESIGN_BRIEF内同时含旧、新方案，不应整份当作某一方案约束 |
| `tmp/` | 临时试验、计算及CAD/布尔依赖，暂不删除或按名称猜测归属 |
| `原始文献索引.md` | 根目录PDF、Reference.txt与思维导图入口 |

根目录原始PDF未移动，避免破坏知识库文件字段与历史链接。资料按主题共用，不强行归给某一设计路线。论文的参数和验证结果不能直接当作本项目实测值。
