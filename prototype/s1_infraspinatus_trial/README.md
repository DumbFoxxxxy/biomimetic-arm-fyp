# 冈下肌完整肌腹试制包

2026-11-03。取自当前 S1-Y2；优先用于单肌肉试制，不替换当前候选，也不是独立完整台架。27 个源对象按原文件逐字节复制，均保留毫米单位、原坐标及装配平移。

本轮先选冈下肌：当前源几何的端环出线偏角约 0.37°，肩胛下肌约 17°，后者的斜向出线尚需单独试验。这只是安排试验顺序，不是驱动能力比较结论。

## 论文提供的工艺参考

依据[论文正文第4.4节](https://advanced.onlinelibrary.wiley.com/doi/10.1002/aisy.70537)及[本地全文](../../knowledge_base/fulltext/Advanced_Intelligent_Systems_2026_Yoshimura_Accelerating_Musculoskeletal_Robotics_Through___426b72.txt)：作者使用Prusa XL和TPU95A；骨骼采用PLA。作者的内部晶格按自支撑设计，外表面网格需要支撑，多材料打印使用PLA支撑便于移除，单材料设备也可使用TPU支撑。

这些是论文样件的制造描述，不证明当前冈下肌在任意摆放下免支撑。设备／材料在本项目继续记为未定。详细打印条件在补充Table S2；截至本轮，本地未收录该表，出版商补充PDF下载返回403，尚未核实其中的喷嘴、层高、温度和速度。不从机型默认配置或材料商品参数反推作者设置，也不将论文材料模量或断裂伸长率作为当前打印件的实测值。

## 钢丝与反力

有两条不同用途的钢丝：

1. **主动线**：名义直径0.6 mm，从近端外盖入口进入TPU连续通道，在远端止挡处终止。拉近端自由尾线，远端止挡作用于端部；TPU肌腹的缩短及恢复需要实测。
2. **被动短肌腱**：自由端盖经两端槽环和压接套连接肱骨抱箍。其网格只是零位布线路由，不能打印为钢丝，也不能把名义中心线长度直接作为裁线尺寸。

主动线中心线及入口坐标见 `manifest.json` 的 `active_route_source_mm`：`full_wire_path_source_mm` 为全路径，`ports.origin.hand_pull_lead_source_mm` 为手拉端；它们处于源装配坐标，不是各零件STL的统一局部坐标。使用每件 `source_to_assembly_translation_mm` 还原装配位置。

近端端垫／前支承承担反力，远端自由盖随肌腹变形，不能固定为肱骨刚体。单肌肉试验只固定近端反力接口，不夹住晶格工作段、不用额外刚板跨接两端，也不把钢丝绕过肌肉直接绑骨。

**当前前支承／背板为贴骨设计，不是台钳专用夹具。** 本包不含肩胛骨、GH、抱箍、工作台及其固定件；选用台钳或临时台架之前，要先确定夹持面与工具空间。没有这一固定条件时，可以进行切片／穿线检查，不能宣称已能完成带载手拉试验。整骨架仍按当前候选装配。

后续已新增[单肌肉近端台架V1](bench_adapter_v1/README.md)：用独立的一体支承／夹持块取代本包的前支承和背板，仅用于单肌肉试验；26对象零位配对、螺钉／螺母规定放置路径及后侧工具包络有几何证据。它不替换整肩源模型，实际台钳、止挡及手拉仍未验证。

主动线固定另有[可拆金属止挡候选](screw_stop_v1/README.md)，保留原端盖，以金属主体和径向M2紧定螺钉固定钢丝。已输出加工尺寸和组合查看入口，但不是打印塑料止挡，实际握持力、钢丝损伤及反夹持工具待试验。

名义通道孔径仍为1.72 mm，未采用独立1.80 mm孔道分支。实际线径、穿线余量、止挡固定、两端压接和预紧均未定；毛坯不可直接视为有效固定。

## 按顺序试制

1. 先记录打印服务的设备、喷嘴、材料及可用支撑。以论文条件为起始参考，不填入未经确认的温度、速度或收缩能力。
2. 分别导入肌腹与六件刚性候选，检查比例、杆件、连续孔道、端钩和切片路径；确认支撑能否从通道及晶格内部取出。保存项目和切片截图，不能只凭STL预览判断可打印。
3. 打印后先检查线能否贯穿肌腹和端盖、端钩能否装入；记录实际尺寸及损伤，不靠放大或自动修复悄悄替换模型。
4. 近端固定、端盖配合及止挡保持落实后，从小位移手拉，分别测输入拉线与肌腹缩短；先不要求肱骨动作。卡线、滑脱、损伤或恢复问题逐项记录，五次记录不是寿命验收。
5. 单肌肉动作确认后再装入完整骨架，用短肌腱连接骨侧槽环，观察是否真正带动肱骨及松线恢复。拮抗回拉和范围测量属于后续试验。

没有力计时拉力保持空值；不使用论文收缩比例或旧25%假设替代本件结果。完整TPU有限元暂不作为上述试制前置门。
