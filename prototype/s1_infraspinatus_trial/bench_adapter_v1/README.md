# 冈下肌单肌肉近端台架候选 V1

2026-11-03。用于把当前完整冈下肌装在台钳／台架上做穿线、手拉及恢复试验。新增一体支承和夹持块，**不改变原肩部S1-Y2骨架、肌腹、端盖、钢丝或锚点**。这是单肌肉试验工装，不作为人体骨骼或整肩关节的替代件。

![实际26对象MuJoCo静态装配](available_parts.png)

## 结构与传力

原近端前支承保留在一体工装顶部。两根窄柱接到后侧圆支柱，再接到平面夹持块；不在整个肌腹下方增加刚性背板。宽支柱最高局部Z为−10.5 mm，当前未变形肌腹最低局部Z约−9.569 mm；窄柱只在近端两螺钉附近接入。实际变形后是否碰到工装须手拉观察。

固定路径为：**近端盖／TPU端垫 → 一体前支承 → 支柱 → 平面夹持块 → 实际台钳或台架**。两颗原名义M3×20螺钉仍穿过原近端盖及端垫，后垫圈／螺母从工装后方装入。原贴骨背板在这套工装中不安装；这是两套互斥装配，不是在碰撞检查中忽略它。

主动钢丝仍从近端进入TPU通道、在远端止挡，远端端盖保持自由。单肌肉试验先观察肌腹缩短／恢复，不安装肱骨或将远端固定到刚性骨段；被动短肌腱和骨侧端环可留到后续骨架试验。图中保留这些参考对象便于核对，不代表远端已有外部约束。

两个STL是同一件的不同摆放，**只打印其中一个**。初次试制按4件候选准备：本工装、[完整TPU肌腹](../01_TPU/muscle.stl)、[原近端盖](../02_rigid_candidates/origin_cap.stl)、[自由端盖](../02_rigid_candidates/free_terminal.stl)。前后盖材料和切片均需确认；工装按刚性件考虑，不打印为软TPU夹具。

现有M3螺钉2颗、M3螺母2颗及垫圈4片为名义模型参考。真实规格、有效螺纹和工具要核对，不能打印这些包络代替金属紧固件。钢丝名义0.6 mm，远端主动线止挡仍是未压接毛坯；**止挡保持尚未落实，所以不能仅凭这个台架宣称已经能可靠手拉。**

后续新增[可拆金属止挡V1](../screw_stop_v1/README.md)，作为替代毛坯的独立试制候选，提供尺寸图、侧向放置路线和握持试验表。它需要金属加工和实物M2螺钉，握持／反夹持工具仍未验证；本台架原26对象场景不自动替换，组合查看使用新候选的28对象场景。

## 装配次序

1. 核对工装和肌腹切片，分别打印。图案／通道内部的支撑、层间结合与打印方向尚未确认，不把打印姿态候选视为免支撑方案。
2. 把夹持块的两相对平面夹入实际台钳。夹持限于后部实心块，工具井出口保持可接近，不能夹肌腹或用板件连接肌肉两端。台钳本体尚未纳入几何检查，实际固定先空载确认。
3. 从近端将原盖、TPU端垫与工装孔对齐，插入两颗M3螺钉；从后工具井放入后垫圈／螺母。记录实际拧紧和端垫压缩，不以名义包络替代预紧效果。
4. 安装自由端盖，确认钩扣配合、通道贯通；穿主动钢丝并落实真实远端止挡。外部Bowden导管不是这套手拉工装的前提。
5. 从小位移拉近端钢丝自由尾线，记录输入拉线、肌腹缩短、端盖活动、恢复、卡线和滑移；保留视频。实际拉力、行程和范围没有实测就留空。

## 已检查的范围

- 工装装配STL和打印摆放STL：精确坐标去重后，零开边、零非流形边、零退化三角形；一个正材料连通体。没有通过自动删碎片、填孔或放宽拓扑门槛取得通过。
- 26对象全部325配对；含相邻接口，无超0.001 mm³判据相交。主动线中心线外1.2 mm半径包络与工装亦未超判据。这个半径是几何检查包络，不是软管规格。
- 两颗螺钉分别从前侧30 mm放入；两组后垫圈／螺母分别从后侧40 mm放入，0.5 mm步长且独立回程，共568个规定姿态，无超判据相交。不模拟螺纹旋合或完整装配顺序。
- 两处后侧Ø8.4 mm直圆柱工具包络到螺母附近未碰工装；不是已选定套筒，也不证明真实工具能夹持螺母。两处0.04 mm法向探针会遇到垫圈材料，支持名义承压面位置，不证明载荷能力。
- 当前191源模型哈希全部保持；MuJoCo静态26对象、DOF=0。没有肌肉变形、强度、台钳夹紧或实际驱动通过结论。

0.001 mm³只是相交报告判据，不是制造公差；0.5 mm是名义放置采样，不是数学意义的连续装配证明。原前支承回读材料差约2.8×10⁻⁷ mm³；装配导出的浮点表面增／减量各约0.0013 mm³，打印姿态回变换差另见JSON。

前三个失败导出及当时生成脚本分别保留在 `rejected_initial_export`、`rejected_simplified_export`、`rejected_separate_bore_export`。最终改为后退宽支柱＋两窄柱，只在新增材料开3.5 mm孔，未采用全件简化或复杂TPU反模挖空。

## 复现

在项目根目录运行，建模／检查需要项目本地 `.deps` 中的manifold3d和既有Python依赖：

```powershell
$env:PYTHONPATH = Join-Path (Get-Location) '.deps'
python tools/build_s1_infraspinatus_bench.py
python mujoco_arm/tools/view_shoulder_manufactured.py --report prototype/s1_infraspinatus_trial/bench_adapter_v1/assembly_check.json --render --distance 0.30
python tools/verify_s1_infraspinatus_bench.py
```

去掉 `--render --distance 0.30` 可打开自由旋转查看器。查看脚本会按当前项目路径重新生成场景，不能把生成XML中本机绝对路径当作外部依赖。生成器是可编辑参数构造源；本轮未提供已验收的SolidWorks实体或实物。
