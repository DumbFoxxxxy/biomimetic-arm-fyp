# FJ1500主动钢丝：可拆金属止挡候选V1

2026-11-03。为当前冈下肌单肌肉试制补充钢丝固定结构：用**金属主体＋M2平端紧定螺钉**替代未压接止挡毛坯。保留现有自由端盖、沉孔、肌腹、近端走线和锚点；不修改整肩当前选择。几何与放置路径已有证据，握持能力尚无实测。

## 连接与制造

主动钢丝经过原通道和端盖孔，穿过金属止挡轴孔；径向紧定螺钉固定钢丝，止挡底部抵住端盖台阶／外侧承压面。钢丝拉力通过止挡传给端盖和TPU端部，TPU肌腹及远端端盖随实际约束变形、运动。被动短肌腱仍是另一个连接，本轮没有替它完成压接握持验证。

金属止挡沿用Ø2.5 mm插入段，配合原Ø2.8 mm沉孔；外露主体由Ø4 mm金属料加工，朝肌腱耳一侧加工0.5 mm深平面，保留螺钉侧壁。不是把一个更大的金属块直接塞进原沉孔。

| 项目 | 名义尺寸／边界 |
|---|---|
| 金属插入段 | Ø2.5 × 2.6 mm |
| 外露主体 | Ø4 mm料、长4 mm，一侧平面至局部X=−1.5 mm；X向宽3.5 mm |
| 总长 | 6.6 mm；加工图以插入段底端为Z=0 |
| 轴向钢丝孔 | Ø0.8 mm贯穿，钢丝名义Ø0.6 mm |
| 径向螺纹 | M2×0.4，轴心距金属插入段底端4.6 mm，沿局部+X朝外 |
| 螺钉候选 | M2×3平端紧定螺钉，名义0.9 mm内六角；实际型号和尺寸待确认 |
| 轴向就位间隙 | 约0.05 mm，不是制造公差或实际预紧量 |
| 外露头部到端盖 | 排除靠近承压面的局部Z=3.05–3.25 mm后，最小间隙约0.25 mm |
| 当前名义状态 | 螺钉平端接触钢丝；未建立握持力、摩擦或扭矩预测 |

螺钉规格参考[PTS M2×3平端产品及尺寸表](https://www.pts-uk.com/products/socket-screws/socket-set-screw-flat-point/metric-a2/a9130203)、[SAIDA平端紧定螺钉尺寸表](https://www.del-screw.co.jp/en/imo/hirasaki/fe.html)。模型选择0.9 mm平端直径与0.8 mm孔深作包络，不能假定任意供应商实物恰好等于这些数值。

主体需要金属加工，材料牌号、尺寸公差及表面处理尚未确定，不能以TPU／PLA打印件代替。**STL中的Ø2.1 mm径向圆孔是未建螺纹的配合包络，不是实际钻孔尺寸。** 加工按M2×0.4螺纹标注及实物螺钉匹配；不能按STL光孔加工后期待其拥有螺纹握持。

金属主体壁厚和有效螺纹接触仍需核对。记录中的螺钉轴向重叠长度不是有效螺纹啮合长度，不能据此推算可承受拉力。图纸是试制候选，不是冻结的量产加工图。

## 装配次序和路径

先在独立单肌肉台架上确认端盖和金属件配合。螺钉后退约0.2 mm时，名义平端退离钢丝孔，便于穿线；这只是几何位置，不是拧紧设定。钢丝穿入后，实际握持需要拧紧和试验。拧紧时须落实金属主体的反夹持，不能把尚未验证的TPU端钩当作防转夹具；实际夹持工具和反扭矩尚未验证。

本轮检查了两种不同上下文：

1. **独立单肌肉台架**：从端盖正外侧20 mm处直插到位，0.1 mm采样、独立回程，共402规定姿态，无超0.001 mm³判据相交。主动线在这一步尚未穿入，不把它当作已经连接的刚性对象。
2. **整肩已装状态**：同样的正外侧直插路径与未变形三角肌重叠，保留232条逐件／方向的超判据记录；不能仅因肌肉柔软就宣称能够穿过。另检验局部路径 `(X,Y,N)=(0,−40,4) → (0,0,4) → (0,0,0) mm`，即先从侧面进入，再沿轴线就位，0.1 mm往返共882规定姿态，无超判据相交。局部基和源坐标变换在JSON中。

上述路径是止挡／初接触螺钉组的名义几何放置，不是完整整肩装配证明，也不模拟手、真实工具、钢丝穿入、反夹持或螺纹旋合。原整肩的其他柔性接触问题继续保留。

## 通过了什么

- 三件新STL精确坐标去重后，零开边、非流形边和退化面；各为单正材料实体。
- 新主体、螺钉、延长主动线对当前其余190源及彼此，共573配对未见超0.001 mm³判据的相交。旧190源之间沿用原报告，不把局部候选提升为整肩无干涉通过。
- 径向后退0至0.2 mm的五个螺钉姿态，以及名义0.9 mm内六角直线工具接近包络无超判据相交；没有真实扳手或反夹持工具验收。
- 螺钉前进0.05 mm探针会遇钢丝，止挡向内0.06 mm探针会遇端盖材料；这些是**有意相交的接触位置探针**，不是可用刚体姿态，更不代表夹紧力或钢丝压缩通过。
- 当前191源和指针未修改。细节场景实际加载4对象，台架场景28对象；没有钢丝握持、TPU变形或实际动作结果。

曾比较完整Ø4 mm圆头（与端盖约0.241 mm³相交）和Ø3.6 mm圆头（端盖间隙仅约0.0069 mm），随后采用单侧平面。圆头分支和正外侧受阻证据均保留。没有降低原相交判据或把6.9微米间隙当作已确认的制造间隙。

## 先做止挡小试，再拉整肌肉

先单独制作止挡、选配螺钉和一段实际钢丝，用独立固定方式测轴向拉动时的滑移、松动和钢丝损伤，再装到打印端盖上确认就位与承压。预期试验拉力目前未知，握持是否足够需要与随后单肌肉实测拉力比较；不填写假定载荷或拧紧扭矩。

没有扭矩工具／力计时相关数值保持空值，仍可记录拧紧方法、拉线与滑移、拆装及损伤视频，但不能由此宣称额定握持力。松开后检查夹点并记录能否重新固定。止挡小试通过后，再在台架上观察实际TPU肌腹的缩短和恢复，最终回到带骨架的驱动试验。

## 复现

在项目根目录，使用具有NumPy、SciPy和项目`.deps`依赖的环境：

```powershell
$env:PYTHONPATH = Join-Path (Get-Location) '.deps'
python tools/build_s1_wire_screw_stop.py
python tools/document_s1_wire_screw_stop.py
python tools/verify_s1_wire_screw_stop.py
python mujoco_arm/tools/view_shoulder_manufactured.py --report prototype/s1_infraspinatus_trial/screw_stop_v1/bench_check.json
```

局部细节可打开`detail_check.json`，加参数 `--distance 0.04 --lookat -0.186 -0.057 1.323 --azimuth -50 --elevation -25`。MuJoCo仅用于查看实际网格，不承担本轮相交计算，也没有显示虚构驱动。
